# SDK2 解析矢量拖尾与 owning Sprite

包身份 `makokara.v2.vector-trail`，入口 `VectorTrail`，导出 `vector-trail`。要求 Vulkan/GPU。
一个 Custom 连续发射器固定速度 `(40,-25)`、加速度 `(0,20)` 和年龄透明度，宿主不再自动绘制该批粒子。

- 晚期接口只读取本实例 `Alive`、固定五秒闭出生窗与 `GetTrail`；`showBirths` 将窗内包括已死亡粒子的完整出生位置画为小蓝点。
- `mode=ribbon` 画可变宽带状拖尾，`segments` 画相邻解析节点的平端线段，`sprites` 用本包 `assets/spark.png` 句柄画包含剪切和镜像的完整仿射；头部圆点保留。
- `sampling=exact` 默认精确出生时刻。`grid` 仅声明本实例无文字写入的连续窗；源、父组、Ruby、其他文字实例和真实装载断点仍由宿主合并，不能跨身份插值。
- 粒子死亡不会删掉固定出生窗记录；当前文字离场也不会提前删除仍存活的粒子。拖尾来自歌曲网格、出生点和当前点，不依赖请求顺序。

寿命 1～5,000,000 µs，拖尾 0～1,000,000 µs，默认 24/s、600,000 µs、6 px、0 散布。
PNG 为版本化的静态 raster 源素材；本例不包含 Paths、SVG 或 M09 能力。
清单 SHA-256 覆盖实际文件字节。这里只提供 M08 样例，不声称已经取得编译、像素或性能证据。
