> 2026-10-03；承接已接受 R0 §4／§8、SDK §5。用户明确确认：**每条合法播放头各自按 rate 发射**。0.9.23 接通 R6 连续发射、解析运动和固定采样拖尾；0.10.0 按用户确认替换为独立发射阶段，并提供作者只读粒子／完整出生记录，见 [发射阶段合同](scripting-emission-stage-proposal.md)／ADR-0088。不关闭完整 R6。

> 下文 §1～5 为当批基础合同／证据；当前 Bridge 已按文末 0.30.0 接续，独立向量／图片图元见 ADR-0123～0124。历史“未实施”不代表当前门禁。

## 1. 身份、时间和几何

- 发射器身份为 `(InstanceId, EmitterId)`；粒子身份为该身份加单调 `BirthIndex`。同时存在的播放头按 `(TrackId, BindingId)` 分别积累配额；同一装载内换字保持配额，头消失后其配额结束，不猜测另一个头是后继。
- 左边界注册的描述控制 `[a,b)`。以输入 double 的精确二进制有理值计算 rate／微秒及剩余配额，出生时刻向上取到第一个满足配额的整数微秒；`b` 的出生留到下一半开区间。同刻不同头按稳定身份顺序编号。
- 出生坐标读取出生时刻的纯文字最终几何；不拿两个边界线性猜测。该查询在共享状态推进前使用左边界状态，不执行事件、视觉回调、发射或图像。源事件已拆成精确边界，区间内没有未处理事件。
- 每次边界提交一次；分数帧在副本上读取临时出生，暂停不累计。倒退、模式／密度改变、失败或取消后的重试从零重建。AnchorQuery 不执行粒子。

## 2. 输出和寿命

- `EvaluateEmitters` 内的 `EmitterWriter.Set` 使用 Overlay 能力，命名输出 ID 与 EmitterId 相同；同帧同发射器最后一次描述生效。与手工圆点同名冲突拒绝；包须声明对应 Overlay 输出。
- 描述明确选择 Baseline／AdvanceCenter、rate、寿命、逻辑直径、颜色、速度、散布、恒定加速度、年龄透明度／大小曲线和前／后层。年龄曲线保存端值及已有 CurveValue，不重排文字。
- 出生散布用现有 PCG32 纯索引服务，实例／发射器／分流键／BirthIndex 决定。粒子保存出生世界位置，之后按歌曲秒和常速度／常加速度解析；切行不会把旧粒子搬到新槽位。
- 拖尾保留出生点、固定网格／事件边界的运动样本，呈现点可附加解析末端；只保留 TrailDurationUs 窗口中的样本。粒子在半开寿命末端消失，其拖尾随之结束。以公共圆点批次呈现采样轨迹，本批不宣告独立 DrawTrails／sprite API 已完成。
- 正式准备帧附带不可变粒子和拖尾快照，生产圆点绘制与预览／导出共用。不向作者暴露可写粒子集合；作者 Particles／EmissionSchedule 已在 0.10.0 补齐，按本实例隔离并保留离场对象；0.11.0 事件 Burst 已补齐，真实来源及边界记录见 [Burst 合同](scripting-event-burst-contract.md)。

## 3. 预算、限制与失败

- 会话活粒子 20,000、拖尾样本 200,000，沿用已接受合同 B，计入全部实例；图元继续受每帧 100,000 项门禁。逐出生先清理到期粒子再检查峰值，不因总历史出生多而拒绝，也不静默削减。
- 用户已确认独立 EmissionRecordLimit=100000：每固定区间全实例真实出生，包括期末已死亡对象；固定和分数副本出生流分配前执行，不静默裁掉记录。
- 数值非有限、非法寿命／曲线、世界坐标或时间溢出、预算、声明外输出均归属真实实例并使本帧失败；导出沿用既有失败／临时发布保护。取消及时退出并清理。
- 本批仅 Jump／SemanticCursor；Bridge 依赖待答的重叠行后继规则，IncludeInTargetCapture 依赖正式主画布捕获协调器，使用时明确报未实施。不伪造后继、不忽略请求。不允许纯帧会话启用持续发射。
- 不修改生产 JSON／schema，不新增程序集或第三方依赖。持久预算／工程参数 UI、粒子包分享工作区、独立图元／桥接／映射仍按 R2～R8。
