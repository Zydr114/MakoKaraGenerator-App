台前幕后MakoKara Generator 界面设计稿，第二版

填写、选择、列表放在台前；预览和时间轴放在幕后，连成一整块。第二版改用紧凑的 Material You： 浅色、深色两套模式同构，台前用主色，幕后用第三色，全部颜色由一个主题色推出，默认从软件标志取色。 页面分区、交互和用词沿用已确认的《Web 前端设计稿》。

相对第一版

  • 不再“台前浅、幕后暗”，改为统一的浅色或深色；幕后靠第三色调的凹面区分。
  • 主色管编辑（选中、焦点、主要操作），第三色管时间（播放、播放头、逐字填充）。
  • 控件按 M3 的形状和配色重做，尺寸压紧到桌面编辑器的密度。
  • 新增设置面板：主题模式、主题色、色彩强度；新增关于对话框。
  • 顶栏左上角和关于对话框使用软件标志；字体改为 Roboto Flex，图标改为 Material Symbols。

组件库与许可

仓库计划以 GPLv3 开源。Apache-2.0 可以并入 GPLv3，但与 GPLv2 不兼容，所以许可证应写 GPLv3 或“GPLv3 或更新版本”。

库许可与 GPLv3用途
React Aria ComponentsApache-2.0兼容无样式的交互层：列表多选、拖放排序、树、带单位的数字字段、菜单、对话框、键盘操作
@material/material-color-utilitiesApache-2.0兼容Google 官方的 M3 取色和配色：从标志或任意颜色生成浅色、深色两套角色
Material SymbolsApache-2.0兼容图标，Rounded、字重 400，选中的页签用填充版；只打包用到的图标
Roboto Flex、Noto Sans CJKOFL-1.1可随附界面字体。Roboto Flex 按需子集化；时间码用它的等宽数字
react-resizable-panelsMIT兼容可拖动的分栏和底部区高度
mdui（现用）MIT兼容逐页替换，替换完再移除
Material Web（@material/web）Apache-2.0兼容，不采用官方 M3 组件，处于维护模式，尺寸难以压紧
MUI（Material UI）MIT兼容，不采用以 M2 风格为主，覆盖样式的成本比自写还高
Base UI、RadixMIT兼容，备选无样式，比 React Aria 轻；拖放和树要另找方案

建议做法。交互层用 React Aria Components，外观全部写成自己的 CSS，颜色来自 material-color-utilities 生成的 CSS 变量。 这样拿得到 M3 的观感，又不受 M3 组件尺寸的约束；mdui 可以逐页替换。

主题色。默认种子色 #019BFE 由 material-color-utilities 的取色算法从标志里取出（标志的四个候选色是 #9D41FF、#019BFE、#02E1FF、#605BFF）。 用户可以选标志色、预设色或任意颜色；渲染画面的颜色由样式模板决定，不随界面主题变化。

稿件是手写的 HTML 与 CSS，用来定方向，不是组件库的实际渲染；歌词和工程都是虚构的演示数据。 第一版的另外两份稿（暗场、歌本）已删除，可在 git 历史中查看。说明和来源见 README.md。
