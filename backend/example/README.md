# 测试样本

## 彩色棋盘格背景

`color-checkerboard-640x480.png`：640×480、无透明通道的RGB PNG；16列×12行，每格40×40像素。红／绿通道随列／行变化，蓝通道按棋盘交替，便于观察背景缩放、裁切、定位和材质效果。配色参考现有`R8WriteBackground`测试背景。

在工程中将此图片选作背景即可使用。可从仓库根目录重新生成，无第三方Python依赖：

```bash
python3 tools/generate-color-checkerboard.py
```

## 日语逐字验收样本

新建工程时，选择本目录的 `japanese-karaoke-20s.wav` 和 `japanese-karaoke-20s.lrc`。

- 音频：FFmpeg `lavfi/aevalsrc` 合成旋律、低音及节拍，120 BPM，恰好20秒；48 kHz、双声道、16位 PCM WAV，带淡入／淡出，无人声。
- 歌词：原创日语《朝の光》，UTF-8 增强 LRC，共6行、36个文字；每个文字单独标注起点，间隔0.5秒。
- 0～2秒为无歌词前奏；六行分别从2、5、8、11、14、17秒开始，最后一字从19.5秒持续到音频终点20秒。

导入时保持格式原有粒度，不需要重新切分或估算时间。LRC 的行终点由下一行起点推导，最后一行的终点取音频时长，因此应配对导入这两份文件。

已通过 `ffprobe` 和 PCM 采样检查：960000帧、时长20.000秒，音频非静音且没有削波。已用0.43.9的正式导入器核验：识别为增强 LRC，36个文字全部有时间，无缺失／估算时间、无跳过行、无导入警告或错误。
