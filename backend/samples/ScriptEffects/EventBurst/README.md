# 真实事件粒子爆发

适用于程序0.31.0；包版本1.0.0，宿主SDK／profile2保持。

完整profile2源码包，可从脚本效果工作区导入、创建event-burst实例并显式启用，保存后无需原目录，可分享为`.mkfx`。默认绑定内每次逐字起唱发射6条，不因暂停、重复预览或未来锚点查询重复出生。

anchor提供四类真实来源：token为TokenStarted的元素族；line为LinePerformanceStarted的行；cursor在逐字起唱、或无逐字时间行起唱时读取绑定内所有实际播放头；mark为前奏文字标记真正开始可见时的节点。前奏准备不触发token／line／cursor。并发起唱是不同事件，每个事件／每个锚点分别发射count条，cursor模式不会合并事件。标记无假TokenId或轨道。

count必须是0～2147483647的整数，零合法，非法小数在初始化明确失败；参数范围不是性能承诺。默认lifeUs=600000、sizePx=6、spreadPx=12、trailUs=180000、直乘颜色(1,.4,.1,.9)。世界速度固定(0,-10)px/s，出生点来自全部实例的最终文字／标记几何，旧粒子按寿命消散，固定拖尾由公共圆点呈现。全部实例共用记录、存活、拖尾和绘制预算，超限阻止导出并保护旧输出，不裁剪。

输出范围与源订阅分开；通常使用绑定源订阅。扩大订阅后，指定元素／行／标记超出输出绑定会明确失败，不偷偷扩大写权。Overlay输出burst由宿主声明／排序／计费，本包不持有粒子模拟器、系统钟或native资源。父组捕获、目标内粒子、复杂映射、完整SDK／R6和最终工作区仍按既有路线。
