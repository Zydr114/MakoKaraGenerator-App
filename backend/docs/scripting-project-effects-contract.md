# 工程效果闭包与实例存储合同

2026-10-04；R4 接续，依据已接受合同 A §3／7、ADR-0071／0100。
当前脚本目标授权代理根据既有合同决定实施细节。本文先定义本批边界，再记录验证。

## 1. 数据与职责

`Project.Effects` 是不可变源数据，保存固定包内容、按执行顺序排列的实例、模拟协议及预算。
Core 不引用 SDK、编译器或原生后端。实例保存稳定 ID、名称、启用状态、包 ID／修订、
导出 ID、封闭绑定／订阅、UInt64 种子和不可变参数 JSON。
绑定支持工程、分支、行集合、元素集合、片段集合、节点；节点显式保存 includeDescendants。
订阅支持绑定源、工程源、分支源。删除歌词、节点或片段不删除实例，失效引用作为诊断保留。

参数使用排序后的不可变 JSON 对象，不另造参数类型或范围解析器。
`EffectPackageDefinition.ResolveParameters` 继续唯一负责九类参数语义。
语法合法但范围错误的参数与编译失败的源码均可保存，以便后续修复。
结构损坏、缺少包字节或包哈希不符不能被替换成空效果工程。

## 2. JSON 与发布

程序升 0.15.0、工程 schema 23；歌词15、模板3、包profile2不变，不转换旧工程。
`project.json.effects` 必填；空工程也保存空 packages／instances。
contractVersion=1，simulation={version:1,stepHz:120,random:"pcg32-v1"}。
packages 条目保存 packageId、revision、path；path 必须等于 `effects/packages/<修订哈希>`。
instances 数组是唯一执行顺序；seed 为16位小写十六进制。绑定／订阅编码沿用合同A §3。
budgets 保存 surfaceMemoryBytes、liveParticles、trailSamples、emissionRecords、drawCommands；
初始值为536870912／20000／200000／100000／100000，均须为正整数。
其他固定图／包预算继续由现有后端校验，本批不新增另一套图协议。

每次保存先在工程内部发布完整包目录，再发布不可变歌词，最后原子替换根入口。
包目录包含规范 manifest.json 与全部声明源码／资源，排除 DLL、PDB、缓存和运行状态。
唯一暂存目录逐文件刷盘、重新读取验证修订后发布；已有修订只校验，绝不覆写。
失败只可能留下未被根引用的对象；另存为及自动备份各自携带全部包字节。
根引用路径、包目录／文件及父路径均拒绝链接；缺少、额外文件、哈希及身份不符拒绝打开。
历史目录不删除、不垃圾回收。

## 3. 编辑与运行

效果聚合可作为一次工程历史改动；同内容编辑返回原工程，引用中的包拒绝注销。
复制实例生成新 ID／种子，不复制运行状态。包升级只修改明确选择的实例。
源对象删除后的绑定仍保留，启用失效实例阻止导出；禁用实例保留诊断但不执行。
所有已启用实例进入快照指纹，普通 Render 缺少准备帧时明确失败，不能静默丢掉效果。
包加载不执行作者代码；离线编译与帧会话继续使用现有编译器和正式资源校验器。
本批持久实例先接续控制器导出；纯材质／图包可以完整注册、保存、分享，
直接实例执行与跨输出依赖计划仍须接续，不能把未支持导出当成无效果成功。
