# R7 直接图配方与模板闭包接续合同

> 施工：2026-10-05，计划程序0.37.0。R7组合审计发现可选图导出无法运行、删除最后包引用无法保存两处实际缺口。当前目标已授权按既有合同实施并记录；完成证据以roadmap为准。

## 正式图实例

直接图导出以真实包声明、修订、图句柄、固定参数和六类绑定进入现有正式会话，按当前装载向声明目标输出ImageEffects。使用宿主内置纯图求值，不生成假C#控制器、DLL或作者加载上下文；纯资源包无需C#文件，含控制器包继续严格编译其源码和完整资源，不用选择图掩盖坏源码。

CompiledFrameEffect区分真实控制器Artifact／EntryType与直接Graph声明，二者不能混用；运行代次为控制器ArtifactHash或纯图真实包Revision。现有prepared binding／失败字段ArtifactHash在直接图情况下承载包修订，PackageIdentity保留真实包／修订／图导出，不能据此宣称生成了DLL。宿主输出声明可为控制器或图，输出声明校验与正式图资源执行仍走同一条路径。

TokenFamily／Line／TextMark使用既有写权与正式部件协调、矩阵、密度、预算、透明旁路和生产图执行。组图、额外requires／跨输出依赖、同目标多个具名输出及非ColorOnly映射继续明确拒绝，不猜执行计划。Tokens读取所属行不授予行／标记／组写权。帧内不编译或解析包。

工程实例工作区可从纯图包新建禁用实例，优先复用允许的上下文绑定；不支持上下文时按声明选择合法绑定类别并尽量使用实际工程ID，无实际对象时保留禁用待修复引用。图参数、种子、订阅、顺序、复制、保存及撤销沿既有统一实例协议，材质继续经源材质字段使用。

## 候选目录与模板闭包

工坊保留当前草稿导入的候选包供选择。正式试样、添加配方校验和保存模板都按完整源材质及效果配方引用提取恰好必要的包；Core严格闭包校验保持，缺包或非法参数仍拒绝。删配方／换纯色不会删除仍被其他槽位或配方引用的包，也不会把未引用候选误写入模板。

仅导入未引用候选不产生持久模板改动。保存后仍可在当前草稿选用候选；切换模板或放弃草稿按现有协议重载模板闭包。候选本机路径和未引用字节不成为模板数据，源包文件不被删除。

## 验收与剩余

补齐真实纯图→工坊→套用→实例参数／顺序→保存／撤销／重开→独立正式预览的连续证据，并核对纯包没有DLL缓存，直接图与同参数控制器逐像素一致、真实透明旁路及门禁／失败身份。删除配方与材质替换后模板可保存，其他引用保持，未使用候选不破坏试样。
