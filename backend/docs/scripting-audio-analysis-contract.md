# 脚本基础音频分析实施合同

> 2026-10-03；**0.9.12 已实施并通过自动验证，完整 R5 尚未完成**；施工基线 0.9.11，按已接受 R0 §8.2／ADR-0071 实施 R5 的独立音频分支。设计先于代码；本批不改 JSON、程序集拆分或 UI。整行样式覆盖、组输出范围和重叠接续继续等待原提问答复。

## 1. 输入与修订

Media 复用现有流式 PCM 读取器，增加明确的固定采样率入口。分析以 48,000 Hz 单声道 float 为输入，每 960 个实际解码样本形成一个 20,000 μs hop；最后不足一 hop 仍保留。时间零点为解码音轨开头，不读播放器、UI 帧数或歌词时间。时长由实际样本数向上取整为整数微秒，不采用容器估计时长。

仅保留 hop 能量和最终只读特征，不保留整曲 PCM。源文件和规范小端 PCM 各做 SHA-256；算法版本、48 kHz、960 样本、零点及实际样本数进入分析修订。分析前后检测到文件内容变化则失败；规范 PCM 另有内容指纹。移动同一文件不改变修订。没有新增磁盘分析格式或缓存，R4～R5 再将固定修订纳入工程执行闭包。

无源为 NoAudio；未开始／尚未完成时调用方保留 NotAnalyzed；文件、探测、解码和分析失败返回 AnalysisFailed 及实际原因，不发布部分序列。取消仍抛 OperationCanceledException。空音轨、非有限 PCM、解码回报数量与实际回调数量不符明确失败，不修数据。有限浮点 PCM 不按 [-1,1] 强行截断。

## 2. v1 可视化算法

- 低频：二阶 20 Hz 高通与 200 Hz 低通串联，Q=1/√2；逐 hop RMS，经 100 ms 指数包络，按整曲最大全频 RMS 与最大低频包络二者较大值归一化。纯高音的微小滤波残余不能因此变成满低频。这是频带近似，不能声称得到硬边界完整 FFT。系数依据 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/) 的 LPF／HPF。
- Pulse：全频 hop RMS 相对前一 100 ms 指数基线的正向增量，按整曲最大增量归一化；静音保持真实零值。归一化使用离线整曲统计，不依赖播放顺序。
- 节奏：脉冲局部峰值须同时超过最大增量的 25% 和整曲最大 RMS 的 15%；峰间至少 160 ms。至少四个峰、三个连续 250 ms～2 s 间隔，按最近至多八个间隔的中位数估计周期。间隔偏差超过周期的 20% 则不给相位；confidence 由归一化平均偏差生成，仅表示近似稳定性。超过最后峰的两个周期停止估计。每点只使用不晚于该点的检测峰，不提前补未来拍点。
- BeatPhase 为距最后峰的周期余数／周期，严格 [0,1)；没有足够证据时 null、confidence=0。持续音、单个脉冲与静音不伪造拍点。参数作为算法版本固定，未新增用户设置。

完整频谱、多频带、精准拍点和高潮识别继续后置。所有公开值只走已有 AudioFeatures／AudioFeatureValues，事件沿用真实 AudioFeatureTick，不增第二套脚本音频 API。

## 3. 固定会话与 required 门禁

CompiledFrameEffect 增加组合根固定的 RequiresAudio 声明，默认 optional；这不是持久包／实例已经可导入。固定输入指纹须包含声明及分析修订。required 在初始化前检查 Available，缺失／未完成／失败使加载失败并阻止导出，使用既有 EffectFailureException。R0 未裁决音轨结束后的 required 行为：是只要求固定分析已完成，还是每个当前时刻都必须有数据，已另行询问用户，答复前不新增越界失败规则。所有查询仍明确返回 OutsideRange／Values=null，不用静音替代。

真实分析结果直接注入现有纯帧／时间线工厂。相同整数时刻下，连续播放、24／30／60 fps、直接中段、回退、独立 Export／AnchorQuery 会话读取同一序列和真实 hop 事件。分析不改源歌词、时间、节点或样式；只有作者已声明的 Style／Transforms／Overlay 帧输出进入像素。

## 4. 验收与剩余工作

必须覆盖真实解码的静音、低频／高频、规则脉冲／不规则间隔、不同源采样率、短尾、分块一致、修订稳定／输入变化、失败／取消；真实 Roslyn 作者消费分析、历史 hop 和生产样式／圆点，画面与静态等价外观／独立绘制对照。required 的初始失败须保留原因；半开查询终点明确不可用。音轨越界的 required 导出行为及其实际编码证据等待用户裁决。

完整 R2／R3～R8 保留：包、分析持久闭包、工作区加载／进度提示、完整材质／图／粒子与六包成片仍待实施。完成后在本节记录实际版本、构建、测试、像素／编码及启动证据。
