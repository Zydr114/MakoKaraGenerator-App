# UI 交互重设计与 SukiUI 全面迁移

2026-10-06。用户以“Implement the plan”批准施工；工作分支 `codex/ui-suki-redesign`，起点为已验收的 0.40.2。本文件记录新 UI 合同，完成状态仍以 roadmap 为准。

## 1. 固定决策及边界

- Adobe 式启动首页：新建、打开、最近工程和备份恢复。新建先填写工程设置；不自动进入演示工程。
- 两个常驻任务：**歌词与打轴**、**画面与样式**。高级编排、预设制作、效果编辑是主窗口内可关闭的临时工作区。
- 原生 Suki 外观：安静背景、清晰层级、少量动画。固定 SukiUI **7.0.1**、Avalonia **12.1.3**；兼容验证失败先请用户决定，不擅自更换版本或供应商。
- 基础外观即时生效、一次手势一次撤销；复杂编排、模板制作和源码维持显式草稿提交。
- 保留现有项目路径、产品程序集、领域模型、命令历史、正式渲染与资源闭包。工程／歌词／模板 schema **26／16／5**、包 profile **2**不变；程序交付递增版本，严格版本门禁仍拒绝旧工程。
- 新结构或交互取舍需用户决定；不把旧脚本待交付能力混入本轮。

## 2. 可评审原型

[可操作原型](../../design/ui-redesign-prototype.html)包含首页、两个基础任务、三个高级任务、作用范围、草稿离开检查与窄窗辅助面板。浏览器打开即可使用；它只模拟导航，不读写工程，也不是 Suki 的实际控件效果。

宽屏主框架：项目名称和保存状态／文件／撤销重做／导出 → 任务页签 → 中央编辑及辅助栏 → 共用播放控制 → 波形及任务时间块 → 反馈与可展开诊断。最低原型视口 760×640；1100 以下辅助栏默认收起，一次只打开一个，中央仍保有至少 280 logical px。最终尺寸以实际 Suki 窗口验证为准。

歌词任务：中央歌词列表，选中行展开文字、元素、独立时间、注音和翻译；拆分、合并、粘贴、导入在相邻工具条。成片预览按需展开。单来源隐藏冗余选择器，多来源和关联进入“更多”。显示真实 Missing／Estimated／校正状态。

画面任务：正式画布占主体；初始范围为“整首歌词”，切换当前行／所选文字必须明确操作并持续显示对象标题。字体、字号、两态颜色、描边、阴影、位置在第一层；渐变、资源材质、包参数按需展开。单行／双行轮换／三行及选定段落布局映射已有容器与片段，作为单个历史事务。复杂结构显示“自定义布局”；替换前说明行段、节点与关联引用影响，不能用基础布局破坏身份。

高级编排：布局 → 分配歌词段 → 时间预览，树和完整参数按需展开。预设制作：固定试样、静态属性、材质、相对配方、库与闭包分享／导入。效果编辑：相关实例和参数优先，绑定／订阅／seed／修订／源码／诊断进一步展开。

## 4. 编辑与导航合同

1. 所有工程编辑走 EditorViewModel → Execute → AdoptProject，ProjectWorkspace 是唯一工程与脏判据；UI 不复制工程状态。
2. 编辑手势开始固定工程及稳定目标，过程中合法值进入已有合并历史；失焦／释放／Enter 结束。非法文本保留并显示字段错误，渲染仍使用最后合法值。切换目标先结束手势，撤销能回到完整手势前状态。
3. 任务切换保留草稿；关闭高级页、换工程、回首页、退出走统一离开检查。分别调用编排“应用”、模板“保存”、效果“保存改动”，不以编译或运行验证替代保存。任一取消取消整次离开。
4. 异步操作固定工程身份／请求代数及取消令牌；迟到结果不覆盖另一工程或已关闭工作区。关闭等待必要释放后才卸载控件。
5. 每类高级工作区复用已打开页；上下文入口传 LineId／TokenId／NodeId／InstanceId，不传列表下标。脏稿与新入口冲突先处理已有草稿。
6. 最近工程只记录成功打开／保存后的应用级路径、名称和时间；失败不篡改最近项。缺失、坏文件及版本不一致给可读原因；不升级旧文件。

## 5. Suki 控件映射及架构

| 类别 | 固定迁移选择 |
|---|---|
| 应用样式、主窗口及全部对话窗口 | SukiTheme（Blue、zh-CN）、SukiWindow；静态安静背景 |
| 按钮、输入、菜单、选择、页签、Expander、列表、滚动 | Suki 7.0.1 自带原生模板；不复制 Semi 内部部件选择器 |
| 颜色、DataGrid | Suki 包提供的样式，Avalonia 对应包固定到当前组合 |
| 对话框和通知 | SukiDialogHost／SukiToastHost，等待结果与离开协议在 UI 层适配 |
| 波形、时间块、播放器、画布 | 本项目组合控件；复用 Timeline／Media／正式会话，不改变视频渲染 |
| 自有样式 | 仅布局、专业绘图区、语义资源和必要密度；清除 Material 模拟模板层 |

App 内新增启动首页、编辑器外壳、歌词打轴、画面属性、共享播放及高级工作区职责。导航、稳定选择上下文、离开检查、编辑手势属于 UI 层；沿用已有视图模型及编辑会话。颜色和文案集中管理，主题只保存应用级设置。

## 7. 验收

- 首页新建 → 导入／粘贴 → 打轴 → 基础外观 → 成片，无需理解容器或脚本修订。
- 局部覆盖／恢复继承／非法输入／无变化；拖动、数值输入、取色各一次撤销。
- 草稿冲突／关闭／换工程／取消／异步迟到；状态、焦点和共享播放安全。
- 注音／翻译／多来源／前奏／复杂树／模板闭包／精确实例／失败源码／恢复逐项回归。
- Linux 宽窄、长歌词及诊断、深浅主题、中文 IME、键盘／弹层、Wayland／HiDPI；Windows 单独记录。
- 新 UI 作者工程的正式 Preview 与普通／透明 Export 同帧，失败／取消／恢复保护旧输出。
- 每步全量构建／测试通过后提交推送；最终启动当前构建，用户人工验收独立记录。
