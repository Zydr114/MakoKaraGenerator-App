# R7 模板效果配方接缝合同

状态：已实施，2026-10-05，程序 0.33.0。本文只描述模板工坊与歌词行编辑器已经接通的 R7 范围；容器／组效果、完整绑定场景整合和最终人工验收仍属于后续工作。

## 1. 模板工坊入口

- 工坊只从当前草稿携带的 `EffectPackageContents` 闭包读取导出，不读取本机路径或运行时实例。
- 0.39.0 起行模板可显式选择整行或行内元素族，分别列出 `bindingKinds` 包含 `lines`／`tokens` 的控制器／图导出；元素模板固定列出包含 `tokens` 的导出。元素族导出的非 `Overlay` 输出必须为 `tokenFamily`，UI 与 Core 共同校验，见[相对目标合同](../../scripting-r7-template-target-contract.md)。0.37.0 起图导出沿真实直接图宿主路径进入正式试样，不再因没有控制器而被界面排除；图导出仍受目标、资源、参数和输出计划门禁。
- 含 `group` 输出的导出不进入选择列表；不能把组效果静默转换为行或元素效果。
- 名称、参数 JSON、包修订和导出 ID 在加入草稿前通过 `EffectPackageDefinition` 与 `StyleTemplate.Create` 严格校验。参数解析失败、包闭包缺失、绑定类型不符、重复配方和组输出均拒绝且保留原草稿与上一份预览。
- 配方按用户添加顺序保存为 `TemplateEffectRecipe`。导入包只改变草稿闭包，保存成功后才写入模板库；模板另存为、复制和重开保留同一包修订与配方身份。

## 2. 正式试样

模板工坊的中央试样不再把配方当作静态说明。`TemplateSampleFactory` 通过 `StyleTemplateApplicator.TryPreview` 把样式、模板来源、绑定和效果实例一次写入固定 `ProjectSnapshot`。有启用配方时，试样带有正式 `EffectInputsFingerprint`，并显示配方数量；失败时保留上一份可用画面。

行模板的 `TokenFamily` 配方按当前固定试样行的全部元素生成实例；元素模板只针对固定试样中的“板”字元素生成实例。这里仍只生成 Core 的正式来源数据，不在 UI 线程编译作者源码或伪造准备帧。

## 3. 歌词行／元素范围可见性

歌词行编辑器沿用 `StyleTemplateApplicator.TryPreviewTemplate`，在当前行或当前元素的模板影响说明中追加实际 `TemplateOrigin` 实例数量和配方名称。用户可以据此区分“模板包含配方”和“当前目标已经准备了哪些实例”。既有保存、应用、恢复继承和撤销语义不变。

容器／组效果仍由主画布的组图门禁管理；本批不新增模板容器字段，也不放宽 `GroupTarget` 拒绝规则。
