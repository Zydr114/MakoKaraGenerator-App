行时间和所选文字时间使用原Suki分组按钮切换，字段、清除时间、前后行、定位、试听和撤销位于播放栏上方的独立布局行。正文及窄窗预览不占用这一行；窄窗预览使用可用高度的四分之一，最大仍为96。正文使用共用8像素紧凑留白，来源/操作条使用8/4留白；均集中在UiControlMetrics，时间框130、按钮36/32及字号保持。长错误和状态完整保留并有界滚动，当前时间组不会被长表单推走。
