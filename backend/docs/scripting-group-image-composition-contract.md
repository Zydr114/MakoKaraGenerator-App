# 组图与真实父级部件合成合同

2026-11-05；0.112.13 实施合同。延续 0.25.0 的独立 C/E 与真实父树语义；SDK v2 的组准入、
完整选择像素、owner-aware Below 和空选择规则在本次接通。完成范围与实际证据见
[M09 记录](../../docs/plans/script-sdk-render-m09-evidence.md)，不以本文代替运行验收。

## 1. 真实目标与权限

正式主画布接受真实 source Group 的 ColorOnly 图。包须为 v3／SDK v2，并同时声明
`image.graph` 与 `image.graph.group`；controller 和实际 graph 均须有唯一匹配的
`ImageGraph/group` 输出，输出 requires 显式含 `image.graph.group`。无 DLL 的直接图复用
相同准入，只遍历宿主授予的可写组。额外输出能力、跨输出依赖、Base 图和 Mapping 仍拒绝。
旧包或缺新能力继续 `GroupImageEffectUnsupported`；不具备真实父树调度的单绑定执行入口
仍以该错误拒绝组，阶段 `ExecuteImageGraph`。

ImageEffects 使用真实 GroupTarget，复用工程／显式节点的组写权及运行父树后代开关；分支、行、元素、片段筛选不授予组写权。冻结退场 alias 可读取及参与渲染，不能独立获得组写权；准备目标必须为 `Kind=Group && SourceNodeId=null` 且存在对应最终几何。隐藏但存在的组仍验证身份、参数、资源和声明，同实例同目标最后绑定，原始每次写入仍验证和计费，跨实例按工程顺序。

组图与有效组透明度共同进入真实运行树隔离；子元素材质／图、整行图、子组图先完成，父图读取这些实际部件产物。绘制序仍是实际首个后代的位置，交错后代改变连续合成单位时保留具名诊断。

## 2. 独立产物与共同透明度

每个可选择层保留来源集合、实际绘制序，以及独立预乘颜色 C 和下层擦除量 E。对下层 B 应用 C+B(1−E)。同目标历史替换范围取 max，独立孩子按顺序合成；不能把跨孩子图 History 扁平地当成同目标历史。

孩子共同透明度 a 在交给父捕获前完成一次。为保留部分捕获且保持完整重组，按后续层累计擦除 S_i 做有序因式分解：

```
k_i = a (1−S_i) / (1−a S_i)
C'_i = k_i C_i
E'_i = k_i E_i
```

各有效层仍按原序合成，结果等于完整孩子 C/E 各乘 a。a=1、S_i=1 时的0/0采用k_i=0，保留透明来源身份。父配方读取共同透明度边界之后的有效部件，不复原已被上层完全遮挡的隐藏部件；固定字形覆盖仍读取原始几何，不能从处理后的颜色推算。

完整选择必须与原整组透明度路径在实际BGRA8舍入容差内相等。逐部位分解再存入 BGRA8 会
累计量化误差，因此闭合边界同时保存“先合成 C/E，再统一乘共同透明度”的完整范围产物。
只有全部成员身份及连续顺序匹配时才使用它；部分选择仍使用有效部件，不复活已遮挡部分。
成功写入使触及的完整范围失效，透明旁路与空选择保持原范围。父图继承 E、前序内容及最终
完整重组共用此选择逻辑，不能只修颜色而使擦除量退回量化部件。有效部分及保留部分各自沿
原层级完成，不再给父输入重复乘孩子透明度。父组自身透明度在自身图和保留部件重组后完成一次。

## 3. 父图、保留部件与擦除

每个输入按自己的显式配方选真实运行范围和部件；IncludeDescendantGroups 控制子组后代。父所选孩子先按独立顺序得到 C_sel/E_sel，TargetColor只传C_sel。父执行结果继承E_sel，并与本图实际替换覆盖／最终普通合成alpha取max。即使父图把颜色改为透明，已执行孩子擦除仍保留。

未选择部件照常保留，融合结果放在所选部件最高绘制层；已融合来源集合不可再只选一部分，明确拒绝。无目标输入图替换绑定范围的全部部件。透明旁路保持原部件身份、层序和擦除，不制造新融合。

父 BackdropBelow 读取进入组时的固定前缀，排除整个目标及后代；孩子读取该前缀加已完成兄弟。
普通前序 leaf 同样进入前缀；前缀保存完整 C/E，不从颜色或 alpha 反推擦除。两者都不作为 TargetColor。

真实背景在首次 BehindText 绘制前快照一次；Below 按原顺序重绘六类图元，Script 请求只排除
直接同实例 BehindText，Source 材质不排除任何脚本。图／Family 材质／Base 材质共用 resolver，
同 leaf 的各部位读取固定进入前缀，不读取自身中途结果。不同 owner 不复用过滤表面；最终
主画布保留全部真实 BehindText。已完成 Color 曾采样的图元不递归净化，不重跑作者图或媒体
provider；作者显式 BackgroundMedia 输入仍遵循其独立捕获协议。此能力不开放 target owned-overlay 捕获。

## 4. 无可见孩子的组

先验证固定图、参数、真实组、范围、声明及预算。无实际可见孩子的组不执行图，不生成凭空内容，记录具名Info诊断并消费绑定；不会漏绑定报错。图产生独立内容的通用场景元素留给后续元素类别，不以隐藏容器伪装。

真实非空组若有 active target 输入但配方选择并集为空，完整预检后记录
`GroupImageEffectNoSelectedChildren` Info 并消费，不 Execute，不改变原 C/E、来源、顺序或 owner。
只有没有 active target 输入才选择整个 scope；部分输入为空而并集非空时，空输入提供零颜色／覆盖，
其余输入照常执行。真正无可见孩子仍使用 `GroupImageEffectNoVisibleChildren`。

## 5. 资源与断代

颜色、擦除、有效层、实际下层、覆盖及图产物全部使用同一帧／会话账，分配前检查；失败、取消和退出回收所有拥有资源，借用输入不释放。固定宿主着色器随运行资源创建，帧内不编译作者源码。

固定帧限制为32层组递归、256层祖先、4096运行单元、256组绑定、256图结果、512活动来源层、
8192累计捕获／图／合成 pass。Below 重绘另有4096批次和200000实际图元／轨迹点限制；
SVG 重绘继续扣原绘制同一份 native 工作账。限额超出具名失败，不降质或截断。

本切片不迁移工程，不升级第三方依赖；能力增加限于当前 v3／SDK v2 profile。HTTP 合同、
匹配发布、浏览器及导出证据各自登记，不能由渲染测试推定通过。

## 6. 必须验证

- 真实作者包、六类绑定与Node后代开关、隐藏组身份及重复绑定。
- 独立前景无背景、孩子先处理、嵌套父子、不同逐输入配方与融合拒绝。
- 半透明重叠层有序分解：完整结果、部分捕获、端点0／1与不均匀密度。
- 独立孩子96%擦除、父透明颜色仍继承擦除、历史max与独立顺序区分。
- 部件最高层、保留注音／描边／阴影、无目标输入、透明旁路诊断／缓存。
- 原组alpha路径和静态画面不退化；共享预算、取消及归因、失败全回收。
- 正式预览与MP4／Alpha同帧，中途错误保护旧成片，固定会话重放一致。
