# R7 模板完整闭包分享与导入合同（0.40.0）

本批把已有 `StyleTemplateTransfer` 接到模板工坊的 `.mktpl` 入口，依据当前脚本目标授权决定身份冲突与关闭协议。工程／歌词／模板 schema **26／16／5**、包 profile2、作者 SDK、Shader ABI、程序集及依赖保持不变。

## 1. 分享的内容

“分享模板…”只允许当前已保存、没有模板修改或尚未提交的样式／材质／配方输入的个人模板。内置模板先复制并保存；分享不隐式保存。文件包含当前模板的静态样式、有序配方及精确包闭包，包括源材质、图、shader、图片与源码，不包含本机 DLL、工程实例、目标 ID 或临时运行状态。

正式保存对话框使用 `.mktpl` 过滤及默认扩展名。分享目标拒绝库入口、协作锁文件、受管 `packages` 子树及父目录链接，避免归档替换破坏当前库；实际库根内的独立 `.mktpl` 文件仍可使用。分享前在仓储提交锁内检查当前实际字节修订，拒绝已变化或损坏的库；随后分享已经固定的完整模板闭包，不修改库。归档使用唯一暂存文件、完整读回校验、刷盘和最后原子替换。失败或取消保护已有分享文件并清理本次暂存。

## 2. 整批导入与身份

“导入模板 .mktpl…”先处理当前修改的保存／放弃／取消，再选择文件。保存失败不继续；取消保持当前输入和预览。未提交配方必须先添加／更新或取消编辑，保存模板不会隐式提交配方；查看完全一致的已有配方不算 pending。成功添加／更新或显式取消清空作者表单并保留当前目标，失败保留输入；新建表单的候选或非默认字段也受到保护。归档严格校验当前版本、包身份、精确文件集合、路径／链接、UTF-8、资源及共享展开预算；空模板归档拒绝。

导入保留 `TemplateId`、配方 ID、相对目标、列表顺序、层和包修订。新身份追加到个人库；同身份及完整规范内容相同的项跳过，全部重复时不改索引、时间、选择或预览。同身份不同内容整批拒绝，先出现的新模板也不发布；需要独立版本时，在来源工坊显式复制为新模板并保存，不自动改 ID 或覆盖本地修改。

0.44.3按ADR-0166扩展原0.40.0的并发边界：完整合并库先通过现有编码／闭包／共享预算校验，再由应用层TemplateLibraryRepository取得同一路径的OS文件范围锁，在锁内读取完整当前库并检查调用方的预期修订。修订为实际索引字节SHA-256，缺失、空库、损坏分别处理；资源先发布，索引替换前再检查修订与取消。普通保存、删除和导入共用协议，完全重复导入也在锁内检查但不写索引。独立脚本配置库采用同一提交原语，保留自身schema。

冲突保留作者草稿、非法输入、预览及撤销历史。“刷新库”只更新目录；当前来源对象改变或被删除时，旧草稿仍不能覆盖该对象，用户可明确另存新ID副本，或重新选择库中当前版本。放弃刷新后的旧草稿采用当前保存对象，已删除则返回基线／空白。另存副本重新读取修订后提交；竞争期间再次变化仍拒绝，不无提示合并。

锁文件`index.json.commit.lock`持久保留，不删除、不替换；所有权由OS文件描述符持有，进程退出自动释放，不以文件存在判断持锁。锁只约束参加协议的应用实例；任意外部编辑器仍可能在最后字节检查与原子替换之间写入，不能宣称对外部程序有强互斥。已观察到的外部变化拒绝旧修订提交。底层Core兼容Save仅供显式离线调用，应用写入均走仓储；测试fixture直接写入不构成生产例外。

包先发布、索引最后原子替换；写盘成功后才更新工坊清单，并选择第一份实际新增模板。导入成功把该模板 ID 回传给工坊调用者；失败保护旧索引、当前选择和预览。底层失败可能留下无引用的不可变包对象，仍不公开半份模板。

## 3. 传输、取消与预览

实际传输期间禁用模板正文、保存、删除和二次传输；名称、模板选择及草稿建立也由 ViewModel 门禁。忙碌状态不把已有脏草稿误判为已保存。文件选择回来后再检查当前草稿；选择期间发生编辑不会绕过保存门禁。

关闭窗口先取消并等待正在进行的传输，再沿保存／放弃／取消协议处理草稿，之后由现有画布关闭协议释放资源。文件对话框本身没有取消 token，关闭等待它返回后停止后续传输。导入在进入库发布前检查取消；原子发布已经开始则完成该次提交，再同步清单，不留下入口与 UI 不一致的半次提交。

归档读取和库保存只处理数据，不执行作者。成功选择导入模板后，中央试样沿现有正式 Canvas／异步会话准备和渲染；作者编译或运行失败按既有诊断及旧图保护处理，Preparing 不作为运行成功。运行验证与模板分享／保存仍分开。原生验证发现旧渐变视图对非渐变字段也读取默认纯色，会在包材质模板选择时崩溃；现仅附着真实渐变字段，且只在允许编辑的字段上同步或提交，不读取包材质的虚假纯色。材质候选重建期间忽略下拉回写，空索引不覆盖当前选择，保留真实包来源与参数；材质两框填满属性栏，成功导入后仍可继续编辑。

## 4. 验证与剩余工作

定向回归覆盖完整源材质／图／C# 闭包分享、脱离原库和归档后重开、重复幂等、整批冲突、空归档、损坏／外部变化、未保存输入、发布失败、取消和旧输出保护。原生入口及最终构建／全量回归证据记录在 roadmap §18.104。

本批不收口 R7 连续组合或 R8 成片／作者文档和用户人工验收；组图／父捕获、复杂映射、跨输出及原路线高级能力保持已有门禁。既往 Roslyn 内部 Emit 间歇风险未修改运行时配置。本轮另有一次编译及程序集载入成功、`Assembly.GetType` 时报告格式非法的 `TypeLoadException`；它与 Emit 异常发生阶段不同，根因未确认，不能因定向或全量复跑通过而记为修复。
