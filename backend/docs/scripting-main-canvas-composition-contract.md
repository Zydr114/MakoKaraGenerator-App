# 主画布图效果与部件来源合同

2026-10-03。接续 ADR-0091／0092；本批按已接受 R0 的渲染职责实施，不改工程 JSON。实施状态以 roadmap 为准。

## 1. 已确认的边界

- 同目标实例依次处理当前结果。捕获逐输入选择真实部件，融合产物放在被选择部件中最高的原层级；未选择的部件保持顺序。
- **用户确认：融合来源不可拆分。** 后续任何输入或替换范围只选择一张融合图片的部分来源时，拒绝整个组合，报告需要调整效果顺序或捕获范围；不扩大配方或恢复旧字形冒充当前结果。
- **用户确认：没有目标颜色／覆盖输入的图替换目标全部部件。** 背景和资源图片输入本身不生成虚假的文字部件身份。
- 透明背景依赖旁路保留实际输入和提示；不形成新的融合层或替换范围。错误 shader 不旁路。
- 元素族先处理，再供整行图捕获。行／标记共同透明度在整个对象完成后应用一次；图捕获不逐部件乘入场 alpha。
- 下层快照取对象合成之前的真实画面，排除该对象、其孩子及尚未绘制的上层内容。同目标后续图读取同一外部下层，不能误读自身中间图。

## 2. 本批生产接缝

`SkiaRenderPipeline.Render` 消费准备帧与帧外固定程序／图片集合；不解析包、不编译 shader、不调用作者代码。缺少真实固定资源、不同修订或未支持映射必须附加真实实例失败，不能输出无效果画面。

对象的六类字形部件与融合来源属于渲染帧临时状态，不保存第二套场景。元素图所在行将这些元素的固定字形从剩余行部件中排除，避免重复绘制；整行捕获读取已处理元素产物。现有无图对象继续原绘制入口。

所有捕获、重组、图结果、真实下层快照、合成及 alpha 混合使用同一帧／会话账，失败或取消释放全部中间对象。明确框和像素密度沿用固定程序；不会超预算缩图或夹值。

## 3. 仍属后续工作

容器组图 writer／隔离、跨行父组调度、owned overlay 捕获和自身后置粒子下层排除、包材质区域绑定、非 ColorOnly 映射和最终工作区仍按原 R2～R8；本批不宣称完整 R3 出口。涉及真实运行后代而尚不能完成重组的捕获须明确失败。已有音轨外 required、optional 缺失、接续和行／元素同属性四项待答保持。

通过正式 Render 入口验证真实源码包绑定、基础填充／注音／描边／阴影保留、最高层融合、完整接续及部分融合拒绝、元素到整行读取、真实下层与历史替换范围、共同 alpha、透明旁路提示、低分辨率密度、资源／预算／取消、MP4／Alpha 同帧和中途错误保护。

## 5. 0.12.1 实施证据

正式 Render 的字形对象协调和元素→整行已实施；通用组隔离、owned overlay／自身粒子排除、区域材质及其余路线未完成。19 条新主画布用例：独立捕获部件和明确层级参照验证最高层；多输入／跨实例及部分融合拒绝；元素原 glyph 排除与独立 Style 参照；标记部件与共同 alpha；真实下层包含早先歌词／标记并排除自己；旁路不融合、诊断缓存；固定资源／实例归因／预算／取消。空部件仅在确认真实 alpha 全零后共享同一空表面，不改变来源或省略非空内容。

有图对象使用批准的独立部件层级，不承诺任意交错字形或旧一遍滤镜绘制逐字节等价；未选部件由真实捕获保留，不借静态重新改色推算图结果。无图对象严格保留原路径。每张图的实际来源／配方、色彩编码、预乘和预算规则沿用既有合同。

真实混合包、媒体玻璃→普通效果分别经正式主 Render 验证 MP4／Alpha 的第15帧与预览一致；透明报告去重；200 ms 的实际 shader 坏像素附加实例并中止编码、保护旧文件、清理临时产物。最终构建0警告／0错误，八项目2354项通过（83／1000／71／87／685／165／179／84）。日志 `/tmp/makokara-main-canvas-build-final.log`、`/tmp/makokara-main-canvas-tests-full.log`，定向记录 `/tmp/makokara-main-canvas-render-final.log`、`/tmp/makokara-main-canvas-export-second.log`。沿用缓存授权，无依赖修改或在线审查结论。
