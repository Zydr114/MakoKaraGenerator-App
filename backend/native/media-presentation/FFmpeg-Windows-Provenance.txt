This helper uses FFmpeg 9.0.2 (https://ffmpeg.org/), LGPL 2.1 or later.
The helper dynamically loads avutil-61.dll, avcodec-63.dll and avformat-63.dll.
The FFmpeg configuration enables no GPL, nonfree, or version-3 components.
The only non-system dependency compiled into those DLLs is zlib 1.4.

FFmpeg source: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz

included beside the runtime. The script lists the compiler and exact FFmpeg
configuration. These notices apply to the indicated libraries, not the app.
