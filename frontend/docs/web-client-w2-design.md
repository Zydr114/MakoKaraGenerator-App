## 2. 结构调整

### 2.1 页面与路由

`App` 维护当前页：`home`、`lyrics`，加一个“工程设置”侧边面板。不引入路由库。没有工程时，导航栏只有首页。打开工程后进入歌词页。

### 2.2 EditorSession

- **多来源缓存**：整体重读时读全部来源的行，按来源保存为 `linesByBranch`。`lines` 是当前来源的视图。逐字预览和行列表都需要关联翻译，一首歌的来源和行数都不多，全部读取的代价可以接受。
- **按行重读**：changeSet 里的行到所有来源中找下标。结构命令（正文、行操作、来源、文本单元、导入）的 changeSet 是 `requiresFullRefresh`，走整体重读。
- **建议选择**：命令响应带 `feedback.selection`、`tokenResult.selection`、`branchResult.selectedBranchId`、`importResult.selectedBranchId／selectedLineId` 时，等这次刷新完成后再应用。新行和新单元的 ID 只有刷新之后才在缓存里。
- **领域拒绝提示**：沿用 W1 的 failureCode 中文表，补上 S3 的原因：`IdentifierExhausted`、`InvalidTarget`、`InvalidCanvasSize`、`InvalidFrameRate`、`InvalidOutputDuration`、`MediaDurationUnavailable`，以及来源相关的原因。

### 2.3 波形

新增 `PeakSource` 接口：给定视口返回每列的 min／max。它有两个实现：
- **后端**：根据每列样本数选层，按 8192 桶分块懒加载，块缓存按 `waveformId` 区分。请求在途或失败时，用已加载的更粗一层顶上，块到达后重画。
- **浏览器**：沿用 W1 的解码和金字塔。只在后端返回 `available:false` 或没有 `project-sessions.waveform.read` 能力时使用。

### 2.4 逐字预览

纯 React 组件。用 `lineAt`／`tokenAt` 找到当前行，元素按 `(播放头 − 起点)／时长` 计算填充比例；注音显示在基础字上方；关联翻译按 `primaryLineId` 从翻译来源里查。每帧只更新填充比例，不触发整个页面重新渲染。

## 4. 实施步骤

每步单独提交：
1. 外壳与 EditorSession 调整（多来源、建议选择）。
2. 歌词页布局：时间栏移到底部区，逐字预览替换成片预览。
3. 行操作、正文、注音。
4. 文本单元结构：拆开、合并、排序、重切。
5. 来源管理与翻译关联。
6. 添加歌词：导入与粘贴，导入报告。
7. 工程设置。
8. 后端波形。
9. 集成测试与浏览器冒烟补齐，联调回执。

## 5. 验收

1. 歌词页的 S3a～S3d 每类命令都能在真实 Chrome 里经界面完成，并且能撤销、重做。
2. 导入文件后显示报告，问题能按源文件行号查看。
3. 来源可以新增、配置、删除，翻译行可以关联到主歌词，并在行列表和逐字预览里显示。
4. 工程设置的四组修改都能撤销；输出时长“未确定”有明确显示。
5. 后端波形与 W1 浏览器自算波形在 WAV 上形状一致；缩放到帧级时能按需加载细层。
6. 单元、集成、`smoke:browser`、`smoke:editor` 全部通过。

## 8. 已知限制

- **G13、G14 未交付**：批量删除行、批量关联翻译都是逐条发送，N 处修改产生 N 条历史（界面已写明）。
- **时间轴的翻译行轨**没有做，翻译行的时间只在行列表和行编辑区里看。
- **波形轨道是最小验证版**（用户 2026-10-16 说明）：将来可能以 TTML 为首选格式，并在波形轨道里统一支持；时间轴与波形组件预计还要扩展。现在保持峰值来源（`PeakSource`）、绘制和轨道分层，不把当前结构当定型设计。
- **波形只核对了 WAV**。MP3、FLAC 的后端峰值与浏览器播放时间基没有核对（后端规范 §6.10 也写明要各自实测）。
- **懒加载跨块**只在单元和集成测试里验证：冒烟用的 12 秒 WAV 第 0 层只有一块。浏览器解码的退路是临时关掉后端波形实跑的，没有在关闭波形能力的部署上实跑。
- **状态栏提示**会一直保留到下一条提示出现：例如“副本与下一行时间重叠”在之后的成功命令后仍然显示。
- 背景图片和视频、替换音频、工程目录列表（G12）、歌词文件导出不在 W2 范围，后端也还没有相应接口。
- 都只在无头 Chrome 里检查过；导入对话框、报告、设置抽屉的窄屏布局没有专门检查。请在日常使用的浏览器里实际导入几首歌、改几项设置。
