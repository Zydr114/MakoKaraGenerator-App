## 前端行为

沿用“台前幕后”的 React Aria 控件、紧凑尺寸、主题令牌和模板检查器布局，没有引入新的视觉体系或样式依赖。

样式库的“外观 → 颜色与描边”增加辉光组：颜色、不透明度、扩张、模糊。三个状态明确区分：

- 关闭“辉光写进模板”：不包含辉光属性，目标继续继承。
- 选择“无辉光”：包含 `glowSpec` 且写入 `glow:null`，明确关闭。
- 原模板只包含辉光叶属性：显示“部分覆盖”，保持其余属性继承；编辑某项时将该叶属性加入模板，避免界面有值而应用时被属性集合忽略。叶属性模板中的 `glow:null` 提供透明颜色、opacity 1、距离 0 的默认叶值，不误报为整体关闭。

外观页保留现有模板分配工作流。模板详情、属性来源、局部覆盖、前奏提示外观摘要均识别辉光。文本单元用途包含辉光属性。颜色 alpha 与辉光不透明度共同生效；模糊值按后端定义为高斯标准差。渲染与继承规范见[后端辉光参考](../../backend/docs/style-reference/glow.md)。
