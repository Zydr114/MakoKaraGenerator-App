# 固定脚本编译服务

`ScriptCompiler` 保留 `MakoKaraGenerator.Scripting.Compilation` 命名空间和原有编译调用，
Roslyn 实现在本项目。运行时项目 `MakoKaraGenerator.Scripting` 只保留编译边界、固定输入身份、
产物存储与固定产物消费；仅移出编译器项目尚不证明 Worker 的传递依赖已经去除 Roslyn。

同键正在执行的调用共享一次编译。等待者单独取消不会中断其他等待者；最后一个等待者取消后，
旧工作从共享表摘除并协作取消，新请求可以重新建立工作。持久缓存根相同时，还通过同键文件锁
合并不同 PID 的冷请求。`CompilationCount` 仅统计此服务实际进入 Roslyn Emit 的次数，不把指纹
相同或缓存命中当作编译次数证据。

内容键覆盖排序后的源码路径与字节、完整入口集合、编译器／选项、实际引用／SDK 字节身份、
当前执行引擎与分析规则。参数、种子和其他资源不进入编译键。产物 format 3 将输入指纹与
PE／PDB 字节摘要分开，完整警告随产物持久保存；损坏或身份错配明确拒绝，不重编译掩盖损坏，
不回退旧 DLL。失败和提交点之前已取消的工作不发布可运行目录。

内部产物默认预算为 PE 32 MiB、PDB 32 MiB、清单 1 MiB，可通过 `ScriptArtifactBudget` 配置。
它不改变既有源码输入或 4 MiB IPC 消息预算。持久缓存默认配额 256 MiB，可通过构造参数调整；
超限先淘汰未持有租约的最旧目录，仍不足则明确失败，不发布新目录。读／取用／发布／清理会在同一缓存
闸门内回收被中断发布留下的 `.build-<32位GUID>` 部分闭包；未知名称或异常文件形状不当作本存储垃圾删除。
这些是读取与发布预算；Roslyn Emit 当前先写内存流再校验，不能据此宣称编译峰值内存或 Roslyn 整体内存已受限。

租约取得、存在检查与淘汰共享同一跨进程缓存闸门。`ScriptArtifactLease` 必须覆盖使用磁盘目录的
整个期间；产物已复制到自有固定输入闭包或完全持有内存字节后可以归还。`.locks` 中有 256 个固定条带编译锁及一个缓存闸门，永久保留以避免删除锁文件造成不同 inode 的
互斥失效；失败源码不产生无界锁文件。每个现存产物最多对应一个租约文件，随产物淘汰在缓存闸门内
关闭独占租约后删除。零字节锁文件不计入编译产物字节配额。缓存根应位于
隔离 profile，不能与用户资源目录混用。Store 拒绝符号链接及非固定三文件产物闭包。

`FixedScriptArtifactProvider` 重新根据固定源码和入口计算身份并校验产物字节，没有 Roslyn 编译或
搜索旧产物的路径。真实入口反射、shader／图片／图／材质校验仍由原包执行边界负责。
