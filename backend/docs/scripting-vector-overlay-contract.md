# R6 线段与带状拖尾生产合同

> 2026-10-05；按后续计划第 4 批接续。施工中的实现与最终证据分开；完成状态以 roadmap 为准。Bridge、图片精灵、目标内捕获及完整 R6 仍继续。

## 1. 输出与顺序

OverlayBatch 为封闭中立批次协议，包含 DotBatch、SegmentBatch、TrailBatch。VisualWriter.Overlay 提供 DrawDots、DrawSegments、DrawTrails；实例身份由宿主固定，全部图元共用 OutputId 名字空间，重复或与存活发射器同名明确失败。批次按工程实例顺序、ordinal OutputId 排序，各数组内部顺序保持；BehindText／AboveText 沿现有全画布层。

宿主 CompleteOverlay 收取全部图元；旧 Complete 只接受圆点，遇到其他图元明确拒绝，不返回不完整结果。PreparedRenderFrame 固定 OverlayBatches，DotBatches 保留为圆点视图；图、材质和组透明度复制保留完整输出。自身 BehindText 提示检测全部图元，不能因使用新图元而漏报自身下层问题。

## 2. 几何和颜色

Segment 为世界逻辑坐标的两端、正有限宽度和直乘 sRGB 颜色；采用平端，不额外应用文字矩阵。零长度合法但没有面积，仍计预算。后端检查 float32 位置、正宽及外边界，不静默夹值／下溢。

Trail 为至少两个 TrailPoint（世界位置、非负截面总宽、直乘 sRGB 颜色）；零宽可表示尖端。相邻重复位置以最后样本的宽／颜色为准；全部重复没有面积但保留预算。每个截面使用相邻合法方向的单位法向和，首尾使用各自线段法向；单位法向和长度 ≤1e-12（反向及浮点消去）时断成两条带，避免法向无定义。宽度为截面的左右距离，不使用无限 miter。相邻截面以三角带连接，颜色由 CPU Skia 顶点颜色插值，颜色只预乘一次；顶点与画笔通道量化可相差 1 个 RGB 值，直带的 Alpha／几何与独立矩形逐像素相同。自交由作者路径决定，不额外去重或并为遮罩。

准备帧和正式 Render 共用不可变描述；1×／2× 和非等比密度沿最终画布缩放。没有帧内作者回调、shader 编译或新的离屏表面。

## 3. 粒子与预算

ParticleDescription.Rendering 默认 Dots，保持既有自动圆点及点状拖尾。Custom 仅关闭自动绘制，出生／解析运动／粒子视图／固定拖尾／随机／寿命／发射记录和预算全部继续；作者在纯 EvaluateVisuals 中从本实例 Particles 输出头部、线段或带状拖尾，不推进模拟。

每个圆点、每个线段、每个拖尾点各计一项，全部实例／图元共用 VisualOutputBudget；全部样本计入，即使零面积或透明，不能用单个超长 Trail 绕过预算。活粒子／固定拖尾／出生记录仍按原独立会话预算。预算、阶段、能力、包输出、无效值和 native 精度失败沿原效果失败通道阻止导出；不裁剪。

## 4. 本步验收

真实公开 C#／正式包消费；混合批次排序与名字冲突、跨实例预算、过期 writer／无能力、default 数组／非法几何／native 精度；直线／折线／重复点／尖端／反向带状输出与透明度，密度、父矩阵只应用一次；真实粒子 Custom 仍保留出生和固定拖尾，暂停／回退／24／30／60 FPS 同帧；持久包离开原目录可重开，并实际 MP4／Alpha 同帧和编码错误保护。通过后写实际证据，不以本步代替完整 R6。

## 5. 实际接续证据

VectorTrail 在保存重开的双文字工程中验证 Custom 与 Dots 的真实出生／轨迹／记录，三种 FPS 同刻全部像素、暂停／回退、独立预览及 Export 一致；实际四次视频抽帧与独立预览比较通过，四类预算及编码中途错误保持真实包来源和旧输出。Native 静态直带、折点、反向／近反向、零面积／极短路径及渐变 alpha 由独立几何和通道判据检查，精确范围见 roadmap §18.90。
