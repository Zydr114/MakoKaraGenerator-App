# R7 效果工作区场景预览上下文合同

## 范围

本合同把歌词行、歌词元素和展示树对象入口的只读画布上下文接入统一 `EffectWorkspaceWindow`。它只补足预览输入，不新增工程字段、效果实例字段、模板字段、包 profile、SDK 方法或第二套渲染器。

## 上下文来源

- 歌词行入口传入当前播放头和目标行 ID，作为无效果时的布局参考。
- 歌词元素入口传入当前播放头和所属行 ID；绑定仍只包含选中的 token ID。
- 场景对象入口传入场景编辑器当前播放头和 `SceneSpecimenLineId`；节点 ID 保留在已有 Node 绑定中。时间预览模式没有 specimen 行时，预览使用动态场景布局。
- 主窗口独立入口不传上下文，保留工作区原有从零时刻、默认全局布局预览。

上下文是 `EffectWorkspacePreviewContext` 的不可变值。初始播放头限制在工程输出范围内；工作区只公开 `PreviewTimeUs` 和有效 `PreviewLayoutLineId` 给画布。**只要快照需要效果／源材质准备帧，就使用动态时间场景，`PreviewLayoutLineId=null`**，不能将静态试样与正式准备帧混用。启用／禁用或源输入变更会通知画布和提示文案，原播放头保留；没有效果时可以恢复原布局参考。

画布请求的有效 `LayoutLineId` 参与快照、模式、质量和时刻的迟到结果门禁；显式验证也使用同一工作区请求。静态布局参考的成功或失败均不反馈工程导出门禁；动态正式预览继续按实时预览合同反馈已保存工程状态。

## 预览与持久边界

工作区仍从宿主传入的工程快照生成实例草稿快照。上下文只改变预览时刻和布局身份，不把场景草稿合并进工程，也不把节点、行或元素写入效果包。播放、拖动时间、透明模式和质量切换只改变工作区 UI 输入；保存、撤销、源码保存／编译、修订接受和导出门禁继续沿现有协议执行。

场景存在未应用或已过期草稿时，“对象效果…”禁用并提示先应用或放弃展示改动，避免工作区画面与正在编辑的树不同。入口不自动提交草稿。应用后重新打开即可使用当前节点及布局；歌词行编辑器仍使用已应用工程。

这纠正了 0.34.0 合同中“未应用新节点的绑定保存会由工程校验器拒绝”的陈述：实际工程效果保存允许保留禁用的失效绑定以供修复，不能借此推断上下文入口已经提供目标存在性门禁。本批以场景入口门禁解决这一接缝，不改已有失效实例保存协议。

## 验收

- 行／元素／节点入口保留初始播放头；无效果时使用布局参考，启用效果／源材质时与独立正式动态会话的像素一致。
- 布局身份不匹配的迟到帧不能覆盖当前画面。
- 透明、质量、诊断、宽窄切换和关闭等待沿用实时预览合同。
- 未应用场景按钮禁用，静态试样不污染导出状态，显式验证与画布使用同一有效布局。
- 工程、效果实例、模板和包 JSON schema 不变，完整组图／父捕获、跨输出和 R8 人工验收继续按原路线实施。

本批程序升至 0.35.0；实现证据记录在 `docs/roadmap.md` §18.99，语义决定见 ADR-0132。
