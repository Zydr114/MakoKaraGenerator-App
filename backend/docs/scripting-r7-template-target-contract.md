# R7 模板效果相对目标合同（0.39.0）

本合同接续模板配方编辑器，使用已有 `TemplateEffectTarget` 与套用协议。工程／歌词／模板 schema 26／16／5、包 profile2、作者 SDK 和依赖保持不变。

## 1. 作者选择与候选

行模板提供“整行”和“元素族（行内全部元素）”两个明确目标，默认整行；元素模板固定作用于所选元素族，不显示目标选择。切换模板清除尚未提交的配方编辑字段、导出选择和编辑身份，并恢复当前类型的默认目标。

整行候选要求导出支持 `lines`，元素族候选要求支持 `tokens`；两者仍只接受当前包目录中的控制器／图导出，排除组输出。元素族导出的非 `Overlay` 输出必须为 `tokenFamily`，不能借 `tokens` 绑定声明写入行或标记。UI 候选与 `StyleTemplate.Create` 都执行此门禁，保存／导入不能绕过；此前语义不合法的配方明确拒绝，不降级为静态模板。

`Overlay` 声明的 line／textMark 是图元输出类别，不是整行／标记 writer；真实粒子包仍可用于元素族配方，来源查询受 Tokens 绑定限制，图元、预算和层序沿原合同。组输出仍拒绝。

目标切换清除导出选择，用户重新选择与目标兼容的导出；编辑模式保留名称／参数输入。选择已有配方时先恢复其目标，再精确匹配包／修订／导出；缺失匹配保留该配方字段与诊断，禁用更新，不使用前一条配方的选择。目标列表保持稳定引用，避免原生下拉框重建候选时回写错误索引。配方清单同时显示作用范围。

## 2. 提交与稳定身份

添加写入当前显式目标。更新允许通过目标选择器修改作用范围，同时保持 `RecipeId`、列表位置与 `OverlayLayer`；这扩展 0.38.0 只保留原目标的编辑边界。参数与完整包闭包在提交前校验，失败保护旧配方、旧预览和旧保存版本。选择目标或导出本身不提交草稿，也不改变试样快照。

目标变更不是原工程实例的静默改绑。后续重新套用仍按已有模板来源槽 `(binding kind, target id, template id, recipe id)` 更新：旧目标来源实例移除，新目标来源实例建立；同一槽的实例 ID／seed／enabled 保持，跨目标不继承旧实例 ID／seed／enabled，新来源实例按首次套用规则启用。其他模板与直接实例保持。

## 3. 正式试样与保存

行模板的整行配方创建一个 `Lines` 实例；元素族配方按试样行全部四个元素创建四个单目标 `Tokens` 实例，来源 owner 保持行模板及试样行。元素模板仍只针对“板”字元素生成实例。正式试样、保存、重开、复制和套用共用当前配方及精确包闭包，不新增运行时或持久字段。

自动回归与原生控件证据记录在 roadmap §18.103。`.mktpl` 分享／导入 UI 已在0.40.0接通，见[模板传输合同](scripting-r7-template-transfer-contract.md)；R7 连续组合验收、R8 成片与用户人工验收继续；组图／父捕获及跨输出保持既有门禁。
