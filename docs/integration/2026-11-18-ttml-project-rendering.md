# TTML 新建工程、预览与导出修复

2026-11-18，基于 `41303bf` 在 `fix/ttml-project-rendering` 修复。产品版本仍为 **0.115.0**，HTTP 合同 **1.56.0**，工程及歌词文件结构不变。

- 新建工程先导入完整歌词，再按实际分支构造默认显示程序。创建会话前校验显示程序的关联。原问题中，歌唱者分支 `agent-v1`、`agent-v2` 替换了默认 `primary` 歌词，但显示程序仍引用 `primary`，导致固定快照和时间编辑同时被拒绝。
- 打开同格式的旧工程时，只移除没有对应来源、身份和内容均与旧版默认记录相同的唯一 `program/primary`，并报告警告。保留所有容器、其他程序、行覆盖和歌词。读取时不写盘；用户保存后才持久化修复。自定义的悬空程序仍报告错误。
- 视频导出允许纯空白元素保持 `Missing` 且无时间区间。显式区间和时间状态仍受校验，可见歌词缺时间仍会阻断导出。对照样本有三个这样的空格，分布在 `L34` 和 `L48`，均按原样保留。
