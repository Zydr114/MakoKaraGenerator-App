## 1. 范围与身份

本批从实际模板作者操作开始，经分享／导入到工程目标实例，再到保存、撤销、重开和正式会话。行模板同时包含源材质、整行图和行内全部元素族控制器；元素模板只套用选中元素。包及模板来源资源删除后，以导入库和工程闭包运行，不靠原始文件或工作区旧 DLL。

模板来源实例保持原单目标与 `TemplateOrigin` 关系；任意绑定编辑使用实际复制出的直接实例，复制按既有合同脱离模板来源，原模板实例仍可调整参数、seed 与订阅。临时副本删除、保留副本重排、一次保存和完整历史均必须实际执行，不放宽模板来源结构校验。

容器使用已支持的真实 Node 绑定及组仿射／共同透明度，不制作组模板配方。组图、父捕获、跨输出与复杂映射保持既有门禁；本批不以验收工作开放这些高级输出。

## 3. 失败与人工边界

协调器失败不得发布新像素；“旧图实际可见”必须由真实Canvas原生操作证明，不能用测试变量持有旧像素代替。未保存作者草稿的失败不阻止当前工程导出；只有与已保存工程一致的当前普通预览错误进入所有者门禁。错误保存与运行验证继续分开，重开失败源码不得使用旧DLL。

宽窄原生自动操作不替代用户人工验收；普通MP4、透明Alpha、错误中止及旧输出保护的最终人工验收仍属第6批R8。本批不宣布完整SDK、R3.1、高级输出或完整R2～R8交付。

既往Roslyn Emit与0.40.0另见的TypeLoad间歇故障均未确认根因；复跑通过不记为修复。若本批再次出现，保留具体失败阶段与失效产物，不自动归为同一原因。

## 4. 本批验证记录

### 4.1 实际故障与生产修复

1. 合法包材质模板在歌词行编辑器选择时崩溃。堆栈定位`DescribeTemplateImpact`反射读取`LyricStyle.UnsungColor`，触发`MaterialSpec.RepresentativeColor`对包材质的明确拒绝；证据为`/tmp/makokara-r7-combination-probe/template-impact-crash.log`及同名PNG。影响比较已按全部21个`LyricStyleProperty`改为typed读取；旧颜色／渐变槽比较实际完整材质，描边分别比较材质、宽度与完整结构，回退字体比较序列内容。详情、局部影响和全部套用确认共用按材质类型生成的标签，不吞异常、不伪造代表色，原token覆盖优先级及来源统计保持。
2. 首次21项定向中，16项影响比较和2项容器链通过，3项模板链在分享前失败。实际Save→Load→Encode核对发现，导入库存顺序与配方／源材质引用顺序不同，重读后顶层包数组字节漂移，误触发当前库内容核验；日志为`/tmp/makokara-0.40.1-tests-targeted.log`、`/tmp/makokara-0.40.1-r7-share-diagnostic.log`。模板资源库存及重读闭包现按`PackageId`／`Revision`的Ordinal顺序规范化；模板清单、写入属性、配方与工程实例仍保持实际有序语义。新增Core回归证明不同库存排列的编码一致、保存重读一致、包字节完整和损坏拒绝，并证明配方反序仍改变编码和实际配方顺序；不通过调整夹具导入次序掩盖生产问题。
3. 首轮完整原生链退出0后，实际PNG检查发现940×640自然窄窗的失败画布被长诊断挤到约30px，旧glyph实际不可见。保留的`compact-failure-canvas-collapse-before-fix.png`及`native-pass-before-compact-layout-fix.log`是修复前证据，不能计为窄窗失败布局已通过。预览窗格现使用`Auto,2*,Auto,*`分配标题、画布、时间控件和详情；全部状态、输入／运行错误及诊断列表进入`PreviewDetailsScroll`，保留完整文字并滚动读取。修复后的自然宽／窄布局与完整诊断复验见§4.3。

三个修复作为普通缺陷修复升PATCH0.40.1；工程／歌词／模板schema26／16／5、包profile2、作者SDK及依赖保持，未开放组图／父捕获或其他高级输出。
