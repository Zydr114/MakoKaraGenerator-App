## 1. 目标与已确认规则

主界面改为三个同级常驻工作区：**歌词与时间、模板制作、画面与样式**。

- 歌词区只编辑文本与时间；工坊制作全部外观、材质及效果预设；画面区负责应用对象和布局。
- 同一对象只应用**一个组合预设**；多个效果在预设内部组合和排序。
- 局部预设覆盖自己声明的外观属性，并继续继承上级效果；移除局部预设恢复继承。
- 工程采用预设的固定快照。修改模板库或脚本配置库不改变已有工程，更新必须明确执行。
- 高级编排作为画面区内部模式；脚本编辑作为工坊下属的独立窗口。
- 所有普通控件使用统一尺寸预设，禁止在页面或动态生成代码中任意指定尺寸。

本轮沿用 SukiUI 7.0.1／Avalonia 12.1.3、现有领域命令、历史和正式渲染能力，不扩展尚未交付的脚本 SDK。

## 2. 三个工作区的界面和行为

### 歌词与时间

中央为可直接编辑的歌词列表，默认显示文本、行起点、行终点及时间状态。选中行后内联展开逐字文本和起止时间。

- 保留导入／粘贴、拆分／合并、注音／翻译、多来源及时间关联；复杂来源设置放入“歌词来源”面板。
- 保留数值编辑、时间块拖动和微调；移除按键实时落点功能，保留播放、定位和循环操作。
- 提供独立于工程样式的中性实时预览：当前歌词、有效逐字高亮；实际行区间之外显示 `···`，不自动猜测间奏。
- 普通 LRC 的推导终点如实提示，可手动改短；缺失逐字时间不制造高亮进度。
- 保留现有增强 LRC 导出及损失提示，导出确认改为一次明确对话。
- 删除模板套用、材质、效果和样式编辑入口。错误脚本不影响歌词区播放与预览。

底部保留工程播放器、波形和时间块；预览跟随播放，文本编辑焦点不被自动选行夺走。

当前主窗口已接入 `NeutralLyricsPreview`：歌词任务显示统一 `LyricSampler` 的中性行／逐字状态，空档固定显示 `···`；切换到画面与样式或高级任务恢复正式画布。它不读取样式、场景或效果实例，属于编辑器呈现层。

### 模板制作

宽窗采用**左侧预设库、中央预览、右侧样式编辑**。首页也可直接进入，无需创建工程。

- 静态编辑包含字体、字号、字距、颜色、渐变、描边、阴影等；屏幕位置、锚点及布局归画面区。
- 材质选择未唱／已唱／描边槽位；效果列表配置相对目标、启用状态及执行顺序。一个预设可以组合基础外观、材质和多个效果。
- 工坊只描述相对对象，例如应用范围、整句、句中文字、标记，不保存当前歌曲的具体行或节点 ID。
- 预览使用工坊自己的固定试样，覆盖逐字、注音、重复词、多行、间奏、标记及测试背景／音频；通过正式渲染路径显示。
- 提供试播、暂停、重播和循环。没有工程播放条、波形、时间轴或当前歌曲歌词列表；离开工坊停止试样播放。
- 编辑即时更新有效草稿预览；非法输入保留，预览使用最后合法值。保存预设仍是明确提交。

### 画面与样式

中央为正式画布；专用面板显示**应用对象、继承来源、当前组合预设及布局**。

- 支持工程、分支、行、文字，以及已有能力支持的片段和节点；按预设能力筛选可应用对象。
- 提供选择、替换、移除、启停及手动更新预设；多选对象可一次应用。参数和源码进入工坊编辑。
- 从工程应用快照可复制到工坊继续制作，即使原模板库条目已删除。
- 布局预设只改编排，不写字体、材质或效果。

主入口不直接编辑字体、颜色、渐变、描边或阴影。模板工坊保存行／文字预设后，画面区将目标转换为稳定 `ProjectEffectBinding`，先预演影响范围，再以一条 `SetPresetApplicationsCommand` 历史提交；状态卡显示直接预设或继承来源。底层即时字段命令暂时只供旧作者窗口和兼容测试使用，不作为三工作区的第二套样式真值。

首批布局预设：

| 预设 | 槽位位置与锚点 |
|---|---|
| 单行居中 | `(50%, 75%)`，中心 |
| 卡拉 OK 双行 | `(5%, 60%)`，左侧中心；`(95%, 80%)`，右侧中心 |
| 双行居中 | `(50%, 55%)`、`(50%, 77%)`，中心 |
| 三行居中 | `(50%, 55%)`、`(50%, 66%)`、`(50%, 77%)`，中心 |

坐标相对于画布。支持整个分支或选中连续歌词段；自定义结构显示“自定义布局”。

### 高级编排与侧栏

高级编排在画面区内切换，沿用“设置容器／槽位 → 分配歌词段 → 时间预览”的顺序，保留完整树、片段、前奏和基础布局操作。

- 使用同一工程和选择上下文，保留编排草稿。
- 只呈现基础外观：不执行脚本效果；包材质使用包内声明的纯色／渐变回退。
- 明确标注“基础编排预览”；切换模式不删除实际脚本数据，正式预览和导出仍执行完整预设。
- 不显示源码、脚本参数或实例编辑入口。

取消通用“侧栏”开关，改为各工作区具名面板。宽窗常驻，窄窗通过“歌词来源”“预设库”“样式编辑”“应用对象”“布局”等按钮展开，同一时间只覆盖一个辅助面板。

## 3. 脚本窗口与保存结构

新增应用级**共享脚本配置库**。独立脚本窗口负责包导入／分享、源码修订、编译、诊断、参数和运行验证。首个生产入口已接通：配置库列表、材质／效果分类、目标／读取范围／种子／图层、源码新修订及 `.mkfx` 分享均不携带工程目标；模板工坊通过共享配置候选将材质或效果复制进自己的完整闭包。

- 分类为“材质”和“效果”；“全局”属于应用范围，不作为第三种脚本类型。
- 配置保存固定包修订、导出、参数、相对目标／输入来源、订阅和种子策略。
- 工坊选择配置后复制完整内容与资源闭包；以后更新配置库，已有模板也须明确采用新配置。
- 工程级或分支级控制器保留一个对应范围实例，不拆成逐字实例。原有计数、订阅、历史和粒子语义保持。
- 保存失败源码、编译和运行验证继续分开；不能用旧编译结果掩盖新修订失败。

新增工程内的 `PresetApplication`，记录稳定目标、预设身份与固定快照、输入对象映射、启用状态，以及配方实例身份和种子。每个具体对象最多一个直接应用记录。

- 应用记录作为真值，统一投影到现有静态样式、材质和效果执行路径；不另建编辑工程状态。
- 静态继承按工程、分支、场景层级、片段、行、文字逐级解析；效果沿用现有执行和最后写入规则。
- 相同配方更新保留实例 ID、种子和启用状态；新增配方创建新身份。
- 新增统一应用／替换／更新／移除事务，完整闭包校验成功后一次进入历史。
- 正式预览、几何计算、脚本准备和导出共用投影；基础编排使用独立预览模式和缓存标识。

第2步的发布目标 **0.42.0** 已完成；当前施工版本为 **0.43.10**，在其上补齐了对象管理、组合预设、精确布局分段、独立模板作者流程及歌词职责清理。工程 schema **28**、模板 schema **6**、脚本配置库 schema **1**；歌词 schema **16**、效果包 profile **2**保持。继续严格程序与格式门禁，旧工程和旧模板库原样保留，不转换或覆写。

## 4. 编辑安全与统一规格

- 标准文本动作和主导航使用 **36px** 高度；紧凑动作使用 **32px**。字号、留白、图标按钮、表单行和面板宽度集中定义，AXAML 与动态控件共用。
- 同一工具条只采用一种密度；专业画布、波形和时间块尺寸不套用按钮规格。
- 歌词和画面编辑使用工程历史；模板和脚本草稿拥有各自历史。一次拖动或连续输入合并一次撤销。
- 切换主任务保留草稿；保存工程与保存模板分别命名。退出统一处理保存、放弃、取消。
- 异步编译、预览和窗口回传携带会话、目标及修订标识，过期结果不能覆盖新草稿或工程。
- 文本编辑导致应用目标失效时，不静默改绑；画面区提供失效对象诊断，歌词区仍正常工作。

分段布局**精确修改选区**：必要时拆分片段，保留未选歌词布局。完整选中的片段复用原 ID；部分选中时，原 ID 留给最早的未选部分，其余部分获得新 ID。已知片段绑定同步映射到拆分结果，保留原效果实例与种子；前奏继续依靠稳定行 ID。无法安全维护引用时整次取消并说明冲突。用户已允许增加 `scheduleContext` 并将工程格式升为28：未选片段读取拆分前的有序源成员及边界引用，保留原槽位和显示时钟；不保存时间副本、不扩大实际片段成员。

## 5. 施工顺序与验收

在当前 0.41.1 上建立独立分支，按以下步骤分别验证、提交并推送同名远程分支：

| 步骤 | 实施内容 | 验收出口 |
|---|---|---|
| 1. 设计与统一规格 | 记录本轮裁决，更新三工作区原型、控件规格和功能去向；同步 ADR、项目入口和架构文档 | 三任务同级、工坊独立、脚本窗口及具名面板行为可检查；普通控件采用集中规格。已验证内容见§6 |
| 2. 预设与存储 | 预设定义、应用记录、共享配置库、统一投影及完整资源闭包 | 一个对象一个组合预设；继承、移除、手动更新、实例身份和搬移后独立性有自动证据 |
| 3. 工作区与生命周期 | 三个常驻工作区、无工程工坊、自有试播和独立脚本窗口 | 切换保留草稿；关闭／换工程／退出的保存、放弃、取消不丢状态；异步结果不串会话 |
| 4. 歌词与时间 | 中性歌词／行及逐字时间编辑，迁出样式入口，移除按键实时落点 | 文本和时间可连续编辑；真实空档、中性高亮、LRC损失确认及播放焦点符合§2 |
| 5. 画面应用与编排 | 组合预设应用、布局预设、精确分段和高级基础预览 | 布局只改编排；选区不扩张、引用受保护；模式切换不改脚本数据，正式输出保持完整 |
| 6. 清理与连续验收 | 清理重复入口和任意尺寸，更新使用文档，完成连续制作和输出验收 | 零警告构建、全量测试、宽窄／深浅真实界面及普通／透明同帧、失败／取消／恢复证据分别记录 |

后续代理先读本文，再按 ADR-0145～0155 和 roadmap §18.114起确认实际进度；`AGENTS.md` 的“先读什么”和“未完成的工作”均指向本方案。§5保留原始施工分批，当前剩余工作的执行顺序见§10。原型或局部验证不代表完整工作流已交付；施工中发现无法由既有合同决定的新结构或交互取舍时，先记录问题并询问用户。

重点验证：

- 文本／逐字编辑、LRC 导入导出、真实空档、播放焦点，以及脚本失败时的中性预览。
- 全局强调与局部玻璃外观同时生效；替换／移除／撤销／重开恢复一致。
- 删除外部配置库或模板来源后，工程仍可独立预览、分享和导出。
- 分段修改不扩大选区，复杂树、片段引用和前奏受保护；冲突没有部分写入。
- 工坊不读取当前歌曲；任务切换、草稿取消及迟到异步结果不串状态。
- Headless 检查宽窄布局、统一尺寸、长文本／诊断、深浅主题、弹层和键盘操作。
- 普通／透明正式预览与导出同帧；失败、取消、备份恢复和旧输出保护继续通过。

最终完成零警告构建和全量测试。自动验证默认后台、无窗口。2026-10-07用户在启动本目标时明确重新授权“自行启动窗口交互测试截图”，取代此前禁止窗口自动化的本轮约束；必要的真实UI验证使用专用测试窗口与隔离配置，不操作用户已有窗口，不留下后台交互循环。真实输入法、物理焦点及平台表现仍按实际证据单独记录。


## 6. 第1步实施与后续功能去向

[三工作区交互原型](../../design/ui-workspace-ownership-prototype.html)新增独立工坊、同级导航、预设固定快照／手动更新、精确选区布局确认、基础编排预览及独立脚本窗口。旧双任务原型保留为0.41.1的历史设计来源。原型不执行真实渲染、不读写工程，不能代替生产验收。

| 现有能力 | 下一步入口与职责 |
|---|---|
| 行／逐字文本、时间、拆分合并、注音翻译、LRC导入导出 | 歌词与时间的主列表与内联详情 |
| 多分支、关联及时间跟随、音频导入与已接受分析 | 歌词来源面板；工程音频能力仍走原命令 |
| 正式成片画布、输出质量、合成、背景、导出及报告 | 画面与样式；歌词区改用中性预览 |
| 工程基线、行／文字属性、材质和样式参数 | 迁入模板制作；画面区仅选择组合预设 |
| 行／元素模板、配方及.mktpl资源闭包传输 | 模板制作，扩展相对作用范围并保留固定闭包 |
| 包／源码／编译／参数／订阅／种子及.mkfx | 工坊下属独立脚本窗口和应用级共享配置库 |
| 工程／分支／Lines／Tokens／Clips／Node效果实例 | 由组合预设应用投影，不保留直接作者入口 |
| 容器／槽位／片段／树／局部变换／进入动画 | 画面区布局与内部高级编排模式 |
| 前奏标记、手工与自动候选／禁用／排除 | 高级编排，保留稳定源行与真实提示节点 |
| 工程历史、自动备份、另存为与恢复 | 原ProjectWorkspace及存储链，扩展应用快照闭包 |
| 模板／源码草稿、无效输入与迟到异步结果 | 各作者会话自己的草稿历史与统一离开检查 |

运行中冻结配置／源码编辑，底部取消始终可用。关闭等待取消和资源释放；迟到成功不能覆盖取消，编辑或选择变化使旧结果过期。保存源码、编译、保存配置和运行验证分别保留结果。新增12项及原配置7项通过，真实720帧／失败源码／中途Error／透明回退均有证据，详见roadmap §18.132及连续验收。格式、SDK与固定依赖保持；实际工程仍须验证自己的完整预设和导出。


## 21. 图形脚本参数（0.43.10）

独立脚本窗口根据当前固定包和导出生成参数面板。枚举与包内图片使用下拉、布尔使用复选框、文本使用多行框、颜色使用原生取色与精确RGBA分量、曲线使用类型／缓动及控制点。有限可操作的数值显示滑块＋文本，机器极限、固定或过宽范围仅显示文本；时长显示毫秒并保存整微秒。判定及精度规则见ADR-0162，未修改任何包声明或SDK。

加载默认值不制造覆盖；恢复单项默认只删除该键。非法输入保留且参与撤销及离开检查，最后合法值保持，保存和正式运行验证禁用；其他字段编辑不会覆盖错误草稿。连续手势复用原独立作者历史。JSON入口折叠在“高级”中，仍是同一参数覆盖，无效JSON可以修复或恢复全部默认。
