# 展示编排编辑器体验优化方案

> 日期：2026-10-01；实施基线：0.8.0／工程 v20／歌词 v15／模板 v3。
> 状态：**用户已批准“按方案实施 0.8.1”，U1～U4 已实施并获用户“测试验收通过”**。用户先前确认 0.8.0 容器、片段及轮换基本按预期生效；本轮集中处理入口、概念、操作归属和排版。槽位树内拖动改变轮换顺序已获明确确认（ADR-0066）。实施证据及最新验收记录见 §13。
> 依据：用户反馈及截图、当前 `SceneEditorControl`／主窗口入口、ADR-0065 和 [既有实施合同](scene-editor-implementation-contract.md)。本稿细化并修订 UI；已批准的原生数据、源时间、世界矩阵和历史合同继续适用。

## 1. 目标和边界

用户的操作路径明确为：**创建容器 → 配置内部布局与轮换槽位 → 创建片段并选择歌词与容器 → 查看时间预览 → 应用改动**。未单独分配的歌词由默认容器接收。

本轮交付 **0.8.1**，工程／歌词／模板 JSON 合同保持 **20／15／3**，角色从现有引用派生。精确程序版本门禁沿用现行规则。§2 的代码事实是 0.8.0 审查基线，§11～12 保留批准前的文档与原型记录，现行实现见 §13。

保留现有 Core 校验、调度、重挂矩阵和 Application 草稿历史。界面呈现变化不把槽位写成另一种歌词源类型，也不扩展脚本、图层或任意图形对象。本稿“复制容器子树”对应用户反馈中的树上“复制分支”，不复制源歌词分支。

## 2. 对照问题与现状证据

| 用户反馈 | 当前实现与原因 | 本轮改法 |
|---|---|---|
| 复选框进入、按钮退出 | `MainWindow.axaml` 将 `IsLayoutEditing` 绑定到 CheckBox；工作区 `Leave()` 使用独立按钮 | 明确的工作区入口与返回按钮，所有入口调用同一导航逻辑 |
| 槽位列表依赖预设，概念混杂 | Inspector 只有选中带 Layout 的节点才有预设选择，只有 SlotSequence 才展示列表；纯组／歌词容器／槽位均用普通树行显示 | 节点角色徽标；布局方式直接显示；预设只初始化；槽位列表独立于预设入口 |
| 新建片段两处出现 | 左栏 header 与底部 clipHeader 各创建一个同用途按钮 | 左栏只新建容器／组；片段区保留唯一主入口 |
| 默认归属和新建片段同级 | 底部将两个按钮放入同一操作栏，默认摘要也混入片段列表 | 默认容器成为有标签的固定设置行；显式片段另有列表和创建按钮 |
| “预演”难懂 | 文案同时指草稿编辑、布局静态试样、按时间查看和确认操作 | 草稿叫“未应用改动”；画面叫“预览”；确认叫“应用”；创建对话框叫“创建” |
| 树操作藏在属性底部 | Inspector 末尾创建复制／删除／上移／下移按钮；树无结构菜单或拖放 | 右键／行内菜单及树拖放；属性仅编辑参数及说明 |
| 短按钮在大栏中居中 | 通用按钮工厂没有按宿主定义水平对齐，继承主题默认呈现 | 栏内创建占满宽；面板关闭在标题右侧；字段重置右对齐 |
| 位置数字难判断范围 | 单句、槽位和容器使用近似标题，父参考尺寸说明在较后位置 | 标题先明确对象角色，位置组顶部显示父级和作用范围 |

## 3. 工作区入口与草稿操作

### 3.1 进入与返回

- 主窗口移除“容器与布局编辑”复选框，原画布工具区改为明确按钮 **“展示编排…”**。
- 分支窗口沿用入口，但名称统一为“打开展示编排”；调用同一导航命令并定位当前分支的展示根。
- 编排页顶栏左侧固定标题 **“展示编排”**，旁边显示草稿状态。
- 顶栏右侧只有 **“应用改动”／“放弃改动”／“返回歌词编辑”**。属性显示按钮移至画布工具栏，不混入工程操作。
- 返回时无草稿直接返回；有草稿使用现有离开判断，选项改名为“应用并返回／放弃并返回／继续编辑”。验证失败留在工作区，保留草稿和原因。
- 进入编排仍暂停播放。入口不成为工程字段，退出不静默应用或删除草稿。

### 3.2 术语一一对应

| 原文案 | 新文案与具体含义 |
|---|---|
| 提交改动 | 应用改动：把当前展示草稿一次写入工程历史 |
| 取消预演 | 放弃改动：丢弃当前展示草稿 |
| 按时间预演 | 时间预览：读取当前时间的实际片段及调度结果 |
| 静态试样 | 布局参考：显示供位置编辑使用的代表性文字 |
| 对话框“预览”按钮 | 创建／更新：加入草稿并立即刷新画面 |
| 预演重新分配 | 预览新的轮换分配／当前改动影响以下片段 |
| 恢复默认 | 节点“重置位置”；源句“清除本句微调”，明确作用范围 |

“应用改动”之后仍需正常保存工程。状态用“有未应用改动／改动已应用，可撤销”表达；不使用“保存成功”代替应用结果。纯查看不产生脏标记。

## 5. 容器、槽位和预设的区分

### 5.1 树和属性的对象角色

角色从现有引用推导，不新增 JSON 类型字段：

| 对象 | 树中表达 | 属性内容 |
|---|---|---|
| 纯组 | 名称＋“组”徽标 | 名称、父级、位置、参考尺寸、作用范围 |
| 自由布局歌词容器 | 名称＋“自由布局”徽标 | 节点位置、内部布局方式、内部文字位置／宽度／安全区 |
| 槽位轮换歌词容器 | 名称＋“轮换·N槽”徽标 | 节点位置、内部布局方式、槽位列表、轮换和动画参数 |
| 被 SlotIds 引用的节点 | 名称＋“槽位”徽标、轮换序号 | 本槽位置、所属布局容器链接、所有装载歌词的影响范围 |
| 未参与轮换的子节点 | 按真实角色显示，标记“未参与轮换” | 正常节点属性；不因存在于容器下就冒充槽位 |

选中槽位时不显示父容器的预设选择器；提供“返回所属容器”链接，说明轮换规则由父容器管理。选中布局容器即可直接看到当前布局方式及槽位列表，无须先套用预设。

### 5.2 显式布局方式

歌词容器属性增加一级字段 **“内部布局：自由布局／槽位轮换”**。预设单独标为 **“快速布置”**，仅提供双槽／三槽等初始参数，不承担开启功能的唯一入口。

- 新建容器对话框分别选“组／自由布局歌词容器／槽位轮换歌词容器”。槽位轮换可明确输入槽位数量，双槽和三槽快捷填入数量和初始摆放。
- 歌词容器的内部布局放在位置字段之前。槽位轮换模式直接显示列表、“新增槽位”及当前轮换顺序，列表放在调度参数前，入口不被位置长表单压住；槽位与纯组仍优先显示位置字段。
- 自由布局模式在同一位置显示“当前直接展示歌词”；切换到槽位轮换打开明确设置对话框，选择现有合格直接子节点作为槽位，或新增槽位，至少指定一个有效槽位。
- 切换为自由布局或套用快速布置前展示影响，引用更新进入草稿。原节点保留为普通未参与轮换子节点，不隐式删除；重新使用时用户明确选择，不承诺未保存的旧 SlotIds 自动恢复。
- 槽位数量、最大同屏句数、触发／保留／冲突策略分别解释。当前 Core 允许正整数同屏上限独立于槽位数量，不新增“上限必须小于槽位数”的校验；最后一个有效槽位不能直接删除。布局预设和模式切换须经过现有校验。

## 6. 树上结构操作与拖放

### 6.1 操作位置

容器树选中行提供不跳动的“⋯”菜单按钮，右键打开同一第一层菜单：

- 新建子容器（适用纯组／容器）。
- 新增槽位（仅槽位轮换容器）。
- 重命名。
- 复制容器子树／复制槽位。
- 上移／下移。
- 更改父级…。
- 删除容器子树／删除槽位（红色）。

属性栏移除复制、删除和上移／下移按钮。槽位列表也可通过对应行菜单和拖动完成结构操作。片段的编辑／删除在下方片段行菜单，属性栏保留成员、时间来源及绑定详情。

菜单启用状态依据当前节点和校验结果。引用阻止删除时解释“被哪些默认容器、片段或展示根使用”；不会为了让菜单动作成功而自动解除绑定。复制子树不复制源歌词或片段。树上的“分支”统一称“子树”，避免与源歌词分支混淆。

### 6.2 已确认的槽位顺序

用户明确答复：**“拖动槽位就改变轮换顺序”**。

- 一个槽位容器的槽位子节点按 SlotIds 的顺序显示，轮换序号与该顺序一致；树中槽位上移／下移和拖放直接调用槽位重排。
- 普通子节点继续按 Nodes 的同级顺序排列。槽位与其他子节点用清晰分组／角色说明区分；两种顺序不混在一个拖放目标中。
- 保留两个已有数据集合的独立职责。UI 读取槽位顺序时以 SlotIds 为准，不再让普通树数组顺序掩盖轮换顺序；不隐式改媒体绘制层级。
- 名称和稳定 ID 不因重排变化；轮换序号重新计算。每个相关片段都从新的第一个槽位重新分配。

### 6.3 拖放排序与重挂

- 行上／下边缘的插入线表示同父排序，提示“调整轮换顺序”或“调整树中顺序”。同一槽位组内才能做槽位排序。
- 拖入节点主体表示更改父级，预览新父级与作用范围；释放后确认“移入…，保持画面位置、旋转和大小”。调用现有重挂规则，槽位移入另一轮换容器时同步两边 SlotIds。
- 非法循环、失效根约束、原容器失去最后槽位等目标明确禁止；Esc 取消拖放，不产生草稿修改。
- 放到空白区域不推定删除或重挂到画布。更改父级菜单保留为非拖动替代操作。
- 同父无实际顺序变化保持原引用；一次拖放只是一个草稿操作，仍由顶部应用一次进入工程历史。

## 7. 片段区：创建与默认设置分层

下方固定区分三行职责：

1. **歌词来源**：明确当前设置哪个源分支。
2. **默认容器**：带标签的设置行，显示当前容器和“未单独分配 N 句”。更改动作依附这一设置，不作为另一种“新建归属”。
3. **展示片段**：列表标题右侧唯一的“＋ 新建片段”主入口。

片段行显示名称、首末源句或成员数、只读时间范围和目标容器。选中片段同步详情并高亮容器；编辑／删除在行内菜单／右键，删除后成员回到默认容器。创建对话框先选连续源句，再选已有容器，确认按钮叫“创建片段”，修改时叫“更新片段”。

若未准备适用容器，空态提示“先创建歌词容器，再分配片段”，不重复放置新建容器／新建片段按钮。默认行视觉样式与显式片段区分，不表现为可删除的普通片段。

## 8. 对齐、尺寸与响应式规则

| 部位 | 明确排版规则 |
|---|---|
| 左栏“新建容器” | 占满可用宽度，左右与树内容一致；取消居中的短胶囊 |
| 片段区创建按钮 | 标题左、创建按钮右；同一行端部对齐 |
| 属性关闭 | “对象名称／角色”标题右侧 32～36 px 图标按钮，提示“隐藏属性”；不独占一行居中 |
| 重置位置／清除微调 | 所属位置字段组的底部右对齐，小号次要按钮；不在整栏中孤立居中 |
| 布局模式切换 | 满宽的明确二选项，当前模式可见；快速布置与模式字段分组 |
| 新增槽位 | 满宽或槽位标题行右端，不挤入属性页最底部 |
| 输入与说明 | 输入满宽；并列字段等宽；标签左对齐，解释紧邻所属组 |
| 底部状态 | 只给当前操作的反馈；错误持久可见，不靠覆盖提示短暂闪过 |

宽工作区维持 224／余量／300 三栏；小于 1100 逻辑像素时左栏约 208 px、属性为 300 px 覆盖面板。关闭按钮、侧栏折叠与画布工具栏使用同一状态，宽窄切换保留用户显式选择。

1400×880／940×640 外窗检查内容区实际尺寸；顶栏允许窄区分两行，标题和操作不互相截断。下方约 150～180 px 固定片段区，三个职责保持可见，列表自身滚动。关闭属性后释放宽区列，窄区不再占用画布宽度。继续采用项目 Material You 资源与应用级主题色，不把 UI 颜色写入工程。

## 9. 已批准的代码实施路线

| 顺序 | 范围 | 主要入口／验收 |
|---|---|---|
| U1 | 工作区导航、术语、对齐、去重与默认设置分层 | MainWindow 的 XAML／导航、SceneEditorControl 与 Strings；一级入口、返回、草稿状态和所有按钮对齐 |
| U2 | 对象角色、直接布局方式、槽位列表和快速布置区分 | SceneEditorControl.Inspector／Dialogs；未使用预设也能配置槽位，作用范围及节点保留明确 |
| U3 | 树菜单、槽位顺序、拖放排序／重挂、片段行菜单 | 独立结构操作关注点，复用 SceneTreeEditor 和现有校验；树展开、滚动、选择按稳定 ID 保留 |
| U4 | 回归、实窗验收、文档和版本 | 全量 build／test；真实控件宽窄检查；新版本自动启动供人工验收 |

按关注点继续拆分 `SceneEditorControl`，结构操作不堆进属性构建函数；统一导航与对象菜单状态。App 不重新实现 Core 的轮换调度或世界矩阵。预览只读快照，来源选择不成为渲染开关。快捷键焦点区分树／画布／输入框，避免树导航箭头误微移节点。

## 10. 验收清单

- [ ] 主窗口使用按钮进入，返回操作直观；脏草稿的应用／放弃／继续路径完整。
- [ ] 当前页面及创建／编辑对话框不再用“预演”表达预览或草稿；应用与文件保存不混淆。
- [ ] 左侧只有一个主要创建容器入口；全工作区只有一个常驻新建片段主按钮。
- [ ] 默认容器有明确设置行，与展示片段的创建操作分开。
