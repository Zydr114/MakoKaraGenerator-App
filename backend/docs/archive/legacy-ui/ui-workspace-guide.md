# 0.49.4 工作区使用路线

本页对应当前三工作区施工构建。三个同级页签为“歌词与时间”“模板制作”“画面与样式”；当前页使用淡色底和底部强调线标记。程序继续执行精确版本门禁，旧版本工程原文件保持完整。完整施工合同与剩余工作见 [三工作区方案](ui-workspace-ownership-plan.md)。

当前已经接通中性歌词预览、组合预设制作／应用对象管理、独立脚本配置窗口、内部基础编排、四种布局与精确连续分段。首页独立工坊、自有试播及完整应用快照复制已接通；歌词区已完成职责清理；具名窄窗面板已接通。此前0.43.10完整长片与3369项全量及参数面板人工验收已通过，完整连续制作人工路线另记，见[连续验收](ui-workspace-ownership-acceptance.md)。当前0.49.4已补歌词卡片复用与稳定焦点、画面分段选区和整形回退，另已修复诊断重复复制／消费和报告分页、脚本历史前缀反复复制／校验、模板目录读取／失效反馈、后台备份／手工保存快照和关闭／放弃边界、导出提交、音频历史、EOF／键盘状态、库并发、作者原始输入、异步导入目标、任务保存命令、背景视频等待／取消及重复帧／循环冻结缓存，按用户要求仅构建及定向回归，见[修复验收](../acceptance/code-review-remediation-acceptance.md)。

包导入期间可继续编辑当前草稿；结果只属于发起草稿，切换目标或离开会取消它。关闭会等待读取释放，系统文件选择的迟到返回会被丢弃。同一作者一次只发起一个导入，目录、`.mkfx`及`.mktpl`共享该限制；模板闭包传输仍要求先保存或放弃当前修改。

文件菜单保存、底部保存按钮和Ctrl+S始终保存当前任务的对象：歌词／画面保存工程，模板制作保存当前模板。工程Ctrl+Shift+S另存为；工坊不提供该快捷键，也隐藏工程另存为和导出入口。编辑现有预设后使用“复制为新预设”生成新对象并保留原模板。独立脚本窗口Ctrl+S保存脚本配置；未保存源码会阻止配置保存，源码使用独立的修订保存按钮，保存不自动编译或采用。非法输入或正在离开时保存入口同步禁用；文本输入Ctrl+Z优先撤销当前输入。

自动备份在后台写完整资源，期间仍可编辑。手工保存也保留编辑入口；写入期间的新内容仍显示未保存，并提示此前快照已保存。关闭时会显示等待，等已接受写入结束后再确认；选择放弃会清理对应恢复现场，离开首页后不会由迟到备份重新建回。保存失败保留未保存状态并可重试；若工程已经写成、仅恢复标记清理失败，会分别提示。

视频背景导入先在后台探测，准备期间暂停工程操作；失败保持原背景与未保存状态，成功才写入工程历史。同一源帧重复请求和末帧冻结复用最近完整帧，半帧或取消不会被当成可用的新画面；切换循环／冻结分别采用正确的源时刻。

## 编辑歌词与时间

1. 首页新建，填写名称／画布／帧率，并选择音频和主歌词文件；歌词确认框显示识别格式与主分支。全部解析及播放准备成功后进入编辑，初始工程显示未保存；失败或取消保留原工程。也可打开当前版本已有工程／最近记录。
2. 普通TXT按非空行导入，不制造时间。追加翻译等歌词时，在“歌词来源”点击导入，明确选择已有分支或“新建歌词分支”，填写名称／角色；替换非空分支需确认影响。新分支导入可一次撤销，翻译关联及时间跟随另行设置。随后可以粘贴追加逐行文本或替换音频。没有时间的行和文字显示缺失状态，组合字和 emoji 保持完整。
3. 选中歌词行，在主窗口内修改文字及行／逐字起止时间，使用拆分、合并、注音、翻译和来源设置。非法输入在字段附近显示错误。
4. 底部工程播放与波形继续共用播放头及循环。J后退并播放、K幂等暂停、L开始播放，Space切换且长按只切一次，I/O 设置循环；文本输入获得焦点时不会触发播放快捷键。
5. 展开的实时预览只显示中性歌词和实际有效逐字状态，不运行工程脚本或读取视频样式；真实行区间之外显示 `···`。缺失逐字时间不会制造高亮进度。

替换音频后撤销／重做会同时恢复对应波形和播放源，恢复期间停止旧曲；打开无音频工程会清空旧播放。目标音频缺失或准备失败时工程及历史保留，在底部点击“重试音频加载”；错误原因见按钮提示及诊断。导入新音频准备失败则保持原可用音频。普通歌词编辑不重新加载整首音频。EOF停在末尾，播放按钮／L／Space从头重播；有效循环从入点继续，J可以退到循环入点前。

歌词区只编辑源文本、时间、注音及来源关联，样式与脚本在模板制作中编辑，预设和布局在画面区应用。`[`／`]` 不再实时打点；S/M 拆合和文字时间微调只在歌词任务生效。增强 LRC 导出损失通过一次对话确认，取消保持旧文件；关联翻译按主歌词真实区间预览。

文字卡片聚焦时尺寸和排列保持稳定；左右键选择相邻元素。源文字编辑或重排后，卡片和焦点跟随当前选中元素；拖动尚未结束时切换工程、分支或行会取消该手势，重新在当前行开始拖动。

宽窗常驻“歌词来源”，窄窗点击同名按钮展开，内容可以滚动；实时预览在窄窗编辑区下方。源表单整体滚动，文本框保持在可见的首屏。

## 制作与应用预设

“模板制作”读取应用级预设库，使用自己的固定试样和正式渲染会话，不读取当前歌曲的具体对象。首页“模板制作（无需工程）”可直接进入；模板任务隐藏工程动作、播放栏、波形和时间轴。试样可以试播、暂停、重播和循环；多行选项增加重复词、注音、真实空档和前奏标记，自有测试音频不读取当前歌曲。

1. 新建行、文字或 Composite 组合预设；在工坊编辑字体、字号、颜色、渐变、描边、阴影和材质。组合预设不声明屏幕位置与对齐，这些内容由画面区负责。
2. 工坊的“脚本工作区”打开独立窗口，配置材质或效果的固定包修订、导出、参数、相对目标、读取范围和种子。源码保存、编译／诊断、配置保存和运行验证是各自明确的动作；已有配置不会因新源码自动升级。“验证当前配置”使用自有12秒试样及普通／透明正式会话各360帧，报告固定修订、范围和诊断。报告每页最多50项，可用上一页／下一页查看，换页不截断结果。未保存源码先保存或放弃，保存新源码后还需在配置中明确选择新修订；运行期间保留取消动作，关闭等待资源释放。

   导入包并选择导出后，“脚本参数”按声明展开。绘制方式等枚举直接选下拉；有限数值可以拖动或精确输入，范围过宽／固定的值只提供文本。时长单位为毫秒，精确到0.001ms；整数不经过浮点。开关、文字、包内图片、RGBA颜色及曲线各有对应控件。默认显示不产生覆盖，“恢复默认”仅删除该项覆盖；非法输入留在原字段并禁用保存及验证，修正或撤销后继续。连续操作合并一次撤销。

   如需直接输入完整参数，展开“高级：参数JSON”；它与图形面板同步。JSON无效时先修复或“全部恢复默认”。该动作清除全部参数覆盖；仅需修复一项时请修改对应字段或JSON，未知参数错误不会被自动隐藏。

3. 在模板面板选择共享脚本配置并复制到材质槽位或效果配方；模板保存独立资源闭包。保存预设后可以分享／导入完整 `.mktpl`。
4. 切到“画面与样式”，左侧“歌词行”显示当前分支的歌词与预设状态；选分支、选行（Ctrl／Shift可多选），再在打开的预设面板选择预设并确认应用。窄窗可以继续多选，选好后点击“选择预设”进入应用面板，点击“歌词行”重新打开；视图菜单也有同名入口。进入画面任务时后台检查模板目录，新保存的预设会刷新。检查期间暂不可应用／更新；损坏或读取失败会保留上次有效列表并显示错误，可点击“刷新模板目录”重试。已有工程应用继续使用自己的固定快照。上方“整首／当前行／所选文字”选择同步实际对象；来源、片段和节点显示真实目标标题，缺失对象不会改成整首应用。中央使用完整工程的正式画布。应用对象目录提供工程、歌词来源、行、文字、片段和节点；按稳定对象选择组合预设，Ctrl／Shift可多选，一次预演和确认应用。多选时仅提供批量应用，其他操作先选定单个对象；若预设声明具名歌词来源，在预设面板明确选择实际分支，缺少或失效映射不能应用。
5. 同一对象只保留一个直接组合预设；可明确替换、启停、更新同身份预设或移除。更新保持既有实例 ID、种子和启停，移除恢复继承；全部操作使用工程撤销历史。修改库不会自动改变工程。来源卡显示上级预设名称和真实对象；未装载歌词提示等待场景，不猜未来槽位。

工坊宽窗显示“预设库／预览／样式编辑”，窄窗通过具名按钮一次打开一个辅助面板，预览仍可见。预设库分“内置模板／我的模板”页签，编辑字段局部滚动。画面区通过“歌词行／应用对象／预设库／布局／合成”按钮切换面板，目标不随面板切换改变。

工坊中的非法字号、颜色、渐变、描边、阴影或材质参数会保持原文并显示错误，预览继续采用最后合法值。修改其他合法字段不会清掉这些输入；切换材质槽也不能隐藏错误后保存。撤销／重做恢复原文与错误，一次拖动合并一次撤销。修正输入或明确放弃后才能保存；仅切换焦点不会启用未编辑的建议描边／阴影。

同时打开多个工坊或脚本窗口时，保存、删除和模板导入会检查库是否仍为本窗口读取的版本。遇到“库已变化”时草稿保持；点击库面板下方“刷新库”更新列表，原始输入和撤销历史保留。若当前模板／配置已被其他窗口修改或删除，普通保存继续受阻，可点击“另存为副本”保留当前合法草稿并取得新身份，或明确重新选择列表中的当前版本。非法输入须先修正；刷新不会替你清掉它。

画面区选择有直接预设的对象后，“复制到模板制作”把完整固定快照及资源复制为新草稿，原模板库已删除也可使用；工程应用保持不变。新保存取得新的预设身份。工坊的撤销／重做只处理自己的草稿，连续输入合并一次操作；样本目标与播放不进入历史。切换任务保留草稿，离开工坊停止试播；回首页、换工程或退出统一处理保存、放弃和取消。

## 画面区内部高级编排

从“画面与样式”的布局入口打开高级编排；画面页签保持选中，不产生第四个页签。顺序为设置容器／槽位、分配歌词段、时间预览。

画布始终标注“基础编排预览”：它保留静态预设属性和布局，不执行脚本效果；包材质使用固定包声明的纯色／渐变回退。属性面板不提供脚本实例编辑。返回“画面与样式”后显示完整效果，正式导出始终使用完整工程。

任务切换保留编排草稿。顶部“应用改动”一次提交展示历史，“放弃改动”恢复源工程；明确返回时可以应用、放弃或取消。换工程、回首页或退出会检查保留的编排草稿，即使当前已经切到其他任务；取消停止离开。

布局提供单行居中、卡拉OK双行、双行居中、三行居中四种图示。卡拉OK双行使用 `(5%,60%)` 左侧中心与 `(95%,80%)` 右侧中心锚点。可以应用整个分支，也可以勾选连续歌词段；确认窗说明影响行数及需拆分的片段数。

分段只修改选中行，未选部分继续使用原容器、槽位轮换和显示时钟。原片段身份留给最早的未选部分；前奏保留。直接片段效果和逐行／逐字族预设身份同步维护，整次修改可一次撤销。若片段应用含不能安全拆分的Application范围配方，会说明冲突并取消整次操作；可以改为选择整个片段。自定义结构仍从高级编排调整。拆分后仅改片段名称会保留原轮换，修改成员或容器会重新独立调度；编辑对话会提示这一影响。工程格式为28，旧版工程不转换。

## 导出、主题和恢复

保存工程与保存模板分别操作。普通 MP4 和透明 ProRes4444 使用独立正式会话；导出窗口提供编码、音频、诊断、进度和最终报告。失败／取消保护旧输出。

标准文本动作和主导航使用36px高度，紧凑区使用32px；新建／歌词导入正文超过统一640px窗口上限时滚动，确认与取消始终可见；帮助、诊断、取色和下拉弹层使用不透明底色。支持最小760×640逻辑窗口；当前窄窗使用具名面板，工坊与编排一次展开一个辅助面板。深浅主题和强调色属于应用设置，不改变视频样式。

首页恢复备份保留恢复现场；最近列表只保存成功打开／保存的应用级元数据。原生验证仅使用专用窗口和独立配置，证据见[连续验收](ui-workspace-ownership-acceptance.md)及 roadmap §18.123～18.133；自动截图不替代用户人工验收、真实输入法或 Windows 验证。

脚本从模板制作打开独立窗口，主窗口没有直接工程效果编辑入口。未保存源码会在关闭时单独询问；“保存源码修订”把完整包保存到本机候选库，编译失败也可保留，原配置继续使用旧修订。重开脚本窗口后可在源码包选择器选择新修订，再明确制作／保存配置。切换包或文件前先保存或放弃当前源码。取消关闭会保留窗口与草稿。

独立运行验证使用完整固定配置，不自动保存或采用源码候选；中途Error和失败源码不能报告通过，透明回退保持真实提示。试样通过仍需在实际工程检查组合预设和导出。音频导入准备失败保留旧播放，换工程／取消／新请求后的迟到结果不接入；演示初始化不清除用户编辑。当前构建验证及人工边界以[修复验收](../acceptance/code-review-remediation-acceptance.md)为准。旧0.43.6／0.43.7手测进程均已退出，日志没有退出原因，不把退出记录为产品缺陷。
