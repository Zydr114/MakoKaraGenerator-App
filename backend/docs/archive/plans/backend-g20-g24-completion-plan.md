### 2.1 G23具体边界

- 生成设置与完整候选preview复用现有领域分析；区分只读分析、设置变更和selected apply，不把preview隐式提交。
- selected apply、删除并排除自动生成、手工前奏保持与生成设置的关系须在候选阶段验证，时间冲突和陈旧目标无部分提交。
- mark配置覆盖领域已定义的编辑操作及静态Node模板映射；模板映射由独立实现批负责，与前奏生成/mark基本命令分别验收后联验。
- attachment必须基于实际文本/布局测量和已有世界外观语义实施，不能用固定参考矩形替代真实测量后宣称完成。其与G22测量接缝共用可验证输入与坐标规则。

### 2.2 G22输入与身份边界

- `scene-measurement-v1`由真实Worker执行，geometry和PNG出自同一次固定输入、同一时间与布局求值；预算、取消/生命周期、修订和目标身份均可核验。
- 明确世界角点、编辑参考及slot/line身份的坐标系和适用范围，不将编辑参考框等同字形墨迹或所有效果的最终像素边界。
- 请求原source身份与为布局测量构造的代表source身份各自给出来源及指纹。代表工程覆盖的布局测量必须标明其代表性；不得复用原SHA标签隐藏输入转换。
- 真实Worker同帧几何/PNG及代表工程为本轮验收必需；公开package/脚本/图片视频/字体完整闭包仍按第5节区分。

## 3. 后端完成验收门禁

### 3.1 每项能力必须形成可追溯闭环

每个G任务最终登记：原需求条目、对应领域能力、公共命令/读取、历史与持久化、实际渲染消费、正反例、最终提交及证据路径。源码存在、DTO存在或定向测试通过只证明相应层，不代替其他必要环节。

1. **领域及纯候选**：复用已有模型/校验，非法身份、非有限值、坏引用和时间冲突明确拒绝；失败无部分写入。需要新增模型时先补明确定义。
2. **Hosting历史**：精确revision、单Writer、一次真实变化一次历史、no-op保redo；undo/redo及重放保持稳定身份。验证并发、旧目标、取消与拒绝后的完整状态。
3. **公共合同**：严格JSON/query、required/null、大小写与判别类型；capability、权限、错误主code/failureCode、预算全部一致。完整候选、验证输入、完整读投影与回执预算在提交前检查；OpenAPI、例子、指纹与独立校验同步。
4. **真实HTTP持久化链**：公开命令/读取→核对实际状态→撤销/重做→保存→关闭→重开；验证旧修订、并发回执及失败原子性。Hosting测试不替代HTTP。
5. **Runtime/Worker证据**：对布局、动画、前奏、局部变换和运行时几何的代表输入，运行匹配Worker及真实Runtime，核对时间、坐标、可见状态与输出。需要预览/导出对应的任务提供真实PNG/成片证据；codec或快照检查不能代替像素和媒体。
6. **构建回归及Git**：每批正常solution零警告/零错误，执行受影响定向与必要模块回归，保留最终exit code/TRX/日志。代码、合同和验收按批提交并同步远程；过程失败与最终成功、定向与模块总数分列，不重复累计。

### 3.2 整体关闭判据

- 第2节所有任务均完成需求映射，真实剩余已实现或经源码与原需求证明确实不属于该任务；不能用“后续独立”挪走G20-G24本身的必需能力。
- 每项任务的后端门禁都有最终证据，跨任务代表工程完成结构→配置→前奏/局部编辑→运行时几何/实际预览→保存重开的一致修订链。
- 公开能力范围、固定预算、明确拒绝和渲染输入边界写入当前合同。所有G20-G24完成声明都应限定为本轮定义的后端能力，保留浏览器/用户和外部B3/B4范围。
- 只有完成全部任务后才更新整体完成状态；G23完成只关闭G23对应批次。

## 4. 实施顺序与批次

1. **G23基础扩展与mark模板映射**：生成设置、完整preview、selected apply、delete exclude及mark配置；静态Node模板映射由单独实现批补齐并与mark配置联验。
2. **G21/G24既有模型出口**：布局kind转换、project enter animation、line enter override及null继承；与既有program策略形成完整层级验收。
3. **G22真实Worker测量及G23 attachment**：接入 `scene-measurement-v1` time/layout、同帧geometry+PNG与代表工程，对接真实测量attachment；可独立编码，按依赖集成验收。
4. **G20-G24整体验收与合同收口**：对G20已有结构操作和所有新增能力完成代表工程、实际预览、持久化与拒绝原子性联合验收，逐项核第3节门禁后更新整体完成状态。

产品 **0.94.0**，合同 **1.24.0**；最终冻结统计按第6节实测登记。各批按代码、合同、验收和Git提交/远程同步推进，不以一个批次完成代替整体完成。

G19片段成员扩缩/拆分/合并、G25、独立时钟、关键帧及任意动画轨道均不是原G20-G24完成的前置；本轮不为它们额外制造领域模型或扩大任务。
