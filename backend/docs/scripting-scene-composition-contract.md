# 正式场景图合成合同

2026-10-03。依据已接受 R0 §6.3、ADR-0079～0080；本轮用户补充的两条规则见 ADR-0081。
本文细化实施顺序，不新增项目数据、程序集或旧工程兼容。

## 1. 已确认的行为

- 同一目标的每个效果合成规则均有效；后续 SourceOver 改色／glitch 保留前面替换下层的范围。
- 透明模式只跳过背景依赖的效果，记录每个跳过原因；其他效果继续执行。被跳过效果不产生新的替换范围。
- 配方未纳入的注音、描边、阴影照常绘制，不被删除，也不受该效果处理。
- 未授予组 writer 的权限，不能因组可捕获而开放组写入。

## 2. 合成链

每个效果先产出颜色 C；后续效果的 TargetColor 读取前一效果的颜色，不提前把下层合入 TargetColor。
同时保留所有实际执行的 ReplaceCoveredBackdrop 效果的 raw 覆盖 R。
最终只对真实下层 B 合成一次：

- 最后效果仍是替换：E = max(所有 R)。
- 最后效果是 SourceOver 或透明旁路：E = max(所有 R, C.alpha)。
- 没有任何替换：保持原 SourceOver。
- 最终结果为 `C × opacity + B × (1 - E × opacity)`。

覆盖的并集采用逐像素 max；同一字形的抗锯齿边缘不能因为多个效果叠加重复扣除。颜色不再次乘覆盖。
后续滤镜使颜色透明也不能恢复之前已替换的下层。SourceOver 颜色扩展到旧覆盖外时，颜色 alpha 仍负责普通合成。
此协议只保存已声明的替换范围；不从任意 shader 推断几何映射。MappedWarp 按独立映射合同后续实施。

同链必须属于同一时间、画布、密度和透明模式；不允许跨帧或裁掉任何历史覆盖。
所有输入、存活图产物、覆盖并集和最终合成都使用同一帧账；失败／取消释放自建产物，不夺取借用输入。
绑定级合成错误附加真实最后实例、代次、时刻和 CompositeImageGraph 阶段。

## 3. 真实背景输入

BackgroundMedia 复用正常 Render 的背景来源、整数时刻、适配和摆放规则；只包含已摆放媒体，不包含工程底色、歌词或提示。
BackgroundColor 只包含工程底色。两者均限于实际画布，画布外透明；显式捕获框和实际密度向外对齐像素网格。
媒体不存在／打不开／该时刻无帧返回 unavailable，不伪造透明图片；required／optional 由图唯一门禁处理。
透明模式不解析媒体，不提供实际底色输入；背景依赖按图的显式 bypass 处理。无背景依赖的颜色参数不受影响。

BackdropBelow 必须在调度到目标之前读取合成结果，排除目标本身及本次捕获的后代。不能用完整渲染结果反向猜测。

## 4. 正式协调器的部件和层级规则

父级图读取子级效果完成后的颜色和替换元数据；被父捕获的子级不再向主画布重复绘制。
注音、描边、阴影按捕获配方分区：纳入部分进入效果；排除部分保持原外观与位置。整张效果结果与这些保留部件怎样叠放已询问用户，答复前不以「原层次」推断新默认。
不同实例配方不同时，必须重新组装其选中部件，不把上一张整体颜色错误地当作所有配方的输入。
入场 alpha 在所属组合上应用一次；不能在子捕获后又重复乘入场 alpha。静态外观 alpha 保持原约定。
正式调度的分支／父树／原顺序与附着提示规则遵循 R0 §6.3；不改变无图绑定路径的像素与顺序。
当前 DotBatch 无所属容器元数据，不伪造它为目标自己的粒子。
