# 线段与带状粒子拖尾

适用于 0.31.0 及当前 SDK 字节。profile2 完整目录包，可从脚本效果工作区导入、创建并显式启用实例，验证会话后保存；可分享为 `.mkfx`。输出绑定与源订阅独立。

`mode` 选择宿主自动点状拖尾、作者平端线段或渐宽／渐显带状拖尾。默认 ribbon。每条合法头独立按 rate 发射；宿主保存出生点、固定采样轨迹、寿命、随机与事件记录，作者仅从本实例 Particles 读取并输出图元，不按预览帧数更新状态。速度固定为世界逻辑 (40,-25) px/s；所有图元使用最终逻辑位置，父矩阵不再乘一次。

Custom 关闭自动圆点及点状拖尾绘制，保留全部粒子／固定拖尾／出生预算；heads、path 和 cursor 是三个独立声明的输出，全部图元共用每帧预算，每条带的每个点也计入。提高 rate 或 trailUs 可能触发明确预算失败，不裁剪。

transition默认jump，可选bridge；bridgeUs=180000、bridgeGapLimitUs=2000000。桥接沿每条合法真实后继独立发射，在空档末段读取全部效果的独立最终端点；半开终点与源起唱保持，不伪造Current。旧粒子保留出生世界位置按寿命消散，桥接来源也可由纯视觉阶段绘制。本包不声明目标内捕获、复杂图映射或完整R6已经交付。色彩为直乘 sRGB，透明度只预乘一次；带状折点与原生门禁见 docs/scripting-vector-overlay-contract.md。
