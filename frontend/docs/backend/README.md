# 后端文档副本

本 App 的后端源码位于本仓库 `backend/`。`contract/` 五个文件整体复制自 `backend/web/`，行为文档 `backend-api.md` 复制自 `backend/docs/architecture/backend-api.md`。

当前合同来源：App 后端源码提交 `5549708`（2026-11-13，源码基线 `8df09c8`），冻结合同 **1.51.0**、产品 **0.112.86**、HTTP 协议 `"1"`。1.51.0 让导出与场景测量在图效果／材质需要缺失（不透明无可用媒体）或不存在（透明）的背景时照预览兜底继续：导出报告列出最多 128 条去重的兜底诊断（来源 imageEffect／material，warning 级）、受影响帧数和截断标记，三个字段同有同无，旧报告没有；导出任务结果带诊断条数；场景测量返回该帧去重后的兜底诊断；不依赖背景的工程导出字节不变。1.50.0 把单态样式换成两态静态样式：未唱／已唱两套外观（已唱的描边、阴影、辉光可跟随未唱或单独设置），描边最多 4 层（由内到外，不再有 position），擦除羽化与擦除高亮；43 项属性路径由 styles.patch／restore、模板属性、来源与前奏标记共用；移除 progress 渐变坐标；与 1.49.x 客户端不兼容，HTTP 协议仍为 `"1"`。保留 1.49.2 不透明预览缺背景媒体时的兜底与 `BackgroundMediaUnavailable` 诊断、1.49.1 试样接入宿主背景分析、1.49.0 作者草稿整份替换包内图片与字体、1.48.0 按帧检查投影、1.47.0 宿主媒体特征轨与作者源码检查。HTTP 路径／方法／schema 为 115／128／663，3926 个合成例；工程／歌词／模板 schema 为 31／19／9。匹配部署、真实 HTTP／浏览器／导出单独记录，合同同步不等于这些验收完成。

- `contract/` 不得手改；其 SHA-256 由 `contract-manifest.json` 和前端合同测试核对。升级时整体复制五个文件与行为文档，并同步 `src/protocol/index.ts` 的版本常量。
- App 根 `pnpm build` / `pnpm build:desktop` 发布本仓库匹配 Server 与 Worker，`pnpm desktop` 仅运行经过 native manifest 校验的本地部署。旧上游 artifacts 路径不再是 App 运行入口。
- 本目录其余交接、工作流和历史审查文档保留来源记录；与本仓库实时源码及冻结合同不一致时，以后者为准。
