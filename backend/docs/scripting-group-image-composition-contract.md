# 组图与真实父级部件合成合同

2026-10-04；0.25.0 实施合同。依据已接受 R0 §6.3、现有主画布／组透明度／父产物合同，以及当前目标允许代理按已有文档决策的授权。本文补齐父合同 §2 的三个边界；完成证据写入 roadmap，不预先宣布完成。

## 1. 真实目标与权限

R3 Core 首批只开放 Token／Line／Mark 的正式主画布路径。准备帧可以保留合法的 `ImageEffectTarget.Group` 扩展绑定，但在正式 Render 消费前必须明确失败，错误码为 `GroupImageEffectUnsupported`，主画布阶段为 `RenderImageEffects`，单绑定适配阶段为 `ExecuteImageGraph`；不能把组绑定报告成普通目标缺失，也不能静默回退为无效果画面。父组捕获、部件重组和透明旁路由 R3.1 接续。

ImageEffects 增加真实 GroupTarget，复用工程／显式节点的组写权及运行父树后代开关；分支、行、元素、片段筛选不授予组写权。固定包控制器和图必须各自声明 ImageGraph/group。隐藏但存在的组仍验证身份、参数、资源和声明，同实例同目标最后绑定，跨实例按工程顺序。

组图与有效组透明度共同进入真实运行树隔离；子元素材质／图、整行图、子组图先完成，父图读取这些实际部件产物。绘制序仍是实际首个后代的位置，交错后代改变连续合成单位时保留具名诊断。

## 2. 独立产物与共同透明度

每个可选择层保留来源集合、实际绘制序，以及独立预乘颜色 C 和下层擦除量 E。对下层 B 应用 C+B(1−E)。同目标历史替换范围取 max，独立孩子按顺序合成；不能把跨孩子图 History 扁平地当成同目标历史。

孩子共同透明度 a 在交给父捕获前完成一次。为保留部分捕获且保持完整重组，按后续层累计擦除 S_i 做有序因式分解：

```
k_i = a (1−S_i) / (1−a S_i)
C'_i = k_i C_i
E'_i = k_i E_i
```

各有效层仍按原序合成，结果等于完整孩子 C/E 各乘 a。a=1、S_i=1 时的0/0采用k_i=0，保留透明来源身份。父配方读取共同透明度边界之后的有效部件，不复原已被上层完全遮挡的隐藏部件；固定字形覆盖仍读取原始几何，不能从处理后的颜色推算。

完整选择必须与原整组透明度路径在实际BGRA8舍入容差内相等。有效部分及保留部分各自沿原层级完成，不再给父输入重复乘孩子透明度。父组自身透明度在自身图和保留部件重组后完成一次。

## 3. 父图、保留部件与擦除

每个输入按自己的显式配方选真实运行范围和部件；IncludeDescendantGroups 控制子组后代。父所选孩子先按独立顺序得到 C_sel/E_sel，TargetColor只传C_sel。父执行结果继承E_sel，并与本图实际替换覆盖／最终普通合成alpha取max。即使父图把颜色改为透明，已执行孩子擦除仍保留。

未选择部件照常保留，融合结果放在所选部件最高绘制层；已融合来源集合不可再只选一部分，明确拒绝。无目标输入图替换绑定范围的全部部件。透明旁路保持原部件身份、层序和擦除，不制造新融合。

父 BackdropBelow 排除整个目标及后代，孩子的下层包含在它之前实际合成的内容；两者都不作为TargetColor。自身后置粒子排除与owned overlay继续独立接续，现有明确门禁不绕过。

## 4. 无可见孩子的组

先验证固定图、参数、真实组、范围、声明及预算。无实际可见孩子的组不执行图，不生成凭空内容，记录具名Info诊断并消费绑定；不会漏绑定报错。图产生独立内容的通用场景元素留给后续元素类别，不以隐藏容器伪装。

## 5. 资源与断代

颜色、擦除、有效层、实际下层、覆盖及图产物全部使用同一帧／会话账，分配前检查；失败、取消和退出回收所有拥有资源，借用输入不释放。固定宿主着色器随运行资源创建，帧内不编译作者源码。

GroupTarget SDK协议扩展与真实父合成以MINOR0.25.0交付；工程／歌词／模板schema26／16／5及包profile2保持，无新JSON或第三方依赖，不迁移旧工程。直接图实例、跨输出、实际图像映射、owned overlay、完整粒子及作者界面仍沿R2～R8，不缩减总目标。

## 6. 必须验证

- 真实作者包、六类绑定与Node后代开关、隐藏组身份及重复绑定。
- 独立前景无背景、孩子先处理、嵌套父子、不同逐输入配方与融合拒绝。
- 半透明重叠层有序分解：完整结果、部分捕获、端点0／1与不均匀密度。
- 独立孩子96%擦除、父透明颜色仍继承擦除、历史max与独立顺序区分。
- 部件最高层、保留注音／描边／阴影、无目标输入、透明旁路诊断／缓存。
- 原组alpha路径和静态画面不退化；共享预算、取消及归因、失败全回收。
- 正式预览与MP4／Alpha同帧，中途错误保护旧成片，固定会话重放一致。
