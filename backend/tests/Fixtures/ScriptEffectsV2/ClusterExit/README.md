# SDK v2 字簇退场

固定退场寿命为 600000 微秒，在三秒上限内。`LineLoads` 提供真实装载、隐藏边界与本实例进度；
样例在源隐藏之后操作冻结副本，新的歌词继续使用原布局与槽位，不等待旧句退完。

独立文字按真实 `Clusters` 的整形单元轻微错峰上移，字族同时淡出。基础字与 Ruby 分别使用各自
完整的绘制单元，不按 UTF-16、字符或 token 边界重新切字。遇到跨 token 连字时不写 token 外观，
改为把完整行连同 Ruby 平滑移出画布，保持共享字形完整。未进入退场的装载保持源外观。

`Declare` 只准备两个只读参数；`Evaluate` 直接查询目标时刻，无回调、跨帧字段或回放依赖。
包只支持 Vulkan，支持工程、分支、行、片段和包含文字的节点绑定；以作者草稿导入、编译并显式采用。

本样例尚处于 M07 开发验收中，不能据其存在认定阶段一通过。
