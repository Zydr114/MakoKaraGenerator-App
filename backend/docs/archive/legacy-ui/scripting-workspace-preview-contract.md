# R7 效果工作区实时预览合同

> 2026-10-05，按后续计划第5批及ADR-0110／0121接续。本批实施实时画布与运行诊断；模板配方、歌词行／元素／容器入口及完整R7验收继续。实际完成证据以roadmap为准。

工作区预览消费当前工程的真实歌词、编排、媒体、已接受音频分析和效果实例草稿，经正式异步会话渲染。实例启用、参数、绑定、订阅、seed、顺序和显式接受修订改变固定输入；未提交源码文本不升级实例。保存源码形成独立修订，原实例继续固定旧修订，只有显式接受才运行新源码。新建实例仍禁用。

合法草稿自动更新画布；尚未提交的非法字段保留原文本，标明预览未更新，不能冒用最近合法值证明当前输入有效。合法但失效的绑定或启用源码／运行错误交给正式会话拒绝，画布保留最近成功图像并明确标旧结果。Preparing、Ready与Failed分别显示，旧快照／模式／质量及回退后的迟到结果不能发布。

画布提供可暂停的画面播放、秒级精确播放头、普通／透明输出和质量选择。播放不改变工程时轴或歌词数据，使用固定输入重建／重放；没有输出时长时，UI范围取真实歌词及已接受分析末端，至少5s，不写入工程。透明旁路图／材质提示与作者Info／Warning进入运行诊断列表，包含实际身份和代码；作者Error保留阶段／时刻／包修订／导出与可选源码行列。诊断定位选择真实固定包和文件，保留已有源码草稿。

保存与运行仍独立。未引用失败源码可以保存；启用失败源码也能保存用于修复，但正式导出拒绝，不回退旧DLL。尚未保存的工作区失败不禁用有效旧工程的导出；已保存且与当前工程匹配的预览失败反馈主窗口导出门禁。“验证工程效果”除校验与初始化外，还必须真正渲染当前时刻，不能把只创建会话称为整段导出验证。

宽窗口同时显示包、编辑器和预览；工作区内容宽度不足1250逻辑像素时，在编辑／预览之间显式切换，包列表保持可选。宽窄切换保留用户所选页面、源码文本及播放头。全部文案资源化，沿现有Material You角色与控件模板；不把UI状态写入工程。

关闭确认仍覆盖全部实例及源码草稿。确认离开后停止播放，取消并等待画布工作器及显式编译操作结束，再释放会话和关闭窗口；关闭后的迟到像素／诊断不反馈工程。诊断只保存不可变值，不持有作者对象、异常或native表面。C#仍遵循合作取消，不新增任意脚本强制终止承诺。

程序新增工作区能力升MINOR0.32.0；schema26／16／5、package profile2、作者SDK、程序集集合及依赖保持。组图、直接图／材质实例、复杂映射及高级输出门禁不因实时UI开放。验收需覆盖真实包像素／诊断、单实例升级及失败恢复、保存／撤销／重做、取消／关闭释放，以及宽窄实际控件操作；不以UI截图代替运行验证或用户人工验收。
