# R7 上下文效果入口合同

## 范围

本合同收口脚本效果工作区在歌词行编辑器和展示编排编辑器中的入口。入口只复用现有 `EffectWorkspaceWindow`；它不新增工程字段、模板字段、包 profile 或第二套实例编辑器。

## 入口与绑定

- 歌词行编辑器提供“本行效果…”，以当前 `LyricLine.Id` 建立 `Lines` 绑定。
- 歌词行编辑器提供“本元素效果…”，以当前 token 的 `Token.Id` 建立 `Tokens` 绑定。
- 场景对象检查器提供“对象效果…”，以选中的展示节点建立 `Node` 绑定，并默认包含该节点后代；槽位的装载与父容器规则仍由展示树决定。
- 三个入口都打开同一个脚本效果工作区，并在顶部显示上下文目标。已有同绑定实例优先选中；新建实例优先使用上下文绑定。
- 新建实例只在当前控制器导出声明支持该 binding kind 时采用上下文绑定。不支持时保留现有工作区的默认绑定，用户可在实例属性中选择合法目标；不会静默把组效果转成模板或另建包。

## 生命周期与边界

入口请求不自动启用实例、不自动保存、不自动提交场景草稿；保存、撤销、源码修订接受和实时试样仍走现有工作区协议。效果实例继续是工程级闭包，容器树仍是独立的展示数据。

目标绑定是当前编辑快照中的稳定 ID。0.34.0 的入口没有提交场景草稿，但工程效果保存允许保留禁用失效绑定，因此不能用保存协议推断未应用目标会被拒绝。0.35.0 已在场景有未应用／已过期草稿时禁用“对象效果…”并提示先应用或放弃，具体预览边界见[场景预览上下文合同](scripting-r7-scene-preview-context-contract.md)。

本批程序升至 0.34.0；工程／歌词／模板 schema 26／16／5、package profile2、SDK、Shader ABI、程序集和依赖保持不变。完整跨场景执行计划、组图／父捕获、容器效果人工验收和 R8 仍未完成。
