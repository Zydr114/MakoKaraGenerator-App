# 整行分片 Glitch（ColorOnly）

纯资源 profile2 目录包：`makokara.line-glitch`，图导出 `line-glitch`，输出目标明确为 line。
在脚本效果工作区导入，新增“整行分片位移”实例，绑定工程／分支／歌词行／clip／Node中的合法行，
显式启用并验证后保存；行模板工坊可将此图加入整行配方。新实例默认禁用，保存不代替运行验证。
本包不允许 tokens 绑定，不处理父组图。

strengthPx 默认6逻辑px（0～12），sliceHeightPx 默认12逻辑px（2～64），frequencyHz 默认8Hz（0～24）。
图一次捕获真实整行的基础字、已唱／未唱填充、描边、阴影和注音；相同横向分片一起采样位移，
而不是分别处理每个颜色部件。每个固定歌曲时间片改变水平位移，频率为0冻结时间片。
strengthPx 为0原样采样；位移绝对值不超过strengthPx，外扩 `ceil(strengthPx)`、声明最大外扩及采样偏移12px，
边界为transparent。不依赖背景，因此透明输出保留图效果。

图声明 `ColorOnly`，这是当前正式生产路径支持的像素图协议：本例位移颜色图像，
不产生实际几何映射，语义光标和粒子锚点保持准备帧真实几何，不随分片位移。
本例不声称合同中另列的 ImageOnly／MappedWarp、光标映射、目标内粒子或组图已实现。
如果后续图读取本目标，它读取按实例顺序处理的真实前一步颜色；同目标多个实例顺序会影响结果。

没有C#或DLL依赖；shader 使用 `host:timeSeconds` 和封闭数值参数，正常预览／独立导出重放得到同一分片。
SDK 1.0.0 为宿主当前精确协议值，完整SDK仍未冻结。包内文件与README摘要均进入修订，
修改后须更新manifest.json摘要；可分享 `.mkfx`，工程／模板保存后无需原目录。
