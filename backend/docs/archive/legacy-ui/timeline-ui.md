# 时间轴与歌词栏界面规格

> 本文以 0.1.0 的界面规格和历史交互为主。0.2.0 的现行时间规则见 [ADR-0050](../decisions/decisions.md#adr-0050模板工坊歌词行编辑器与程序版本边界) 和 [临时优化方案](temporary-style-line-editor-optimization.md)：已有独立行时间轨，行内元素编辑不得制造重叠，拖动已选元素边沿只改该元素。下文“共享边界同时改两侧”等旧行为不得作为当前版本验收依据。

> **0.41.0 当前入口**：共享播放和波形常驻工程底部。“歌词与打轴”显示独立行／逐字轨；画面与样式及高级工作区隐藏这两轨，保留同一播放头、缩放、吸附和循环选区。行及元素编辑已经内嵌主窗口；当前使用路线见 [工作区指南](ui-workspace-guide.md)。

- **状态**：历史规格；0.2.0 新增独立行轨与歌词行编辑器，实际完成和待验收见临时优化方案 §11
- **来源**：用户确认的形态（2026-09-25），与 `development.md` §8.1 / §8.3 / §8.4 对齐
- **相关决策**：`decisions.md` ADR-0011（对齐不变式）、ADR-0012（波形数据层）

## 1. 底部时间轴

### 1.1 轨道结构

```text
┌─ 时间轴 ──────────────────────────────────────────┐
│ 整曲 ▓░▒▓█▓▒░▓█▓▒░▓█▓▒░▓█▓▒░▓█▓▒░▓█▓▒░▓█▓▒░░▓  │ ← 缩略条（独立时间度量）
│      ░░░░░░░░░░████████████░░░░░░░░░░░░░░░░░░░  │    + 视窗框
├──────────────────────────────────────────────────┤
│ 标尺  00:10.0      00:12.0      00:14.0      00:16.0 │ ← 与下两轨同一映射
├──────────────────────────────────────────────────┤
│ 波形     ▁▃▅█▇▅▃▁▂▄▆█▇▅▃▁▂▃▅▆▇▆▅▃▂▁▂▃▄▅▆▇█▇▅▃▂▁ ▂ │
├──────────────────────────────────────────────────┤
│ 逐字块 ┌─────┐┌───────────┐┌────────────┐┌─────┐ │
│        │  夜 ││   空中    ││  最亮的    ││  星 │ │
│        └─────┘└───────────┘└────────────┘└─────┘ │
└──────────────────────────────────────────────────┘
高度：缩略 28 + 标尺 22 + 波形 60 + 逐字块 56 = 166 px
```

### 1.2 各轨道职责

| 轨道 | 时间度量 | 职责 |
|---|---|---|
| 缩略条 | **独立**（整曲压缩进视口宽度） | 显示整曲波形、当前视窗框；接受拖拽/点击定位 |
| 标尺 | 与波形轨、逐字块轨**共用** | 时间刻度与时间码标签 |
| 波形 | 与标尺、逐字块轨**共用** | 峰值包络、播放头 |
| 逐字块 | 与标尺、波形轨**共用** | 每个文本元素一个色块，块内显示文本；拖边界改起止，拖中心整体平移 |

## 2. 对齐不变式（硬性要求）

用户明确要求：**任取一个时间点（逐字块首尾、波形上任意位置），都必须在波形轨与逐字块轨上对齐；标尺也要跨轨道对齐；缩略条不参与。**

落实为 5 条不变式：

1. 存在唯一的 `TimeAxis.TimeToX` / `TimeAxis.XToTime`，标尺、波形采样、逐字块定位、播放头、命中测试**全部**走它。
2. 三条主轨道的 `Left` 与 `Width` **完全相同**，不允许任何一条有自己的内边距或滚动偏移。
3. 同一个时间在三条轨道上得到同一个 x；同一个 x 在三条轨道上解析出同一个时间。
4. 播放头是**一条**跨轨竖线（一个 x 值）。
5. 缩略条使用独立的 `OverviewAxis`，只通过"视窗框"与主视图联系。

### 2.1 实现机制

不变式不靠"调像素"保证，而是由结构保证：

```text
TimeAxis          时间↔像素的唯一映射（值类型，不可变）
TimelineLayout    轨道矩形 + 共享的 TimeAxis + 独立的 OverviewAxis
                  AllMainLanesShareHorizontalExtent 为自检属性
```

控件**不得**自行计算这些值，必须通过 `TimelineLayout` 取矩形与映射。

### 2.2 测试位置

| 文件 | 覆盖 |
|---|---|
| `tests/.../Timeline.Tests/TimeAxisTests.cs` | 映射、往返、单调性、锚点缩放、钳制、吸附 |
| `tests/.../Timeline.Tests/TimelineLayoutTests.cs` | 三轨同水平范围、命中与绘制同映射、缩略条独立性、视窗框 |

## 3. 交互

### 3.1 缩放与平移

| 操作 | 行为 |
|---|---|
| 鼠标滚轮 | 以**鼠标位置为锚点**缩放；锚点处的时间保持不变 |
| Ctrl + 滚轮 | 量化缩放档位（后续） |
| 中键拖动 / 空白处拖动 | 平移 |
| 缩略条拖动视窗框 | 平移主视图 |
| 缩略条点击 | 把点击处的时间居中 |
| `F` | 聚焦当前歌词行的区间（`TimeAxis.ShowingRange`） |

### 3.2 逐字块编辑

| 操作 | 行为 |
|---|---|
| 拖左/右边界 | 改该元素的起点/终点 |
| 拖块中间 | 整体平移，时长不变 |
| 多选后拖动 | 整体平移 |
| 双击块 | 原地输入精确时间 |
| `S` | 在光标/选中边界处拆分元素 |
| `M` | 合并相邻选中元素 |
| `←` / `→` | 按帧移动播放头 |
| `Shift` + `←` / `→` | 按较大步长移动 |
| `I` / `O` | 设置选区起点/终点 |
| Space | 播放/暂停 |

### 3.3 吸附

`TimeSnapMode`：`None` / `Millisecond` / `Frame`，默认帧吸附（跟随项目帧率）。
节拍吸附需要 BPM 与拍号信息（`development.md` §18 待决策第 11 项），暂不提供。

### 3.4 越界与重叠

- 元素超出所属行范围：**高亮**，不静默裁切（`development.md` §8.3）
- 元素之间重叠：高亮并在状态栏提示（校验器的 `OverlappingElements` 警告）

## 4. 左侧歌词栏

### 4.1 形态

- 列表**始终显示全部歌词行**（不丢全局视野）
- 点击某行 → 该行**下方就地展开**一条逐字块编辑条（再点收起）
- 展开区与底部时间轴的逐字块轨**选中状态双向同步**
- 展开区里的逐字芯片**只显示字**，时间在芯片的提示（`ToolTip`）里；行本身仍在第二行显示时间
- 歌词栏底部是**当前对象样式摘要 + 「打开样式」**入口（跳到右侧样式工作区）与元素时间编辑区
- 选中元素使用时间轴与歌词栏的选中高亮识别；字幕画面只按未唱/已唱两种样式渲染，
  不为当前元素设置独立颜色

```text
┌─ 歌词行 ────────────────┐
│ 01  夜空中最亮的星       │
│ 02  请照亮我前行         │  ← 选中：展开
│     ┌──┐┌──┐┌────┐┌──┐  │
│     │夜││空││中最││亮│  │  ← 芯片，可点选
│     └──┘└──┘└────┘└──┘  │
│     [S 拆分] [M 合并]    │
│ 03  🏳️‍🌈 emoji 与 café    │
└──────────────────────────┘
```

### 4.2 切分与时间的分工

这是两条**互不共用同一个手势**的操作：

| 目标 | 手段 |
|---|---|
| 改**切分方式**（哪些字属于同一个元素） | 芯片选中 + `S` 拆分 / `M` 合并；或双击边界 |
| 改**时间**（元素的起止时刻） | 拖逐字块边界（时间轴上），或在展开区的芯片上拖边界 |

## 5. 与数据层的接口

```text
音频文件
   │  AudioWaveformLoader（Media 层，内部用 FFmpeg，界面不可见）
   ▼
WaveformPeakPyramid   多分辨率峰值；GetPeak(startSample, endSample) 自动选层
   │
   ▼
TimeAxis              时间↔像素唯一映射（Timeline 层，无 Avalonia）
   │
   ├─→ 波形轨：逐像素列算 GetPeak
   ├─→ 逐字块轨：每个元素算 TimeToX
   └─→ 标尺：按刻度间隔算 TimeToX
```

界面层只接触 `WaveformPeakPyramid` 与 `TimeAxis`，不出现 `ffmpeg` / `ffprobe` 字符串。

## 6. 已知限制

- 样式操作统一在右侧「样式工作区」完成：内置／我的样式分栏、会话草稿和应用目标集中在同一提交区；
  歌词栏只保留当前对象摘要与打开工作区入口。本文件描述的时间轴与歌词栏规格不变。

| 限制 | 说明 |
|---|---|
| 峰值分辨率下限 | 第 0 层桶大小 64 采样（44.1 kHz 下约 1.45 ms）。放大到更细时返回所在桶的峰值，界面应提示已达分辨率上限，而不是让用户以为看到精确波形 |
| 整曲峰值一次性构建 | 一首 5 分钟歌曲约 1.6 MB（金字塔），可接受；更长的文件需要改成分段缓存 |
| 窗口尺寸 | 默认 1400×880、最小 940×640。早期"窗口必须小于屏幕逻辑尺寸，否则顶部被挤出屏幕"是**误判**——真因是 Skia 绘制没先 `ClipRect` 就 `Clear`（ADR-0015） |
| 铺满整曲只算一次 | 装载时按当时宽度计算（`F` 可重新聚焦当前行）；窗口被 WM 改尺寸后不会自动重新适配 |
| 元素无时间时不显示 | 时间缺失/非法的元素不出现在时间轴上（这是有意的，见 `TimelineTokenBlocks.FromLyrics`） |

## 7. 交互与快捷键

| 操作 | 效果 |
|---|---|
| 滚轮 | 以指针为锚点缩放（指针下的时刻不动） |
| Shift + 滚轮 / 中键拖 / 空白处拖 | 平移 |
| 拖播放头（标尺或波形轨上，±5 px） | 移动播放头；播放头只在标尺与波形轨可抓，逐字块轨上优先选块/拖块 |
| 拖块边界 | 改该元素起止；共享边界会同时改两侧（见 §5） |
| 拖块中心 | 整体平移，时长不变 |
| 点标尺 / 波形 | 定位播放头 |
| 点缩略条 | 把主视图移到该处（不改播放头） |

| 快捷键 | 效果 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 微调**选中元素**（Shift 为 10 帧）；没有选中元素时移动播放头 |
| `[` | 把选中元素的**起点**记为播放头位置（元素原本没有时间时，终点暂按一帧占位并标为"估算"） |
| `]` | 把选中元素的**终点**记为播放头位置，并自动跳到下一个元素 |
| S / M | 拆分 / 合并选中元素（按 Unicode 文本元素切，不按 UTF-16 char） |
| F | 把主视图聚焦到当前行的时间区间 |

## 8. 歌词栏

- **行排版是两行**：
  - 第一行：`序号`（小字、变淡、右对齐固定宽度）+ **歌词文本**
  - 第二行：`起始时间 → 终止时间`（更小字号 + 更淡），左对齐悬挂在序号之下
- **歌词文本本身就是展开/收起的按钮**（不再画三角）：
  文本单行显示，超宽时截断成省略号（`TextWrapping=NoWrap` + `TextCharacterEllipsis`）。
  点击时以"用户看到的状态"取反——因为改选中会顺带把行展开，
  若先选中再对当前值取反，第一次点"展开"反而会收起。
- 点行内其他位置（例如时间行、空白）只做选中并且保证展开，永远不会在那里收起
  （早期实现让"点已选中的行"也收起，点行内空白、点芯片间隙都会误触发，看起来就是随机）。
- 注意：`Button` 默认会继承主题的<b>强调色</b>，把歌词文本做成按钮后必须显式指定前景色，
  否则文本会变成蓝色，在选中行的蓝底上几乎看不清。
- 历史教训：早期用 `TextBlock` 画三角、靠"事件源向上找名为 `RowToggle` 的控件"判断点击——
  这条路径**不可靠**：控件只有绘制出来的内容处才可被命中，点在同一控件内的空白处会让
  事件源变成外层 `Border`，向上找名字就永远找不到三角。结论是**不要用"名字向上查找"判定点击目标**。
- 点芯片 = 选中该元素，并与时间轴选中**双向同步**。
- 面板底部是**元素时间编辑区**：起点 / 终点两个可输入时间码的文本框、只读时长、
  `−1 帧` / `+1 帧` 微调、`应用`（输入框里回车同样应用）。
  时间码写法 `mm:ss.mmm`，也接受 `ss.mmm` 或 `ss`。
- 校验失败（终点不晚于起点、超出音频长度、时间码无法识别）**只报错不改数据**，
  绝不把用户输入静默"修正"成合法值（docs/development.md §19）。
  元素原本没有时间时也允许在此标定——时间来自用户输入，不是程序猜的。

## 9. 画布布局模式（ADR-0053）

- 画布下方的「布局编辑」切换为当前行静态试样；暂停播放，暂收起主时间轴与播放栏。关闭后恢复原时间预览，播放头不因排版移动。
- 位置栏固定显示来源、X/Y、像素／百分比、六种锚点、旋转和相对缩放、恢复默认与批量入口；回车／失焦提交，未编辑字段保留完整精度。
- 点击当前行字形边界后拖动，8 逻辑像素以内吸附画布边缘／中心或批量清单所选行的锚点；Alt 关闭吸附。拖动锚点止于画布边缘，精确输入越界只提示。
- 指针松开只提交一步；Esc、捕获丢失、切行或工程变化取消预演。方向键以 1 画布像素微调，Shift 为 10 像素；输入框与下拉选择不抢键。时间快捷键在布局模式不编辑时间。
- 批量清单独立于打轴选中；先展示目标、前后坐标、实际变更数及时间重叠提示，再确认套用／分布／恢复。平均分布需要至少三行与已有位置跨度，按歌词顺序排列。
- 边界、锚点与吸附辅助线是界面覆盖层，不进入导出。实际实现与验收状态见 `roadmap.md` §18.9、样式方案 §14。


## 10. 分支编辑与动态布局（ADR-0054）

- 歌词栏上方选择分支，下方列表／元素／时间轴只显示当前分支；切换不写工程、不进入撤销栈，并断开连续编辑合并。
- 当前分支文字、独立行时间、元素时间、重排和模板套用继续由现有歌词行编辑器负责；模板「全部」按类型覆盖全工程分支。
- 「分支设置」用草稿编辑名称／语言、时间／动画策略、当前行关联、分支位置／安全区和双行参数；保存提交，取消放弃，失效草稿拒绝。
- 翻译关联模式下，顶部波形聚焦关联主行的源时间，行时间区明确显示跟随关系并禁用独立写入；解除关联或改独立策略后恢复精确编辑。
- 布局试样采用当前双行槽位或分支默认；单行位置覆盖优先。跨分支批量位置清单按分支分组。
- 实施状态与实窗验收以 roadmap §18.10、样式方案 §15 为准。
