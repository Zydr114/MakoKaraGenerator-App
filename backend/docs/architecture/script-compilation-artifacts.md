# Host 编译与 Worker 固定产物

本页对应 App 重构 M01–M02；实现不改变 SDK 1、效果包 2、工程／歌词 schema 29／18，
也不实现纯时间求值。节点证据与正式性能状态见 App 根目录的
[验收清单](../../../docs/plans/script-sdk-v2-render-acceptance.md)。

## 编译职责与身份

Server 组合根建立共享 `IScriptCompilationService`，作者编译、预览、验证、导出与场景测量
使用同一服务和 `{StateRoot}/script-artifacts`。独立使用 `WorkerProcessProxy` 时可显式注入服务；
未配置时的默认编译器也只在 Host 进程运行。Worker 和 Runtime.Hosting 只依赖产物合同及加载器，
Worker 发布不包含 `Scripting.Compiler` 或 `Microsoft.CodeAnalysis*`。

编译输入键包含排序后的源码路径／文本、完整入口集合、编译器与选项、实际参考 DLL 和 SDK 字节、
引擎版本及分析规则。参数、种子和非源码资源不改变该键。PE／PDB 字节摘要独立于输入键；
Worker 以实际部署参考集、SDK 和引擎身份核验兼容性，继续进行原有入口反射、shader、图像、
图与材质校验。计算参考 DLL 摘要不等于已加载全部运行程序集。

同键编译合并、跨进程锁和有界持久缓存由 M01 负责。新进程命中缓存不是 Roslyn 增量编译。
缓存读取失败明确报错，不退回旧 DLL，也不以重新编译掩盖损坏。

## 私有固定输入

Host 新建一次输入目录，将原始来源固定为 `source.bin`，必要的成功产物写入
`scripts/<artifactHash>/`。私有 pipe 传输原始来源摘要、授权目录、固定产物描述及失败诊断；
不将 PE／PDB 内嵌为 base64。产物的实际摘要须与受 IPC 哈希保护的固定声明一致，不能仅信任
产物目录内可同时被修改的清单。所有原始解码器仍在 Worker 运行，不改变公共来源 profile。

原始来源仍受 4 MiB 预算约束；私有清单不超过 1 MiB，单份 PE／PDB 各不超过 32 MiB，
一次固定产物拷贝不超过 256 MiB。读取前检查声明和实际长度，读取后核对完整摘要；
路径、链接、重复身份、重复 JSON 字段及未知字段拒绝。该预算不宣称限制 Roslyn Emit 峰值内存。

编译失败保留源码身份、入口和完整诊断，不携带可执行产物。Worker 重算固定输入身份后才消费，
诊断位置必须属于该份源码。禁用效果不会为了准备产物而执行；源材质引用所需的包仍参与准备。
原来的资源／shader／图／编译失败归属由相应执行边界保持。

## 所有权与取消

固定目录由 Host 代理拥有。会话成功打开后持有至最终关闭 ACK 或确认所属 Worker 已排水；
一次性任务持有至有效终态或进程排水。取消或关闭失败不能提前删除 Worker 可能仍在读取的输入。
删除失败保留目录所有权，允许随后清理重试。

M03 内部恢复接缝允许关闭旧 Runtime 后复用同一固定封包重开，使用新会话 ID 和序号，
不重复编译或复制闭包；最终关闭才释放。M02 本身不改变 HTTP seek 的 Worker 重建策略。
Host 准备与编译仍需服从调用超时和主动取消，不能把期限到达误报成用户取消。

## 验证边界

实际发布检查 Worker DLL、deps 和运行加载模块；共享编译计数、损坏／缺失／超限／部署不匹配
负例与真实 Worker 工作流分别证明。HTTP 独立 Oracle 自行编译期望结果，其 Runtime 依赖
逐字节对照 Worker，Compiler／Roslyn 依赖逐字节对照同一发布的 Server。
正式性能在暂停本任务其他构建／测试的窗口独立采集；正确性测试不替代性能验收。
