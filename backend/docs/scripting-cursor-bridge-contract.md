# 固定时间 Cursor Bridge 合同

> 2026-10-05，承接 ADR-0125 的真实后继与独立端点。0.30.0 正式接通，语义裁决见 ADR-0126；自动证据和剩余范围以 roadmap §18.93 为准，完整 R6 仍按后续计划。

## 1. 飞行与身份

- Bridge 使用绑定内全部合法后继边，每条边独立按 rate 发射，不选择第一个后继。并发分叉／汇合保留各条路径；源订阅不扩大两端输出范围。
- 仅正空档且 GapUs≤BridgeGapLimitUs、BridgeDurationUs>0 时飞行，范围为 `[To.StartUs-min(BridgeDurationUs,GapUs), To.StartUs)`。零空档、重叠、超限、无后继不生成飞行，也不延迟演唱。句内定时元素空档沿相同规则。
- 路径连接独立 PreviousEndLimit／NextStart 的最终世界点，以 BridgeCurve 调制线性位置进度。CubicBezier 是现有时间缓动，有限过冲保留；不新增空间控制点或夹值。出生后按粒子自己的寿命／运动消散，不随新句移动。
- 粒子来源新增封闭 Bridge，保存真实 Track／From／To、转换事件 ID 和实际飞行区间。BindingId 归旧端，新的装载可从 To 读取；不伪造 TokenId、OccurrenceId 或 PlaybackFrame.Current。

## 2. 时轴与配额

- 不向共享 120 Hz／精确源事件时轴添加飞行边界。注册左端描述时只准备与下一固定区间相交的桥接；飞行起点即使落在网格内，精确有理配额也从该起点积分。
- 实际头与桥接分别保存配额；同一边／飞行起点跨固定区间持续，描述改变飞行起点时重新积累。飞行终点半开，终点配额不跨接到新头；与既有消失头规则一致。同刻顺序在原实例／发射器／Track／Binding 后增加稳定桥接身份。
- 固定提交和分数呈现共用同一调度，呈现使用副本，不因 FPS／暂停增加出生。Burst、解析运动、固定拖尾、Custom 及四类预算共用原模拟与 Render。

## 3. 独立端点与失败

- 端点通过同一快照、全部效果、音频及源材质的独立 AnchorQuery 重放，跳过发射／粒子／视觉，不能递归 Bridge 或污染主会话。
- 只缓存成功的不可变端点值，不保存作者／后端实例；缓存键包括身份、端点种类、锚点、模式和目标。重建／失败／取消／关闭清空缓存。
- 端点不可用记录实例来源的 Warning 并停发该路径，不回退为基础点；作者 Error／取消传播，未来 Error 保留实际失败包／控制器来源。非有限曲线／世界位置、记录／存活／拖尾／绘制预算沿原明确错误和导出保护。
- 纯帧仍拒绝连续发射，IncludeInTargetCapture 仍明确拒绝；不改 schema26／16／5、包 profile2、程序集或依赖。

## 4. 验证出口

验证真实未来 callback／全部最终变换、网格内飞行起点、短／长／零空档、重叠／并发／窄绑定、句内／行依据／前奏与槽位；24／30／60 FPS、分数暂停／跳转、顺序／随机、四类预算、Error／取消／资源释放；完整包保存重开与实际 CPU／MP4／Alpha 同帧、失败保护。正式源码构建、全量回归、变异、文档、独立提交及推送后记录完成证据。
