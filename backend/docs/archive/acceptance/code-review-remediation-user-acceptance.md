# 本次goal的具体改动与验收清单（产品0.49.6，2026-10-09）

本清单按[代码审查修复计划](../plans/code-review-remediation-plan.md)的原编号整理，实际实现／历史结果以[分批验收](code-review-remediation-acceptance.md)、[最终出口核对](../research/code-review-remediation-final-audit.md)及[roadmap](../history/roadmap.md)§18.136～18.161为准；行为裁决为ADR-0163～0185。代码审查基线是`main@e87ace0`／0.43.10，本清单截至产品修复提交`711944a`／0.49.6，工作分支`dev/code-review-repair`，对应实现提交均已推送。后续用户要求移除原goal，并单独修复导出入口、保持版本，追加结果见[导出入口合同](../legacy-ui/export-entry-contract.md)／roadmap §18.162；不改变本清单各历史批次的验收范围。

**用户最新反馈：**“测试完成，目前已经可以正常新建窗口。”本次0.49.6新建入口恢复记为人工通过；此反馈没有逐项覆盖其余制作／播放／导出路线。原goal继续暂停，全量测试、性能优化／基准／采样及此前暂缓的未知失败提示均不自动恢复。本清单只整理已做改动、记录反馈和给出验收方法。

所有列出的自动结果都标明原实施批次。它们不是当前0.49.6全量结果，也不能相加成为全量通过数。当前产品保持工程／歌词／模板格式28／16／6、脚本配置1、包profile2及固定依赖；继续使用原三工作区、固定组合预设、不可变工程快照和一次手势一次撤销的制作模型。

## 5. 建议的人工连续路线

在已交付0.49.6程序上使用新的测试工程和测试库；保留原材料，闭包搬移／缺失文件验证使用副本。当前健康普通包在`/home/zydr/.cache/MakoKaraGenerator/manual-0.49.6`，示例在其`example/`；需要启动时使用`/home/zydr/.cache/MakoKaraGenerator/start-0.49.6.sh`。原NTFS目录及旧脚本未同步，测试输出宜放健康磁盘。旧版本工程仍受精确门禁，不修改版本字段绕过。

1. **新建与播放**：新建音频＋主歌词 → 导入A／B → 撤销／重做并听辨 → EOF重播、循环、J／K／L／Space。通过条件：模型、波形、声音及播放标记一致，暂停及文本输入互不干扰。新建已获反馈，其余动作按实际结果分别记录。
2. **作者草稿与保存**：非法字号／颜色／曲线 → 另一个合法字段 → 撤销／重做 → 修正后保存；工坊／工程／配置分别检查菜单和快捷键。通过条件：非法原文不丢、保存门禁一致、写入对象正确。
3. **冲突与异步目标**：两测试作者共用测试库，验证旧修订冲突；包导入期间换草稿／关闭。通过条件：前者结果及双方草稿保留，迟到结果不写新目标，错误后可重试。精准异步时序优先用既有可控测试。
4. **配置、预设与选择**：保存／正式运行验证配置 → 制作组合预设 → 应用／局部继承／撤销 → 精确分段与布局 → 编辑歌词并切换对象、聚焦／拖动 → 来源菜单收起／重开。通过条件：实际选中ID、映射、实例／seed、预设修订与UI同步，一次动作一次撤销，无旧手势回写。
