# 脚本图像资源账本实施合同

> 2026-10-03；0.9.16 已实施并自动验证，依据已接受的 R0 §8（每帧 64 张活动表面、每会话 512 MiB 估算中间表面）及 ADR-0071。本批不改程序集划分、生产 JSON、脚本写权限或缺失输入策略。

## 1. 所有权与范围

固定的 `ImageSurfaceBudgetSession` 保存会话总账，`BeginFrame` 创建帧账。预览和导出各有自己的账本；宿主可向 Skia 管线注入固定会话账，捕获、图执行和合成可以显式共用同一个帧账。未显式传入帧账时，生产绑定适配器在一次调用内共用一份帧账，其捕获产物在适配器返回后继续占用会话内存。

预算在创建像素存储之前预留。捕获、图节点和合成的图像包装持有预留，直到图像释放；不能在 Execute 返回时提前减账。一个帧账关闭后拒绝新申请，但已有产物仍计费，后续 Dispose 可正常减账。关闭会话也不强制释放调用者持有的图像。

同一 native 图像句柄的输入别名只计一份存储。已受管产物进入另一张帧账时，为新帧增加活动计数，但会话字节只计一次；外部图像由调用方拥有，账本仅在其受管借用区间计费，不夺取图像生命周期。返回值若借用输入，输入计费必须保留到返回值释放，透明旁路同样如此。

主窗口／编码器的最终像素缓冲不属于本批“中间表面”账；父子合成协调器后续应沿用此账本，不能另开单图账冒充整帧总账。

## 2. 分配与预检

图仍检查自己的 pass、尺寸、外扩和单图峰值。共享账本另外检查当前活动资源加上图的预计节点峰值，包含尚未释放的前一实例／其他目标产物，失败发生在新节点分配前。

显式 Blur 沿用现有执行计划的两张全输出框临时表面估算，并在真实滤镜执行期间预留。固定字形捕获的入场／标记 alpha 和外描边 SaveLayer，按捕获实际像素框的完整一张存储保守预留，生命周期覆盖 Restore。预算错误列出申请量、当前量和限制，不缩图、不减少遍数。

native 滤镜内部实现、旧文字阴影的内部 scratch、字形缓存、驱动对象及锁定 SkiaSharp 的 ToShader 包装终结器不等于这些像素存储估算。本批不声称完整 native RSS 已受控，不以账本基础替代 R3 完整出口。主画布图调度、子图进入父捕获、媒体／下层输入及包资源闭包仍待接入。

## 3. 验证与交付

测试须使用真实固定字形捕获和正式 CPU 图：跨图保留产物导致超限、释放后恢复、别名去重、跨帧共享图像、透明旁路保留计费、模糊／SaveLayer 临时峰值、取消／异常回收以及连续执行后总账归零。至少一次变异证明删去共享检查会使回归失败。

完成后递增程序 PATCH，同步 ADR、roadmap、AGENTS 和生产捕获记录；全量构建／测试并启动最终构建。本批不新增脚本界面。
