This helper uses FFmpeg 9.0.2 (https://ffmpeg.org/), LGPL 2.1 or later.
The helper links against the co-located libavutil.so.61, libavcodec.so.63 and libavformat.so.63 via $ORIGIN RPATH.
The FFmpeg configuration enables no GPL, nonfree, or version-3 components.
The only non-system dependency compiled into those shared libraries is static zlib 1.4.
