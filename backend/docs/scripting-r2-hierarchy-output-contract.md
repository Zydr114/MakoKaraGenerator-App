# R2 整行与层次仿射输出合同

> 2026-10-03；**0.9.10 已实施整行仿射与真实运行父树传播，完整 R2 出口未达成**。施工基线 0.9.9，按已接受 R0 §3／§5 和 ADR-0071、0073、0074，JSON 不改。样式跨目标覆盖仍待答；组写权限随后获确认，仅工程／显式节点可写，0.11.1 组仿射见[后续合同](scripting-group-affine-contract.md)。

## 1. 已确定的矩阵规则

LineTarget 使用真实 LineId＋当前 BindingId。整行 ApplyAffine 使用 LineGeometry.BaseGeometry 的逻辑坐标，已有字体布局、单句／入场、槽位与父组矩阵保留；输出是帧值，不回写源布局。变换整个歌词行及注音，附着于该文字节点的前奏组跟随；FixedParent 前奏不跟随该句，但仍保留自身真实父组关系。翻译只受自己所属运行父树影响，不因关联源行而自动移动。

同一目标局部矩阵按调用和实例顺序右乘；恒等或抵消的输出省略。不同层级使用真实父×子关系，各层只乘一次。令基础节点世界矩阵为 B、基础父矩阵为 P，最终父矩阵为 F、自身局部效果为 A：

```text
节点最终矩阵 = F × inverse(P) × B × A
```

未变化祖先直接保留 B，避免无变化路径反复求逆造成数值漂移；根节点没有父矩阵。跟随提示使用运行时目标文字为父，保留基础附着锚点及参考尺寸，不另做布局。独立元素族／标记变换在这个层次矩阵之后组合，不再乘一份父组。

## 2. 范围和准备帧

Project／Branch／Lines／Clips 可以写匹配的整行。Node 只按实际运行父树和 includeDescendants 授予整行权限。Tokens 仍可读取所属行的元信息／基本几何，但不获得整行写权限。

FrameWriter.Transforms.ApplyAffine(LineTarget, Affine2) 严格验证本帧目标、能力、阶段、有限性和可逆性。共享合字允许整行变换，因为没有拆分 glyph；元素独立变换的字簇限制保持。错误 Binding、缺实际节点／几何、循环／不可逆祖先和组合溢出明确失败，不取默认父节点。

PreparedRenderFrame.Scene 保持共享后端的基础帧；HierarchyScene 是层次变换后的绘制帧，既有场景调度／进度不变。FinalLineGeometry、FinalGeometry、FinalMarkGeometry、FinalGroupGeometry 和 Playback 使用同一最终矩阵。组参考框仍表达容器自身，墨迹来自最终文字、注音和标记，不因字形扩大而修改组参考尺寸。族和标记的独立输出不重排相邻文字。

后端使用 HierarchyScene 绘制整行，原有族／标记局部输出只再应用各自一次。无变化时保持原帧引用；缺／重复／旧装载输出以及原生坐标越限不进入普通占位帧回退。除了 double 有限／可逆检查，还在实际 Skia float 矩阵上检查有限逆矩阵；double 可逆但 float 下溢退化的输出明确失败，不夹值或静默消字。导出与独立未来锚点查询消费同一准备帧。

## 3. 待用户答复的规则

1. 整行 Style 与元素 Style 写同一属性时，是否按实例／调用顺序后写生效，整行写入覆盖静态元素外观。
2. **已确认并在 0.11.1 实施**：组写权限仅授予 Project／显式 Node，源筛选不授予组写权；includeDescendants 使用实际运行父树，具体见[组仿射合同](scripting-group-affine-contract.md)。

第 1 项仍待答，整行 Style 不默认覆盖顺序；第 2 项已收口，不再列为待答。组基础外观仅 alpha，组透明度仍需实际隔离合成／捕获，不能变成逐后代乘法。光标重叠后继仍待之前的问题答复。

## 4. 验证要求及实施证据

真正 SDK 作者源码独立编译；整行、注音、跟随／固定提示和播放头的最终矩阵一致；与等价静态整体移动逐字节像素对照；与元素族缩放／标记仿射组合一次；非均匀仿射／旋转和多实例顺序、共享合字／无逐字时间、范围／阶段／能力／失效装载／数值门禁、源引用不变；既有 callback／编码失败与全量回归。实际结果在 R2 记录及 roadmap 更新，不把施工方案当完成证据。

0.9.10 全量构建 0 警告／0 错误，**1770 项通过，0 失败／跳过**；新增 Rendering 18、Scripting 4。真正 Roslyn LineProbe 在真实前奏、三槽、普通行、父组／单句旋转和入场下执行，整行移动与保持字形逻辑起点的等价父组移动逐字节相同；固定父组提示单独补偿以保持其世界位置。整行＋族缩放＋标记局部移动与独立静态移动＋局部输出对照同样逐字节一致。

原单句位置参数的平移会重算字形绘制起点，产生亚像素取整差异，故不以它冒充上述固定字形矩阵的逐字节基准；最终矩阵、播放头和几何仍单独严格检查。极小缩放回归先复现 float 退化后无异常的静默丢字，再由实际后端可逆门禁修复。完整证据、日志与剩余范围见 [R2 记录 §3.8](archive/research/scripting-r2-sdk-geometry-progress.md#38-0910-整行仿射与运行父树验证)及 roadmap §18.39；当前没有脚本工作区 UI。
