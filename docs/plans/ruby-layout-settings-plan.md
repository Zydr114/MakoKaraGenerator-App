# Ruby 排版设置与连续字距

2026-11-17，用户选择方案 2：Ruby 继续继承所属文字的外观，增加字号比例和正文间距设置。
用户手测已经确认现有碰撞退让有效，本次将固定 1 排版像素的下限改为至少连续注音的自然字距；
截图中的分段 Ruby 不应比同样字体、字号和字距连续排版时更拥挤。

## 范围与决定

- 沿用共享整行整形和 Ruby 避碰求解器，不引入独立注音外观、独立脚本目标、逐字重整形或平台原生预览改造。
- 最小段间距来自注音边界字形的自然留白及附加字距，不能只把固定 1 改为可能为 0 的 `LetterSpacingPx`。
  保留不可拆字簇、非精确映射和非单调视觉顺序的安全边界；不自动解决脚本主动变换造成的重叠。
- 新增规范样式 `ruby.relativeScale`、`ruby.gapPx`，两者都是可空数值。
  最终样式中的非空值覆盖歌词原始 `RubyAnnotation` 数值；空值表示使用歌词原始值（通常为 0.5 和 2）。
  覆盖对象区分未设置（继承上层）与显式空值（回到歌词原始值）。
- 沿用工程、预设、分支、行、文字单元的样式解析与属性恢复，不把原始注音数值静默重写为模板值。
  Ruby 字号与距离可以用于文字单元目标，因为它们不改变正文的整行字体参数。
- 模板库添加两个属性开关和数值控件；编排检查器提供所选句子的直接调整及恢复继承。
  容器和片段沿用已有模板分配，本次不增加无上下文的容器／片段 `styles.patch` 命令。
- 字号比例须为正的有限数，正文间距须为非负有限数，非空值还须通过实际文字布局范围检查。
  测量、绘制、装饰缩放、包材质、变形和缓存必须使用相同的最终比例。
