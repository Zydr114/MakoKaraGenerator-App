## 1. 已确认的行为

| 项目 | 用户选择 |
|---|---|
| 互斥关系 | 居中句出现时双行暂时退出，只显示该句主歌词 |
| 显示区间 | 严格使用该句源行的 `[startUs,endUs)`，不复制另一套展示时间 |
| 容器交接 | 边界直接切换，不做两个容器之间的交叠或退出等待 |
| 单句动画 | 保留该句自身入场动画；仍从源行起点计算 |
| 恢复轮换 | 常规片段从槽位一重新开始，独立句不占用槽位 |
| 坐标系 | 居中容器属于共同父组，随整组移动、旋转与缩放 |
| 翻译 | 保留关联翻译，在翻译分支自身位置显示；注音继续跟随基础字 |
| 时间冲突 | 普通句演唱时间与独立句重叠时，拒绝配置并报告冲突 |

“边界切换”作用于容器可见性；单句进入动画仍能在其所属区间内求值。源行、逐字时间、样式覆盖和翻译 LineId 关联保持一份。

## 2. 本批范围

实现 Core 定义与校验、工程持久化、纯时间调度、场景定义／帧／世界几何、预览与导出、预设演示工程。已有样式套用仍作用于源行，可以独立改变特殊句的样式。

本批不新增容器树面板、独立显示按钮、容器重挂、槽位增删／重排或通用实例样式编辑器。这些交互在完整案例验收后设计。

## 3. 已选择：独立通用容器树

用户明确选择直接替换全部展示配置的存储，不在分支配置上追加特殊字段。工程 `lyricPresentation` 保存三个独立集合：

- `nodes`：稳定容器 ID、ParentId、Placement、固定 ReferenceRect 和可选内部 Layout。容器树可以任意嵌套，位置只有这一份来源。
- `programs`：源 BranchId、共同根容器、常规显示容器、动画策略与 ExclusiveClips。片段通过 LineId 与 ContainerId 关联源行和容器。
- `lineOverrides`：源 BranchId／LineId、普通文本局部位置及行进入动画覆盖。

布局的槽位顺序保存为节点 ID 列表；槽位的位置只在对应节点保存。槽位调度参数不再重复保存槽位位置。常规容器、居中容器和共同父组都是同一种容器节点；普通歌词、翻译及双行均从这棵树投影。

`LyricBranchPresentation` 保留为现有窗口的临时适配视图，由原生树读取／写入，不能再作为磁盘数据来源。旧 branches 展示 JSON 被严格拒绝；不转换旧工程。

```text
共同父组（外层 Placement）
  ├─ 常规容器（Layout：默认文本位置或槽位序列）
  │   ├─ 槽位一容器（唯一位置）→ 本次源行文本 → 注音
  │   └─ 槽位二容器（唯一位置）→ 本次源行文本 → 注音
  └─ 居中容器（独立 Placement）→ 片段所绑定的源行文本 → 注音

独立翻译组 → 翻译容器 → 关联翻译
```

节点树不存歌词副本或某帧几何。文本与注音从源对象及本帧绑定生成；源 ID、画布节点 ID 和片段／绑定 ID 分开。组矩阵按真实父子关系递归计算，先静态位置再局部动画。

通用树的核心合同在本批实现；任意树、槽位和独占片段的交互编辑仍后置。现有窗口借助适配继续修改原先已有的展示组／常规布局参数。

## 4. 调度合同

1. 通过 LineId 读取独占源行时间，解析常规／独占时间片段；时间缺失或非法则配置不可用，不能猜时间。
2. 普通行必须完整落在某个常规片段内。半开区间相接合法；与独占区间相交为阻断错误。独占片段之间的交集也报告错误。
3. 对当前常规片段的成员单独调用槽位调度，从槽位一开始。独占句不进入该成员集，前后片段互不借用“上一句”触发提前显示。
4. 在独占行起点切换到其容器；终点切回后续常规片段。逐字采样仍只调用 `LyricSampler`，不得提前唱字或修改源时间。
5. 居中句采用自身行覆盖／工程默认入场动画；不消费双行槽位的退出动画。其他常规行保留现有槽位动画。
6. 关联翻译查找最终主歌词场景可见行，保持自身位置；注音继承居中句的最终变换。
7. 直接跳转与顺序播放必须得到同一节点、绑定、进度、矩阵和像素，不依赖实际播放历史。

## 5. 编辑用例与校验接缝

虽然本批不开发新 UI，仍提供可预演的纯配置操作：有效结果返回完整不可变工程；失败报告路径和冲突行，工程保持原引用。一次成功提交可以通过现有工作区命令进撤销栈，取消草稿不进历史，相同配置为无变化。

保存／打开／导出共用源关联及时间冲突校验。源时间或关联变化后也需重新检查，禁止把非法配置静默改成普通双行。删除源行时，按现有显式删除命令清理其片段关联；未被使用的容器可保留。复制独占展示配置等交互语义留给后续编辑功能设计，本批不新增自动复制片段操作。

静态试样使用对应常规或独占容器的基础布局，关闭时间动画，未定时源行仍不伪造时间。现有普通／双行位置目标继续编辑原展示组及常规槽位，新增子容器的选择编辑后置。

### 7.3 用户验收

1. 在演示工程分别查看约 3 秒、11 秒、18 秒：常规双行、独占居中、恢复双行；独占区间内无普通主歌词，翻译与注音保留。

3. 选特殊句进入现有布局编辑，修改共同容器位置、旋转或缩放；居中句随共同父组变化，恢复后槽位仍保持相对关系。撤销应整体恢复。
4. 在行编辑器给特殊句套行模板；保存／重开仍保留展示归属。特殊句归属和独立子容器位置本批由预设配置提供，尚无新增编辑按钮。
5. 扩展普通句行时间使其与居中区间相交，应明确拒绝并保持原时间；导出结果与预览一致。
