# GPU 性能优化第一批实施与验收（2026-10-27）

> 状态：已完成本批实现、本地回归、匹配发布、有限 fresh HTTP 和正式直接 Runtime 对照（2026-10-28收口）。工作分支 `dev/performance-optimization`，起点为 `main` 的 `1b2d375`；生产输入与短批次基线 `8681bc0` 相同。用户本轮明确授权恢复性能优化、使用 GPT 6.1 Sol xhigh 与 GPT 6.1 Terra xhigh 子代理编码和测试。主代理负责范围、调用链审查、验收整合及分步提交推送。

## 1. 本批范围

依据 [优化调研](../research/backend-gpu-performance-optimization-research-20261027.md) 和 [原性能基线](../research/backend-render-performance-baseline-20261027.md)，先减少重复整图读回与分配：

1. 内部拥有且不可变的图像只在首次成功时完成预乘扫描，后续同设备验证复用成功事实。所有结构、类型、密度、sRGB、预算和取消检查仍执行。
2. 对可由实际绘制路径证明为空的原始颜色部件减少判空读回或捕获。必须保留目标选择、几何、变换、共同透明度、部件顺序，以及原有预算准入和错误顺序；无法证明的路径照常执行。
3. 对仍需读回的临时缓冲采用明确上限、有效长度和异常归还的复用机制，避免保留无界整帧缓存。缓冲复用与读回次数降低分别计量。

不跳过空 coverage 下的作者材质执行。其完整图域非法预乘、masked 越界、逐节点错误归属不能被优化掩盖。不变更公开 CPU/GPU 选择、失败不回落、项目格式或 HTTP 行为。

同帧作者图共享、GPU 全域小结果归约、同步边界和 ROI 根据本批实测瓶颈再决定；本批不预先承诺固定样本达到 500 ms/帧。500 ms 仍按原调研的五轮未插桩 GPU 计量帧最大值口径判断，创建、首帧、seek 单列。

## 2. 实现约束与责任

- Sol 编码代理负责 `SkiaGraphSurface` 与图像验证入口、独立回归。成功凭据不以 native handle 为全局键；外借输入不缓存，失败和取消不标成功，创建者释放使凭据失效。`BorrowAs` 保留原非拥有语义，凭据不能延长 image、device lease 或预算 reservation 生命周期。
- Terra 编码代理负责原始颜色部件、捕获与有界判空缓冲、独立回归。材质执行及作者错误检查不按空区域跳过。
- Terra 验收代理负责复用并扩展短批次工具，旧/新同设备完整 BGRA 与规范化诊断对照、源码与构建指纹、交替采样和原始证据。
- Sol 只读审查代理独立检查生命周期、取消、错误与预算语义。主代理复审最终 diff，协调构建/测试与正式采样互斥，按文件分步提交并推送指定分支。

无关未跟踪 `tools/backend-project-image-export-probe/` 保留。首批兼容内部优化交付版本计划为 `0.106.1`，合同 `1.39.0` 与 HTTP 协议 `1` 保持；产品元数据通过现有生成器同步，禁止手改冻结生成物。

## 3. 验证出口

### 正确性和失败语义

验证成功缓存与多个别名、不同图像、外借内存变化、跨设备、取消/失败重试、创建者和设备释放；验证单像素非法预乘、区域外非法颜色和 masked 容差、结构/密度/sRGB、预算恰好及超限。空部件覆盖无/有 ruby、描边/阴影、sung、排除、普通/透明、变换和半像素边界。关键新增回归需做变异红/恢复绿检查，失败记录保留。

正常 solution 零警告构建及相关 Rendering/Runtime/Backend 定向回归。现有全量测试暂停约定不因性能任务恢复；真实 HTTP 与直接 Runtime 证据分别登记。

### 性能和归因

六类原 fixture、1080p Final、时间序列与固定字体保持。未插桩旧/新执行体按同设备交替运行；普通 `8+24`、材质/组合 `4+8`，各五轮。每个进程项目帧加设备 probe 少于 100；不并发渲染，采样期间暂停构建和测试。

每帧完整有效 BGRA 与规范化诊断严格比较；CPU 与 GPU 各自对照旧版，不要求两种后端字节一致。透明与 seek 的有限正确性对照单列。报告 median/P95/max、五轮分布、创建/首帧、托管分配与 GC；插桩仅用于独立归因，记录读回/扫描/Raster 次数和字节，不混入正式 wall 统计。记录本机设备证据及进程自然退出。

### 发布与文档

完成实现和本地回归后同步产品元数据及合同静态校验，准备匹配源码的 Server/Worker 发布并复核有限真实 HTTP 渲染路径。验收报告保留源码、工具、发布和证据指纹，区分直接 Runtime 性能、HTTP 功能及原历史证据。新统计不回写原基线，不外推完整工程、长片、浏览器、跨平台或 GPU 编码。
