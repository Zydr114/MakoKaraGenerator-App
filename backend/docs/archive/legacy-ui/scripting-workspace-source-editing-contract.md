# 脚本工作区源码编辑与接受修订合同

2026-10-04；**0.24.0** 已实施并完成自动验证。依据已接受 R0 合同 §7.5／§10，以及当前脚本系统目标授权；本合同具体化 U2 的作者操作闭环，不改变已确认的效果行为。本文定义状态和职责，实际证据见 `docs/roadmap.md` §18.76。

## 1. 本批目标与边界

用户在工作区选择已有包，编辑多个 C# 文件，保存固定修订，独立编译和定位诊断，显式升级一个所选实例，然后保存工程效果。源码可以是暂未编译或编译失败的状态，保存不得因此拒绝。实际启用并参与预览／导出的效果继续受正式编译、初始化和求值门禁约束。

本批只编辑清单中 `role:csharp` 的既有 UTF-8 文件，不创建文件、改清单、改 shader 或图 JSON。源码新建／包复制、同时勾选多引用升级、完整实时工作区预览、窄窗口专用覆盖面板仍后续。不能以本批源码编辑能力宣布完整 R7 或 R2～R8 交付。

## 2. 对象与职责

| 对象 | 责任与真值 | 不承担的责任 |
|---|---|---|
| 固定包修订 `EffectPackageContents` | 完整清单与资源字节；内容修订唯一标识全部文件 | 不随文本框输入变化，不被原位覆写 |
| 包源码草稿 | 按包身份／基准修订／路径保存编辑文本及原字节，保留切换选择前后的内容 | 不直接改变工程实例或主窗口工程 |
| 工作区效果草稿 `ProjectEffects` | 已登记包修订、工程实例及顺序，所有改变等待一次历史提交 | 不记录 Roslyn 活对象、诊断会话或成功 DLL |
| 所选包编译任务 | 固定一个真实包闭包，通过既有离线编译服务得到诊断和产物 | 不依赖实例是否启用，不代替整个工程求值或导出验证 |
| 显式实例升级操作 | 只更新所选实例的固定包引用，并按既有语义检查入口／参数／绑定 | 不传播到其他实例、源材质或模板 |
| 正式运行会话 | 按当前启用实例与真实源材质建立预览／导出独立会话，失败阻止成片 | 不把失败源码恢复成旧源码，不生成无效果替代输出 |

工作区不持有可修改的 Core 源对象供脚本访问；以上是作者工具的状态，作者 SDK 仍只使用已冻结的目录、参数、资源和阶段 writer。

## 3. 三种状态必须分别表达

| 状态 | 内容 | 产生变化的操作 |
|---|---|---|
| 未发布源码草稿 | 一个或多个固定包修订下的脏文件文本 | 编辑文件；文件／包切换只改变选择 |
| 未提交工程效果草稿 | 与打开窗口时的工程效果不同的包修订或实例集合 | 导入、保存源码修订、实例编辑或显式升级 |
| 编译状态 | 具体包修订的未编译／编译中／成功／失败／取消及诊断 | 独立编译当前固定修订；新编辑使旧成功不再代表当前草稿 |

“源码已保存”表示它成为工作区内的固定修订；“工程效果已保存”表示已通过历史命令交给主窗口；“工程已写盘”由主窗口工程保存负责。编译成功是另一个状态，不能用一个“已保存”概括全部。

编译旧修订的成功结果不能标记新修订成功。没有关联当前启用效果时，独立包编译失败也不能谎称整个工程一定不能导出；当前启用或被源材质真实引用的包失败时，正式运行门禁才报告对应导出阻止。

## 4. 跨选择草稿与多文件保存

1. 草稿键是 `(packageId, revision, path)`，以固定基准修订为准。文件列表切换、包列表切换、实例选择及重建列表均不能丢失尚未保存的文本。
2. 编辑一个文件不会立刻更新清单摘要或固定包。未编辑文件保留原内容字节，包内 shader、图、图片和其他资源保持原样。
3. 源码区“保存修订并编译”先合并当前包基准修订下的全部脏 C# 文件；分别编码 UTF-8、更新对应 `sha256`，然后由唯一 `EffectPackageContents.Create` 检查完整路径、文件集合、profile、摘要和内容闭包，再独立编译该固定修订。编译失败时修订已经保存，不能回滚源码或将其标成保存失败。
4. 成功后将完整新修订登记到工作区效果草稿；保留旧修订，选择新修订并以它作为后续编辑基准。原包／工程入口不覆写，不自动升级现有实例。相同字节修订复用，不制造重复包。
5. 其他包尚未发布的文本仍保留。源码发布失败不清空草稿、不更新基准，不创建部分包修订。
6. 保存工作区时，尚未发布的所有包源码草稿先构造固定修订并登记，再提交效果草稿。任何闭包构造失败都保留全部草稿，并阻止该次提交；C# 语法或编译失败不是闭包构造失败。

源码草稿本身不进工程历史；已接受固定修订随 `ProjectEffects` 一次历史命令提交，工程撤销恢复包引用与实例，主窗口正常保存、另存为和备份持有完整源码资源。

## 5. 所选包独立编译与诊断

源码区“保存修订并编译”先固定该包全部未发布源码，再捕获该修订的不可变闭包。通过现有分发参考程序集、离线 Roslyn 和固定包校验编译，不以“整个工程目前没有启用实例”作为免编译依据；没有脏文本时也可以编译当前所选修订。成功结果也不自动启用实例或升级引用。

诊断保留 severity、code、message、包身份与修订，以及可用的文件路径／行／列。列表选择诊断时定位它所属包修订和源文件，将编辑器定位到相应行列；没有源位置的包或资源诊断仍直接显示，不伪造 `0:0` 源位置。编辑后的草稿与诊断基准不一致时明确说明诊断所属修订，不把旧结果当作当前源码结果。

独立编译失败保留可编辑源码和完整诊断。UI 区分编译失败与用户取消；不使用旧成功 DLL 冒充当前修订编译成功。工作区编译结果只是包的技术验证，正式运行仍验证当前工程绑定、参数、全部启用实例和源材质。

## 6. 只升级当前所选实例

“应用此修订到所选实例”是独立显式动作，作用于当前选择的固定包和当前选择的工程实例。同一 `packageId` 的新修订才可升级；不把包选择动作等同于应用效果。

升级保留 `InstanceId`、name、entry/exportId、参数覆盖、绑定、订阅、seed、enabled、模板来源、overlay 层及执行顺序，仅改 `revision`。按既有入口／参数／绑定合同验证：若新修订不再接受原入口或参数，显示真实错误并保持原实例，不清参数或换默认入口强行成功。此操作不要求 C# 已编译成功，因此用户可以显式保留失败修订的引用并保存。

其他实例、源材质引用和模板仍指向原修订；不能按包身份全局替换。新建实例初始禁用，完成绑定／参数后由用户启用；复制则沿用既有复制语义，不偷偷变更复制来源的启用状态。

本批未实现多引用勾选接受。完整 R0 流程以后需要列出实例／材质／模板的受影响引用并允许选择，不能因当前单实例动作已经可用就宣称完成该流程。

## 7. 工程保存与正式运行门禁

工作区“保存工程改动”检查可持久化的包闭包和实例输入，不以导出校验器或正式运行会话成功作为前置条件。编译失败的源码和其固定引用可进入一个 `SetProjectEffectsCommand`；主窗口随后可以正常保存／另存为／备份。保存成功后窗口留在原处显示结果，只有关闭流程中的保存成功才退出。尚未完成的参数或结构输入错误必须可见，不能保存伪造的有效默认值。参数／名称／种子／绑定／订阅错误分别保留，只清除被修正字段；其他合法操作不能清掉它们。非法输入计入未保存状态并阻止保存与接受修订，刷新保留原文本，显式放弃才重置。已有的包定义／失效导出诊断单独显示，不冒充用户新输入，也不阻止通过合法导出或换包修复。

独立的“验证工程效果”使用正式会话并显示运行诊断，不代表未被引用的包已编译，也不能反向禁止作者保存失败源码。实际启用源码或源材质失败，预览保留上一成功图像时明确标旧结果，当前导出失败；不会切回旧 DLL、忽略失败实例或用占位效果生成成功成片。禁用实例可以保存错误源码，但它的包被真实源材质或其他启用实例引用时仍需验证。

## 8. 异步任务、关闭与释放

编译或保存任务期间冻结源码、包／实例选择、导入、分享和变更操作，固定该任务的输入。取消按钮与关闭操作仍可用；界面不阻塞 UI 线程。取消后 await 任务离开受管边界并释放编译包／加载上下文等本批持有资源，过期完成不能覆盖新状态。

关闭确认同时考虑工程效果草稿和全部包源码草稿：

- **保存**：先发布未提交源码修订，再提交效果草稿；失败保持窗口和文本，不把取消当成功。
- **放弃**：丢弃窗口内全部未提交改动，主窗口工程不变。
- **取消**：留在窗口，所有草稿保持。

正在运行的任务先取消并完成清理，再处理关闭确认；不能关闭窗口后由后台任务继续改工程。受信 C# 的合作取消边界保持，不在本批承诺强制终止任意恶意死循环。

## 9. 断代与后续范围

本批程序升至 0.24.0；工程／歌词／模板 schema **26／16／5**、包 profile **2** 保持。没有新增工程 JSON 字段、作者 SDK、程序集或第三方依赖，不迁移旧工程。

U0 已有运行组合根和独立预览／导出会话；后续准确缺口是直接图／材质实例、跨输出执行计划、组／父捕获、映射和完整工作区流程。其他明确后续项包括：新建源码包和文件、多引用升级、shader／图资源作者编辑、模板配方入口、实时效果画布、940×640 显式覆盖面板及六示例整体成片。

## 10. 本批验证范围

| 范围 | 必须证明 |
|---|---|
| 跨选择草稿 | 文件和包来回切换、多次列表刷新仍保持脏文本；旧修订字节未变 |
| 多文件修订 | 一次保存合并全部脏文件，未编辑资源字节不变，摘要与内容修订正确 |
| 独立编译 | 没有任何实例也能编译所选包；真实语法错误产生正确路径／行列，可点击定位 |
| 单实例升级 | 两个实例及一个源材质共用旧包时，只改选中实例；身份／入口／参数／seed等保持，非法升级不部分修改 |
| 失败源码保存 | 失败源码可提交工程、保存重开；被启用引用时正式会话／导出拒绝，无旧 DLL 回退 |
| 任务与关闭 | 编译期冻结编辑、取消及关闭清理，无过期结果；只有源码脏时仍出现保存／放弃／取消 |
| 初建状态与历史 | 新建实例禁用；工作区提交一个历史命令，撤销恢复固定包和实例 |

实际构建、全量测试、独立包编译、失败源码持久化与导出门禁、真实宽窄窗口操作证据见 roadmap §18.76。表中完整未来流程不因本批局部验证而自动完成；多引用接受仍未实现，没有新 GUI 人工反馈，不记录人工验收通过。
