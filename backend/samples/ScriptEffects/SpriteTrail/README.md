# 图片粒子与固定拖尾

适用于程序0.31.0；包版本1.1.0，宿主SDK／profile2保持。

完整 profile2 目录包，可导入或分享为 `.mkfx`，保存工程后无需原目录。
每条真实播放头独立发射，宿主保存出生、运动、寿命与固定拖尾；纯 `EvaluateVisuals`
以 `Parameters.GetAsset("image")` 固定图片绘制旋转星芒及逐样本淡出拖尾。
使用 `Custom` 关闭自动圆点，旧句粒子保持世界坐标。图片自身 Alpha 与颜色乘数各一次。

图片参数可选本包已声明图片；例图为自行生成的 16×16 白色星芒与半透明内层，
没有外部素材依赖。每个星芒（包括拖尾样本）计入公共绘制预算，资源在会话外完整解码。
transition默认jump，可选bridge；bridgeUs=180000、bridgeGapLimitUs=2000000。桥接沿每条合法真实后继独立发射，在空档末段读取全部效果的独立最终端点；半开终点与源起唱保持，不伪造Current。旧粒子保留出生世界位置按寿命消散，桥接来源也可由纯视觉阶段绘制。本包不声明目标内捕获、复杂图映射或完整R6已经交付。
