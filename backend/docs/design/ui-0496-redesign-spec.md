# MakoKara 新版 UI 设计规范

日期：2026-10-10。配套：[截图与代码审查](ui-0496-interaction-review.md) / [交互设计源](ui-0496-prototype.html)。

**状态：自然引导修订版已获用户确认，作为重构设计基线；产品分切片施工，完成情况见[实施记录](../archive/legacy-ui/ui-0496-refactoring-progress.md)及roadmap。** 用户已确定：所有外观先做预设再应用；允许重组工作区与流程；保留本版布局和自然引导方式，同时保持当前全部功能与 SukiUI 风格。设计确认不等于产品实现或原生验收。

本次的逐页调整与信息显露规则见 [自然引导修订](ui-0496-natural-guidance.md)。本文中的合同、边界和实现说明面向设计与开发，不是要搬进界面的文案。

实施入口见 [UI 重构规划](../archive/legacy-ui/ui-0496-refactoring-plan.md)：包含功能保留与迁移要求、页面/状态设计稿索引、交互规则、统一 Suki 控件数值、代码职责、验收矩阵和简短实现顺序。原生数值执行该规划第 4 节，本文的网页原型尺寸不另成一套规格。

## 1. 产品规则

1. **工程编辑与资源制作分清。** 工程保存、预设保存、效果组件保存都有明确对象名。
2. **先选目标，再选动作。** 对象选择只有一个真值；面板切换不会改目标，也不会偷偷换到另一个工作页。
3. **外观通过预设改变。** 工程检查器只显示生效外观、选择/更换预设、停用/恢复、移除、复制到工坊和更新。颜色、字体、描边、脚本参数都在预设制作里编辑。
4. **试看与应用分开。** 候选试看不写工程。明确应用产生一次撤销；取消还原已应用结果。
5. **预览说明它是谁。** 当前时刻、所选行试看、工坊固定试样、布局草稿各有明确标签。
6. **常用功能先出现。** 歌词与字时间、预设基础样式、工程画面使用主要空间；源码、诊断和高级节点按需展开。
7. **已有语义保留。** 维持一个对象一个组合预设、固定副本、显式更新、稳定目标、撤销及现有布局能力。本文不自动改变工程格式、继承算法、脚本能力或预览内核。
8. **操作本身提供引导。** 常驻信息只回答当前对象、当前状态和可执行动作。流程由具体按钮、即时预览和状态递进表达；解释只在缺项、冲突、异常或用户主动查询时出现。同一状态只占一个位置，不在标题、提示框和底栏重复。

背景、画布与对象位置属于工程/布局设置，不属于本轮用户所说的歌词外观字段；本稿保留它们的独立入口。若未来要把背景也预设化，另立范围，不在本稿隐含加入。

## 2. 整体信息架构

```text
MakoKara   Test · 工程已保存                         工程设置  保存工程  导出视频
┌ 工程任务 ───────────────────────┐       ┌ 资源制作 ────┐
  歌词与打轴       画面与编排                 预设工坊

歌词与打轴                       画面与编排                 预设工坊
  来源/歌词列表                    对象浏览器                 内置/我的预设
  当前行文本与注音                 当前时刻/目标试看            基础外观
  所选文本单元时间                 预设应用 / 布局              材质与效果
  播放器 + 时间轴                  自定义布局…                 固定试样
                                                             效果组件编辑
                                                               配置 / 验证 / 源码
```

三个入口仍可直接访问，但工坊放到资源制作侧，不造成“每做一首歌都必须制作模板”的顺序暗示。无工程时可单独进入工坊；无工程身份条时显示“个人预设库”。菜单保留文件、编辑、视图、帮助；低频入口不占用主工具条。

工程名/脏标记在工坊也可见，当前作者名及保存状态位于工坊自己的工具条。全局“保存工程”始终明确对象；`Ctrl+S` 按当前活动编辑上下文保存，菜单显示“保存预设/保存效果组件/保存工程”，顶部紧邻活动上下文显示快捷键归属。存在未提交编排草稿时，导出先处理草稿，不把旧工程结果当成草稿结果。

脚本配置作为工坊下属可关闭工作页。保留“在独立窗口打开”作为高级选项，使用同一作者状态，不能复制一份独立脏草稿。

## 3. 页面 S1：歌词与打轴

**默认优先级：歌词列表 → 当前行/字 → 时间轴。** 来源单列撤去；一个来源时只显示名称，多来源下拉旁有“管理来源”。

```text
主歌词 ▾  管理来源     当前行 01 / 06           定位到此行  试听此行
添加歌词…             [ 朝の光浴びて                               ]
01 朝の光浴びて        行显示区间  00:02.000 — 00:05.000   时间工具…
02 青い空見上げ        [朝] [の] [光] [浴] [び] [て]
03 風の声を聞く        注音（所选：朝）[あさ]      拆开单元 / 合并后项
…                     当前时刻文本预览（可收起；不显示预设样式）
───────────────────────────────────────────────────────────────
所选单元「朝」  开始 00:02.000  结束 00:02.500  时长 0.500 秒
试听本行   播放  00:02.718 / 00:20.000    循环 02.000–05.000   吸附：帧
时间标尺 / 波形 / 行显示轨 / 文本单元轨
```

- 行列表和时间轴、文本单元选择保持可见联动；播放头与编辑选择独立。点击“定位到此行”才跳转。
- 选中行/单元的时间字段固定靠近时间轴；不会随着上方注音/导入内容滚走。
- 时间字段成组验证，Enter/离开整组提交；Esc 撤回当前组未提交输入。错误保留输入并就地说明，阻止针对同一目标的后续提交。不得把暂时无效输入写进工程。
- “整体平移…”打开小面板：新起点、差值、包含本行所有文本单元、修改前后区间；一次应用、一次撤销。它与改行显示区间分开。
- 导入和粘贴在“添加歌词”中明确：现有来源/新来源、追加位置、格式识别结果；文本编辑框只改本行。
- 多字单元仍按现有文本边界拆分。标签用“文本单元”，具体选中内容总显示；不把字符/字素数和唱词单元混为一谈。
- 中性歌词预览可收起。以“当前时刻”和时间码说明预览上下文，不默认展开首次使用教程。
- 无字时间：显示“未定时”，给设置时间入口；无可拆分内容：禁用拆分，原因在该控件按需查看，不常驻解释段落；来源空：中央提供添加歌词，不摆满禁用编辑器。

解决 A06/A07、L01–L07。

## 4. 页面 S2：画面与编排

### 唯一对象与正式预览

左侧统一对象浏览器提供“工程默认、歌词来源、歌词行、文本单元”。“更多对象”展开片段与布局节点。类型和集合明确；主列表不是第二套应用目标。

右侧常驻路径如 `主歌词 / 第 2–3 行 · 2 行`，其下两个页签“预设”“布局”。布局页切换为布局专属范围条，不沿用不适用的工程预设范围。实际范围变化需可见，不靠上次隐藏面板的选择。

画布占中央主要空间，默认“适合窗口”，可 100%、缩放；质量与显示比例分开。工具条显示 `工程效果 · 00:02.718`。选中的第 3 行不在此时刻时，提示“所选行当前未显示 · 定位到此行”，不自动改成编辑试样。

多选行只更新选择和数量，不自动换右侧页签。非连续选择可以用于预设；简单分段布局若只支持连续范围，应显示“此布局需要连续歌词段”，由用户改选，禁止悄悄扩大到两端之间。

多选提供显式“多选”入口，进入后每行出现复选框和“全选/清空”，退出后保留选择。Ctrl/⌘ 作为熟练操作保留，无需常驻一行快捷键教学。未选对象时只显示空态及“选择工程默认”，不显示一组禁用的应用控件。

### 当前预设

```text
当前对象：主歌词 / 第 1 行
预设
  清晰描边 · 继承自工程默认      外观来源…
  [更换预设…]  [复制到工坊编辑]

已有本地应用时：
  Test · 本地预设
  [更换预设…]  [复制到工坊编辑]
  启用开关     更多：移除本地应用 / 查看库更新
```

来源详情显示各字段实际来源及其对应对象，可随当前播放时刻解释节点/片段关系；摘要可以合并相同来源，但不把所有值都说成“来自上级”。工程默认只建立回退，不强行覆盖已有本地应用。

“停用”保留副本与映射，并显示当前回退结果；“移除”去掉此对象的应用，按钮提示上级效果将显现。两者可撤销，不使用同一个含糊的“清除”。

### 页面 S3：选择与应用预设

选择器可在宽窗侧边扩展；紧凑窗作为独立内嵌页。目标摘要和提交区始终可见。

1. 搜索/分类浏览内置与个人预设：预览缩略图、名称、可用目标、是否含效果。兼容性由现有规则判断；不兼容项可解释原因，不给空下拉。
2. 选择候选进入**试看**，画布标 `试看 · 清晰描边`，具体目标只在检查器显示一次。切候选不积累工程撤销。
3. 有具名输入时，先显示“此效果需要：翻译歌词 → [请选择来源]”。缺失时不能伪装成成功试看/应用；无默认猜测。输入绑定与参数编辑不同，允许在应用阶段映射实际来源。
4. 内联影响摘要只显示超出目标名称的信息，例如实际会替换的已有应用或工程默认下保留的局部预设；不再重复目标和“其他行保持不变”的通用说明。
5. 主按钮命名为 `应用到 2 行`。应用成功转回当前预设摘要，并提供“撤销”。无变化不新增历史。普通操作不再次弹相同确认。
6. 导航/对象切换时试看取消；未提交映射可按稳定目标保留草稿，但重新试看/应用前须确认最新目标和库快照。异步试看完成后只更新对应候选，旧请求不得回写。

试看完整脚本效果需要产品接入正式临时快照；网页设计稿只是示意。这是新增 UI 会话工作，不能以现有应用影响预演替代视觉试看验证。

### 预设修改闭环

`当前对象 → 制作副本 → 工坊 → 保存为个人预设 → 返回并试用 → 显式应用到原目标`。

返回上下文包含工程、目标稳定 ID、来源预设、原任务和播放位置。保存不会自动写工程；取消制作返回原对象。若原工程已换/目标删除，保存仍可完成，但“返回并试用”要求重新选择，不能误应用。

库版本更新另走 `查看更新 → 当前工程副本/库候选对比 → 检查来源映射 → 更新此应用`。保持原实例身份和种子等已有语义；“无更新/来源已不存在/同名不同预设”有不同说明，不依赖隐藏下拉。

解决 A02–A05、P01–P06、W06。

## 5. 页面 S4：布局

简单布局与预设应用分离。布局页顶部固定：`布局范围：主歌词 / 全部 6 行`，可选“连续歌词段”，明确起止行及时间。工程预设选择为工程默认时，布局页也必须显式选择来源，不继承“整个工程”的含糊措辞。

当前布局摘要在上；下方展示四张小图：单行居中、卡拉 OK 双行、双行、三行。名称和当前程序保持一致；不能识别时显示“混合/自定义”，不自动选“单行居中”。

点击候选后画布显示“试看”，范围继续在检查器展示。实际会改变片段或继承时，提交区才列具体影响；不常驻“可能改变继承”的泛化提醒。一次“应用到第 2–4 行”完成一次撤销。简单布局不暴露组/槽位/片段内部 ID。

下方“自定义布局…”进入 S5。存在编排草稿时先处理，防止简单布局与草稿互相遮盖。范围更换保留或重新计算候选，不能沿用错误影响摘要。

## 6. 页面 S5：自定义布局

保持既有草稿/提交方式。顶部明确 `自定义布局 · 未应用 2 项改动`，右侧 `放弃改动 / 应用并返回`。工程未保存与草稿未应用分别显示。

三个工作页：

- **布局结构**：左侧树使用“布局组、歌词容器、显示位置”角色标签；选择双行容器能看见上行/下行位置。属性只显示该类型支持的设置。
- **歌词分配**：用可读表格连接“第 1–6 行 → 卡拉 OK 双行”；显示默认布局、例外段、未分配项及前奏；每行可定位到对应歌词/容器。仍保留复杂片段能力。
- **时间检查**：带时刻查看布局结果，标记当前可见歌词及目标容器；不得标为完整成片渲染。

树/属性收起按钮靠近各自区域，不与上述页签并排。树选择和子项高亮表达影响对象，检查器显示具体对象/子项数量；出现扩大范围的操作时才说明额外影响。槽位次序用序号及连线表达。

画布常驻角标 `布局预览 · 脚本关闭`。主动作“应用并返回”回到工程效果。若点返回/切换任务而草稿未处理，给“应用并离开 / 放弃并离开 / 继续编辑”；不能静默展示旧成片并让用户误认草稿已生效。

位置/旋转/缩放使用集中尺寸、统一单位与锚点说明；默认呈现常用字段，父级重挂和复杂来源细节在高级区。单位改变只改变表示方式，不移动画面。

解决 B01/B02、C01–C03。

## 7. 页面 S6：预设工坊

默认进入视觉预设库；选择已有个人预设进入编辑。内置预设显示“只读”，并给明显的“复制并编辑”。类型选择仍区分现有整行、文本单元和组合能力，使用用途标签，保留底层能力限制。

```text
预设工坊   我的预设 / 清晰描边 · 未保存       撤销  更多  保存预设  返回并试用
内置 / 我的    固定试样 · 整句 / 多行         基础外观 | 材质与效果
预设缩略图     [          放大的试样画布      ]  字体、字号
搜索/新建      [试播] 00:01.500 / 00:12.000     未唱 / 已唱填充
               整句 / 单元 / 重复词 / 间奏       描边、阴影、透明度
```

- “基础外观”默认打开，按文字/填充/描边/阴影分组；已唱/未唱并列且有文字标签。不可用于当前对象的字段说明原因，不可伪装生效。
- “材质与效果”展示当前组合。先选择具体部位，再选材质；效果列表展示名称、作用目标、启用状态和顺序。调整参数只发生在工坊草稿。
- 原始 JSON 留给高级用户；可用声明参数使用图形控件。不要让基础改色之前先经过效果包导入和配方名称。
- 固定试样可以整句/多行/重复词/间奏切换，统一标“固定试样”；保留独立试听音频，明确其来源，不附加重复教学。页面不假装使用当前歌曲。
- 保存区固定可见，删除放更多菜单。保存仅更新个人库；返回并试用回到 S3，不直接修改工程。
- 非法输入就地保留，顶部显示“有 1 项待修正”并可定位；保存/返回试用禁用原因可见。关闭有保存/放弃/继续编辑。
- 没有返回上下文时，主操作为“保存预设”，不显示一个无目标的“应用”。

解决 W01–W03、W06/W07、P02/P05。

## 8. 页面 S7：效果组件编辑

属于预设工坊，标题包含父预设；保留独立组件库以复用。术语替换：脚本预设→效果组件；导出项→包内效果/材质；固定效果包→效果包，固定版本放详情。

**空态：** “还没有效果包 → 导入效果包…”；菜单内可选文件或目录。此时不铺开一屏空表单。

**配置页：** 包内效果选择、组件名称、图形参数、作用目标、需要读取的来源。仅显示选中效果所需字段。高级参数/随机种子/叠加策略按需展开，字段标签不使用内部编码。

**验证页：** 显示验证使用的组件快照/参数版本和固定试样，启动、进度、取消、失败定位与完整报告。配置改动后旧结果标“结果已过期”；验证成功不等于工程整片验证通过。

**源码页：** 文件列表、编辑区、编译诊断、保存新修订。显式区分：

| 动作 | 影响 | 不代表 |
|---|---|---|
| 保存源码修订 | 保存一份新代码版本 | 不代表编译或运行成功 |
| 编译 | 检查当前指定修订能否编译 | 不自动升级所有引用 |
| 采用修订 | 当前组件改用选定可用修订 | 不自动修改已复制的模板/工程 |
| 运行验证 | 执行该配置的固定试样 | 不代表真实整片已验证 |
| 保存组件 | 写入组件库 | 不改变父预设已有副本 |
| 保存并加入预设 | 保存后将明确选定组件复制到父预设草稿 | 父预设仍须保存，工程仍须应用 |

“保存并加入”是新导航编排，不降低当前保存/编译/验证门禁。父预设只读时提供“复制预设并加入”；父预设已关闭或目标失效时提供“保存组件”，就地提示原预设不可用，不静默替换目标。

解决 W03–W07。

## 9. 页面 S8：工程设置与导出衔接

从顶栏打开工程设置。固定显示 `Test / 工程设置`，四组：画布、背景、音频、输出范围。

- 画布：常用尺寸/比例选择及自定义宽高、帧率，标注像素；质量不在这里。
- 背景：当前图片/视频名称与缩略图；选择/替换/移除放一起。图片不显示播放模式；视频显示实际可用策略。
- 音频：文件名、时长、状态、替换/重试；不会藏在歌词来源下面。
- 输出范围：按当前音频计算、按歌词末尾计算、自定义结束时刻。现有两个按钮是取值操作，本稿默认仍为明确计算一次；音频/歌词变化后提示可重新计算，不偷偷引入持续绑定语义。
- 工程字段按组 Enter/失焦提交，一次操作可撤销；关闭保留已提交设置，通过工程未保存状态和撤销反馈表达，不常驻解释保存规则。更换媒体是显式动作，失败保留原媒体并就地提示。
- 导出页保留路径/格式/质量、音频和输出摘要；旁边“修改工程设置”能往返保留导出草稿。检测中、缺少依赖、输出范围未知、取消中、失败及完成均有可执行下一步。

## 10. 统一交互状态

| 场景 | 页面必须显示 | 提交/离开规则 |
|---|---|---|
| 工程已修改 | 工程名后的未保存状态 | 保存工程，与资源库草稿分开 |
| 预设候选试看 | 候选名、目标数、待应用角标 | 应用或取消；离开取消试看 |
| 本地应用停用 | 已停用，实际回退来源 | 可重新启用；移除是另一动作 |
| 多选混合预设 | 混合值、具体对象数 | 保留个体差异，直到显式替换 |
| 空库/没有兼容项 | 原因及创建/导入入口 | 不显示空白下拉加一排禁用按钮 |
| 输入非法 | 错误贴近字段，可定位 | 保留草稿；禁止提交，不自动修正 |
| 作者草稿 | 保存对象名、未保存状态 | 保存/放弃/继续编辑 |
| 编排草稿 | 未应用状态、基础预览身份 | 应用/放弃后离开 |
| 库内容改变 | 所用副本、候选更新 | 比较后显式更新，不自动跟随 |
| 目标/工程已变化 | 原目标已失效 | 重新选择，不对新对象沿用旧请求 |
| 后台运行/取消 | 正在执行或等待释放 | 等释放完成后重试；旧报告不冒充新结果 |

普通应用把确认移到有目标、有差异的内联提交区；删除资源、覆盖文件、丢弃草稿等不可逆/有损操作才需要独立确认。无变化操作不给虚假的“修改成功”。

## 11. 视觉、尺寸与可访问性

- 延续现有深浅主题和蓝色主操作，不引入新组件库作为本轮前提。减少大圆角套小圆角和大段说明文字；分组主要靠标题、留白和细分隔线。
- 原生布局按逻辑像素验收，建议宽窗 1600×1000/1440×900，中窗 1100×760，最小 760×640；同时验证 1×、1.8×、2×。这些是验收目标，不是当前程序已通过的结论。
- 宽窗：对象列表约 224，检查器约 320，中间弹性；用户可拖动。中窗优先收起对象列表，保留当前路径。最小窗使用“画面/检查器”明确切换，不用两条固定侧栏挤没画布。
- 歌词列表/属性内容可独立滚动；所选时间字段、主提交、播放控制不能被表单尾部推走。底部时间轴可调整高度。
- 按钮、输入、段落、间距从统一尺寸项取值；设计稿建议普通控件 32–36、主操作 36–40、8/12/16 间距，实际落实到现有集中指标后验证，不能分散写死。
- 控件有可见标签和键盘焦点；选中/错误/草稿不只靠颜色。隐藏或切页时焦点回到入口或同一对象；弹层 Esc 关闭并恢复焦点。
- 长名称、日文/中文/拉丁混排、200 行歌词、50 个预设、8 个输入映射、含错误的多选须专门验收。正文可换行，关键目标与按钮不只靠省略号和悬浮提示。
- 对话中的设计预览为便于小屏阅读可纵向重排，320–736 宽度不是承诺桌面产品支持手机尺寸。

## 13. 核心验收任务

1. 初次使用者从现成预设完成“整首默认外观→导出”，不被迫进入工坊。
2. 选第 2、4 行更换预设；目标数、非连续范围、其他行保留情况在提交前清楚可见；一次撤销恢复。
3. 工程默认改变后有局部覆盖的行保持，其原因可以在来源详情看懂。
4. 当前应用复制到工坊，修改保存后回到原目标；返回前工程仍未改变，应用后才改变。
5. 工坊保存期间原目标被删除/工程被替换，返回应用会明确阻止旧目标回写。
6. 给主歌词第 2–4 行换双行布局；不会误改翻译来源或其他行；不把不连续选择悄悄扩大。
7. 选一个文本单元可立即看到起止时间；非法时间不写入，Esc/Enter/失焦行为一致，撤销粒度合理。
8. 工程播放在空档时选中另一行，能区分“没有歌词的当前时刻”与“所选行试看”，无渲染故障误判。
9. 内置只读预设有明确复制入口；基础字体、填充、描边在首屏可达；错误/保存按钮不被滚动遮住。
10. 空组件库导入效果包→选择效果→参数→验证→保存并加入，清楚知道当前存在哪一层。
11. 编译成功、配置保存、采用修订和运行验证结果分别可读；改参后旧验证标过期。
12. 自定义布局调位置→看基础草稿→应用返回→看实际工程效果；不把回退图当最终脚本效果。
13. 更换背景、修改输出范围、进入导出再返回调整，路径/格式和错误恢复连续。
14. 760×640、长文本、多选和高 DPI 下完成上述关键操作；主提交、当前目标、错误与焦点可见。

设计稿验证只证明网页原型自身的导航与排版。原生控件、真实工程/音频、脚本执行、输出视频、物理键盘/IME和跨平台行为仍需实施后分别验证。
