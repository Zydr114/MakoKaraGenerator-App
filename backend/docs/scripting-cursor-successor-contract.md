# 真实光标后继与独立端点合同

> 2026-10-05，R6 Bridge 的前置施工。完成证据以 roadmap 为准；转换表和端点解析不代表桥接发射已经交付。

> 0.30.0 已按[桥接合同](scripting-cursor-bridge-contract.md)／ADR-0126 接通正式飞行及逐边独立发射；下文保留0.29.0前置批次范围，最新证据见roadmap §18.93。

## 1. 固定接续

- 同一分支／程序按源顺序接续。句内连接相邻的真实定时元素；缺时间元素不制造演唱身份。跨句只连接相邻源行的末／首定时元素，整行均无逐字时间时使用真实行区间。缺行时间的源行阻断跨句接续，不跳过未知演唱去猜后继。 相邻源行的起唱时刻相同则形成并发组，组间保留全部末／首边，组内不猜先后。下一组起唱早于上一组时不创建逆时间边。
- 源身份与正式播放头共用同一个 Current 投影。PreviousEndLimit 取 EndUs-1、NextStart 取 StartUs；分别从共享场景取得实际 BindingId。不可见／准备／保留状态不制造光标，槽位替换等造成端点不可见时不补造装载。片段／前奏沿原工程校验，不放宽演唱时间冲突门禁。
- 句内同一装载接续，不任意配对不同装载；跨句保留全部真实装载边。多个合法后继返回集合，不按节点名、槽位或集合第一项猜唯一光标。
- 重叠源行允许转换事件，GapUs=0；事件在 To.StartUs，仍排在结束／进入／起唱之后。不为重叠句创建飞行区间，不延迟下一句。
- 固定接续先于实例输出范围。From 和 To 均须符合真实输出绑定；窄绑定不跨越范围外的源行去重新选择另一个后继。源订阅独立，project 订阅不扩大粒子输出权限。

## 2. 独立端点

- 宿主按固定表查询绑定内后继，返回每条边及 PreviousEndLimit／NextStart 的最终几何。每个端点独立 AnchorQuery 重放共享事件、推进和文字求值，保留所有实例的最终文字／父树变换。
- 查询不执行发射、粒子、视觉、图像或背景阶段，不写主会话历史。端点不可用明确保留不可用值，Error／取消直接传播，不回退为基础几何。
- 事件表／查询是 Bridge 的必要基础。本步不解除 CursorEmitterDescriptor 的 Bridge 门禁；下一步接入独立端点、固定半开飞行区间、真实桥接来源、配额和绘制。
